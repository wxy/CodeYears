# CodeYears 0.1.4 Chrome 商店交接

在 Chrome 应用商店后台的「软件包」上传修复版候选 `codeyears-0.1.4-city.zip`。安装包与这个素材包是两个文件。

- [商店文案](store-listing.md)提供英文和简体中文的完整可复制文本。这次需要更新详细说明。名称和简短说明沿用 0.1.3。
- [审核说明](review-notes.md)说明新版可见变化、公开个人主页的复现步骤和作者页链接的行为。
- 官网、支持页、隐私政策和已有宣传图块沿用现有商店配置。产品页提供对应语言的入口。

## 第 4 张截图配文

**简体中文**

微缩城市就在贡献图里。每个有贡献的日子对应一栋小建筑，可以随时切回 GitHub 原图。

**English**

See daily contributions as miniature buildings in GitHub’s contribution graph. Switch back to the original graph whenever you like.
