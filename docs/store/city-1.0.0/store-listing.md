# CodeYears 1.0.0 · Chrome Web Store 文案

## English

### Name

CodeYears: GitHub Contribution City

### Short description

A free GitHub contribution visualizer. Turn real daily contributions into a city.

### Detailed description

```text
CodeYears 1.0 turns your GitHub contribution history into a city you can explore. Smaller counts bring in houses, while higher counts can produce apartments, offices and towers. Days with zero contributions appear as greenery or paving, depending on the surroundings. Zoom out to see years of work together, or zoom in to see the dates and activity behind a building.

A miniature city inside the contribution graph

On a GitHub personal profile, select Miniature city in the Contributions tab or in the CodeYears toolbar settings. Small buildings appear within the original calendar area. The five-level legend follows GitHub’s contribution levels, and GitHub continues to provide date selection and tooltips. Choose GitHub original at any time to switch back.

Open the city and choose your years

Select City beside the contribution graph, or open CodeYears from Chrome’s toolbar and click Open City. The city starts with the most recent three available years. Changing either end of the range updates the map immediately. The URL remembers your selection so you can reopen it or share the same range with someone who has CodeYears installed.

Terrain and roads appear first, then buildings fill in as yearly data arrives. The earliest year shown on the GitHub profile sets the starting point for fixed five-year districts. Contributions are grouped by complete ISO weeks, so a week around New Year can span two calendar years. The contribution total shows the dates it actually covers.

Follow the highway signs

Blue exit signs lead to contribution cities for personal accounts mentioned in the profile’s Bio. Add friends to your own Bio with @username mentions, and CodeYears places them at available exits in order. Click an empty sign for instructions and English Bio examples you can copy. After following an exit, use the return sign to go back to the previous city in the same tab.

Billboards along the ring road display organizations from the Bio, profile details and Organizations list. Click one to visit the organization on GitHub. The map can show up to 16 organization billboards.

Explore districts and individual buildings

Tree-lined roads connect districts and cross the rivers on bridges. Beyond the streets are wooded ridges, branching rivers, lakes and distant snowy peaks. Highways continue to the edges of the view.

Villages outside the ring road mark the creation dates of public repositories. Hover over a house to see the repository name and date. The city’s contribution total follows the GitHub contribution calendar.

Scroll to zoom and drag to pan. When the canvas is focused, use the arrow keys to pan and + or - to zoom. Fit view frames the city and its named road signs, while Maximum zoom brings you in for a closer look. Expand the city within the page, then press Esc or click the backdrop to return.

Hover over or select a building to see the dates it represents and their actual contribution total. CodeYears loads available GitHub activity summaries on demand, including related repositories and approximate counts for commits, pull requests, reviews and issues. When GitHub activity confirms the date you joined and that day is in view, a distinctive tower marks it.

Save your city

Frame your view, then right-click the canvas to save or copy it using Chrome’s image menu. Right-clicking includes the City of Code plaque in the image, with the profile’s GitHub handle and a Made with CodeYears credit. While exploring, mouse activity reveals the plaque. It fades after five seconds of inactivity.

Language, cache and privacy

Open More for the legend, viewing instructions, sign details and the rules on data privacy. You can also refresh the selected years, clear the profile’s yearly contribution cache, or choose English, Simplified Chinese or the browser language. The CodeYears toolbar popup on a GitHub personal profile lets you show or hide the City tab, choose the contribution graph style and set the interface language. If Chrome asks each time you visit GitHub, the popup links to the extension details where you can turn on automatic access for github.com. Its footer links to the product website, source code and feedback. The full privacy policy is available from this store listing.

CodeYears is free. On your own profile, it verifies your current GitHub session and shows the contributions GitHub makes available to you, including private contributions you can see. Other profiles and signed-out or unverified sessions use GitHub’s signed-out view. That view may include anonymized private contribution counts the profile owner has chosen to show. Public repository names and creation dates come from GitHub’s public API and are used within the current page. Yearly contribution records are cached locally by viewer, profile and year. Your language preference is also stored on the device.
```

## 简体中文

### 名称

CodeYears：GitHub 贡献之城

### 简短说明

免费的 GitHub 贡献历史可视化扩展。选择年份，用真实每日贡献生成贡献之城。

### 详细说明

```text
CodeYears 1.0 把真实的 GitHub 每日贡献绘成一座可以探索的城市。贡献较少的日子对应小住宅，较高的贡献档位会出现公寓、办公楼和大厦。零贡献的地块则根据周围环境呈现为草地、植被或铺装。拉远可以看到多年的开发轨迹，拉近可以查看一栋建筑对应的日期和活动。

在贡献图里看微缩城市

打开 GitHub 个人主页后，默认显示原生贡献图。在「贡献图」页签或工具栏弹窗中选「微缩城市」，原日期范围里会出现小建筑。五档图例沿用 GitHub 的贡献档位，日期点选和悬停提示继续由 GitHub 提供。随时可以切回「GitHub 原图」。

打开城市，选择年份

点击贡献区的「城市」页签，或在 Chrome 工具栏的 CodeYears 弹窗点「打开城市」，即可在当前主页查看多年的贡献之城。默认展示最近三个可用年份。修改起始年或结束年，画面随即更新。城市网址会记住所选区间，刷新后可以继续查看，也可以把这段年份分享给同样安装了 CodeYears 的人。

地形和道路先出现，建筑随各年的贡献数据逐步填入。城区从 GitHub 主页列出的最早年份起，每五年划为一个固定城区。贡献日期按 ISO 完整周组织，年初年末的同一周可能包含相邻公历年的日期。贡献合计旁会标出实际覆盖的日期。

沿公路前往其他贡献城市

蓝色高速出口牌来自 GitHub 简介（Bio）中提及的个人账号。在自己的简介里写入朋友的 @用户名，CodeYears 会按出现顺序把这些账号放到可用的出口上。点击空白出口牌可查看设置方法，并复制适合放在 Bio 里的英文例句。沿具名路牌进入另一座城市后，可以通过返程牌回到当前标签页里来时的城市。

外环路边的广告牌展示来自简介、资料栏和 Organizations 列表的组织图标。点击广告牌可打开相应的 GitHub 组织主页。一张地图最多展示 16 块组织牌。

从城区全景看到建筑细节

林荫道路连接各个城区，桥梁跨过河面。城郊有林木覆盖的山脊、分叉的河流、湖泊和远处的雪山，出城公路延伸到视野边缘。

环外村庄标记公开仓库的创建时间。悬停在住宅上可查看仓库名和创建日期。城市贡献合计以 GitHub 贡献日历为准。

滚动鼠标滚轮可缩放，拖动可平移。画布获得焦点后，也可用方向键移动，用 + 和 - 缩放。右下角的「全景」会把城区和已命名的路牌一同纳入取景，「最大倍率」可快速查看近景。可在当前页面展开城市，按 Esc 或点击遮罩返回。

悬停或选中一栋建筑，可以查看它涵盖的日期与真实贡献合计。CodeYears 会按需读取 GitHub 可见的活动摘要，包括相关仓库，以及提交、拉取请求、评审和 Issue 的可用汇总。查看最早年份时，如果 GitHub 的活动记录明确标出了加入日期，城市会用一座纪念塔标记那一天。

保存你的城市

调整好取景后，右键点击城市画布，即可通过 Chrome 原生菜单保存或复制图片。右键会把左下角的 City of Code 铭牌带入图片，为分享的画面保留当前主页的 GitHub 账号和 Made with CodeYears 署名。浏览时，鼠标在画布上活动会显示铭牌，静止五秒后收起。

语言、缓存和隐私

「更多」菜单提供图例、操作说明、路牌来源和数据隐私说明，也可以刷新所选年份或清除当前主页的年度贡献缓存。界面支持英文、简体中文及跟随浏览器语言。在 GitHub 个人主页打开 CodeYears 工具栏弹窗，也可以设置城市页签显隐、贡献图样式和界面语言。如果 Chrome 设为每次访问都询问，弹窗会提供扩展详情入口，便于开启对 github.com 的自动访问。页脚提供官网、源代码和问题反馈入口。完整隐私政策可从商店条目打开。

CodeYears 免费使用。查看自己的主页时，扩展会核对当前 GitHub 会话，并显示 GitHub 向该会话提供的贡献，其中可以包含本人有权查看的私有贡献。访问其他人的主页、退出登录或身份未能确认时，城市使用匿名访客可见的数据，其中可能包含主页主人选择公开的匿名私有贡献数。公开仓库的名称及创建日期从 GitHub 的公开接口读取，仅在当前页面使用。年度贡献缓存在本机，按访问者、主页和年份隔离，语言偏好也保存在本机。
```
