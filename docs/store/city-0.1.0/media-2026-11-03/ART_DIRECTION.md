# 生长秩序

城市的秩序来自长期累积，而非一座孤立的地标。画面以街道、楼群与自然边缘的连续关系为主体，让密度和疏朗共同形成节奏。精确的透视和经过细致标定的建筑本身承担叙事，排版只提供必要的识别。

色彩从现有城市中提取：深松绿、温暖石色、铜金与玻璃蓝。宣传画布允许使用沉稳的深色承托，让浅色建筑在缩小后仍有清晰轮廓；这种衬底属于宣传版式，不暗示产品提供新的主题或夜间功能。精细处理明暗和色块的关系，胜过添加更多装饰。

比例必须照顾两个观看距离。大横幅容纳城市整体的呼吸感，小图块则靠近街区，让建筑仍能作为建筑被辨认。所有城市内容都直接来自正式渲染器，保留统一角度，避免为了视觉气氛虚构新的建筑、灯光或操作界面。构图以反复校准的尺度、对齐与留白体现工艺。

文字只保留 CodeYears 品牌名，并在需要时标明示例数据。品牌名与图标作为安静的锚点，避免广告式的功能清单和夸张口号。宣传图块跨语言使用，界面截图则完整保留各自语言，把理解成本交给清晰的视觉层次，而不是重复文案。

最终检查以原尺寸和半尺寸同时观看，仔细处理边缘、文字间距与城市主体的覆盖范围。精致来自克制而准确的安排；任何不能改善识别、尺度或节奏的元素都不加入。
