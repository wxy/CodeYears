# 产品定义

状态：旧 3D City 原型已有实现但未获视觉接受；最新改为固定视角预绘建筑方向，六款设计样稿完成、尚未接入。Terrain 保持连续，完整实装与视觉验收待完成。更新日期：2026-10-31。

本文件记录产品范围。技术可行性见 [数据与隐私](DATA_AND_PRIVACY.md)、[性能](PERFORMANCE.md)，开发状态见 [路线图](ROADMAP.md)。

## 计划中的主要流程

1. 用户正常访问 GitHub 个人主页。只进行必要的页面识别，提供轻量入口；不自动请求全部历史或初始化 Three.js。
2. 用户选择 City 或 Terrain。识别主页所有者与当前访问者，读取对应年度缓存，按需补齐缺失数据。
3. 数据通过校验后交给时间轴；先显示完整平地，整个城市或地形共同生长。数据获取进度与景观生长进度是两个独立状态，生长百分比不是某日贡献已呈现的计数。
4. 用户可暂停、继续、跳过到已可用的最终状态。完整缓存不会强制跳过动画。加载中、失败和部分年份缺失要有明确状态。
5. 画面静止停止连续绘制；隐藏标签暂停；关闭、离开主页或销毁视图后释放资源。原生 GitHub 内容继续可用。

这段是目标行为。以下是旧原型的实际状态，尚未切换预绘素材：当前已实现主动打开、起止年份、逐年加载、年度统计、完整缓存重播、播放控制、旋转缩放及关闭；City 使用五类建筑轮廓和草木分层，建筑按材质配色、年份轻度调色，组织在共享街路和公园中，Terrain 保持连续；缩放会合并相邻网格，减少远景细节。两视图共享生长进度、相机和已加载数据，切换不重新请求；失败或取消不展示不完整历史。透明画布和 UI 跟随 GitHub 页面明暗，Signature / Natural 主题选择尚未接入。后台沿用身份保护策略，清除结果并销毁风景，返回后重新生成。版本化证据见 [城市图样报告](reports/CITY-TYPOLOGIES.md)。

## 最新建筑设计阶段

用户不接受现有屋顶/建筑造型，要求先完成典型、精美的建筑设计，并明确不需要旋转。当前 [六款样稿与素材规范](design/city-buildings/v1/README.md) 已形成；图片是设计总览，不是透明运行时图集，尚未替换 City。新主线为样式反馈 → 透明素材/比例/锚点 → 固定视角城市与缩放平移 → 直接路径和性能验收。

## 视觉边界

- City 向有写实质感的微缩景观推进：有车道线/路口/人行横道的公路、中央绿地，以及坡顶住宅、办公楼、圆塔/退台塔楼、拱顶会展馆和体育场。当前候选阈值为每日 0=草地、1–2=灌木、3–5=树木、6+=建筑；远景按聚合组内日均量分层（0、>0–2、>2–5、>5）。这些阈值是本轮实现选择，尚未冻结。建筑楼层同时参考相对贡献强度与城市分区；同年、同楼层且位于同一街路地块的相邻建筑可合并，数量仍精确保留。公园树木、湖泊、道路仅作景观，地块植被则表示贡献强度。不追求车辆、行人或游戏系统。用户要求更接近实景、更有表现力，不代表当前已达到视觉验收。
- 画布透明并跟随 GitHub 背景，地景边缘渐隐，Terrain 不另铺矩形底板。Terrain 用真实数量的对数强度，经局部平滑、相对起伏、褶皱调制和边缘收敛塑形成连续山脊；绿色低地、灰绿高地、岩石与雪顶随当前高度显现；高度不是实地海拔，也不等于某日精确数量。远景空间分组只改变表现，原始总量和每日明细始终保留，具体映射与阈值尚未冻结。
- Signature 与 Natural 是已确认的主题名称；具体配色、材质参数与数值映射尚未冻结。
- 轻量、清晰反馈和自然动画优先于复杂特效；减少动态效果的系统偏好需要纳入验收。
- 不覆盖或删除 GitHub 原生贡献图；没有数据或 WebGL 不可用时仍保留正常浏览路径。

## 技术待验证项

- 同源贡献页面能否在现有会话下可靠按年获取；响应形式、登录重定向、限流与站点导航行为。
- 每日数量解析、日期范围、零贡献、闰年、语言和年份差异；页面显示总数与逐日合计是否一致。
- 当前访问者的可靠识别、登录切换与缓存失效；权限或私有贡献可见性变化。
- 内容脚本、资源加载和所需权限的最小组合；Chrome / Edge 的实际行为。
- 20 年数据下 City 与 Terrain 的性能、静止帧停止、后台暂停与资源释放。

上述均不能因产品选型已确认而标记为已验证。

## 后续设想

只有扩展取得真实使用与传播反馈后，才考虑另立免费独立网站项目，承载确实受扩展形态限制的体验。目标是传播、引流与声誉，不是收费。现在不建设网站，也不为它提前加入登录、服务器或通用平台框架。

截图导出、动画导出、可分享作品链接、扩展独立大视图、自动画质分级和社区协作可记录为候选，尚非首版交付承诺。仓库已于 2026-10-29 按用户决定公开；开源许可证和商店发布策略尚待决定。

## 维护规则

新增决策注明来源与日期；验证结论记录环境、输入和实际结果；设想只有经确认后才能进入首版范围。功能未实现、已实现未验收、已验证与已发布分别记录。
