状态：六款建筑样式已获用户选择，透明素材已接入固定视角 City；年度工作周街区与缩放平移可体验。Terrain 保持连续，整体视觉、完整 MVP 和性能预算待验收。更新日期：2026-10-31。

本文件记录产品范围。技术可行性见 [数据与隐私](DATA_AND_PRIVACY.md)、[性能](PERFORMANCE.md)，开发状态见 [路线图](ROADMAP.md)。

## 已确认决策

| 议题 | 决策 |
| --- | --- |
| 名称 | 正式命名 CodeYears；不再继续本轮命名比较 |
| 产品形态 | 首先是 Chrome / Edge Manifest V3 浏览器扩展 |

| City 表达 | 2026-10-31 用户修正：扩充颜色/造型，明确占地与贡献高度；每种支持组合至少两个选择。增加警局、消防局、火车站等功能设施，重绘单树/树林，低贡献区域可用草地、湖泊、广场；允许按占地与高度一起等比复用素材（扩充待实施） |
| 展示交互 | 2026-10-31 用户修正：取消旋转，保留缩放和平移；City 使用已选风格的透明预绘建筑 |
| 设计 | Apple 式精致克制；Signature 与 Natural 两种主题 |
| 时间 | Time Travel 从完整平地整体生长，低矮部分先停止、高处继续；完整缓存也可重播，支持暂停、跳过 |
| 资源 | 按需激活、静止停止连续帧、离开释放 WebGL，性能优先 |
| 技术方向 | TypeScript、Vite、Shadow DOM；City 采用 Canvas 2D 预绘素材，Terrain 采用按需 Three.js 高度场，二十年预算待验证；数据/缓存/时间轴/渲染可分离 |

“真实数量”指当前访问者在 GitHub 贡献页面被允许看到的每日贡献数量，不代表全部 Git 提交，不保证能看到隐藏的私有活动。不以颜色等级生成估计数量。

## 计划中的主要流程

1. 用户正常访问 GitHub 个人主页。只进行必要的页面识别，提供轻量入口；不自动请求全部历史或初始化 Three.js。
2. 用户选择 City 或 Terrain。识别主页所有者与当前访问者，读取对应年度缓存，按需补齐缺失数据。
3. 数据通过校验后交给时间轴；先显示完整平地，整个城市或地形共同生长。数据获取进度与景观生长进度是两个独立状态，生长百分比不是某日贡献已呈现的计数。
4. 用户可暂停、继续、跳过到已可用的最终状态。完整缓存不会强制跳过动画。加载中、失败和部分年份缺失要有明确状态。
5. 画面静止停止连续绘制；隐藏标签暂停；关闭、离开主页或销毁视图后释放资源。原生 GitHub 内容继续可用。

当前已实现主动打开、起止年份、逐年加载、年度统计、完整缓存重播、暂停/继续/跳过、固定视角缩放/平移/重置及关闭。City 每年一个横向街区，按工作周排列并固定合并结果；预绘六种建筑保留原始材质颜色。Terrain 保持连续。两视图共享生长进度、缩放平移和已加载数据，切换不重新请求；失败或取消不展示不完整历史。透明画布和 UI 跟随 GitHub 明暗，Signature / Natural 主题选择尚未接入。后台沿用身份保护策略，清空结果并销毁风景，返回后重新生成。实际验证与未验收范围见 [预绘城市报告](reports/PREPAINTED-CITY.md)。

## 最新建筑设计阶段

用户已选择 [六款设计方向](design/city-buildings/v1/README.md)，分别生成透明素材并接入。原设计总览只作参考，不直接裁为图集。已针对用户反馈修复建筑与地图的主底边方向、缩放改变建筑与跨格融合的问题。素材标定是图像近似校正，建筑尺度是地块视觉尺度；不宣称物理比例准确或整体视觉已获接受。下一步先收敛整体观感，再完成二十年预算及剩余浏览器验收。

用户后续认为当前效果可以继续推进，提出单元规范、变体、植被平地和季度道路。加入 3×3 占地，已完成 [八张单元设计板](design/city-units/v2/README.md)，22款透明候选已生成、待统一标定；统一地面投影是接入硬约束。具体规范见 [城市单元规范](design/CITY_UNIT_SPEC.md)：占地承载合并日期，高度建议表示日均贡献强度，素材等比放大同时改变 W/D/H。用户已授权按规范继续设计；具体阈值、季度道路取最近整周边界以及单元的实际几何仍待验证。运行时仍用上段六款 v1，仅景观带已改为从所选历史起点每五年分组，不把新单元候选算作已接入。

## 视觉边界

- City 采用砖石住宅、街角公寓、中层办公楼、退台塔楼、会展/文化中心和体育场。当前阈值为每日 0=草地、1–2=灌木、3–5=树木、6+=建筑；建筑按相对强度分档，同年同档矩形合并，当前上限为 8 周列×4 个星期行。具体数值不是已冻结产品决策，也不要求合并成员数量逐个相等。每个年份通常需要 53 个边界周列，必要时 54 列，保留真实日期；当年不补未来零值。缩放只改变大小和绘制细节，建筑类型、合并与原始数据保持不变。公园树木、湖泊、道路仅作景观，地块植被表示贡献强度；不引入车辆、行人或游戏系统。
- 画布透明并跟随 GitHub 背景，地景边缘渐隐，Terrain 不另铺矩形底板。Terrain 用真实数量的对数强度，经局部平滑、相对起伏、褶皱调制和边缘收敛塑形成连续山脊；绿色低地、灰绿高地、岩石与雪顶随当前高度显现；高度不是实地海拔，也不等于某日精确数量。远景空间分组只改变表现，原始总量和每日明细始终保留，具体映射与阈值尚未冻结。
- Signature 与 Natural 是已确认的主题名称；具体配色、材质参数与数值映射尚未冻结。
- 轻量、清晰反馈和自然动画优先于复杂特效；减少动态效果的系统偏好需要纳入验收。
- 不覆盖或删除 GitHub 原生贡献图；没有数据或 WebGL 不可用时仍保留正常浏览路径。

## 技术待验证项

- 同源贡献页面能否在现有会话下可靠按年获取；响应形式、登录重定向、限流与站点导航行为。
- 每日数量解析、日期范围、零贡献、闰年、语言和年份差异；页面显示总数与逐日合计是否一致。
- 当前访问者的可靠识别、登录切换与缓存失效；权限或私有贡献可见性变化。
- 内容脚本、资源加载和所需权限的最小组合；Chrome / Edge 的实际行为。
- 20 年数据下 City 与 Terrain 的性能、静止帧停止、后台暂停与资源释放。

上述均不能因产品选型已确认而标记为已验证。

## 后续设想

只有扩展取得真实使用与传播反馈后，才考虑另立免费独立网站项目，承载确实受扩展形态限制的体验。目标是传播、引流与声誉，不是收费。现在不建设网站，也不为它提前加入登录、服务器或通用平台框架。

截图导出、动画导出、可分享作品链接、扩展独立大视图、自动画质分级和社区协作可记录为候选，尚非首版交付承诺。仓库已于 2026-10-29 按用户决定公开；开源许可证和商店发布策略尚待决定。

## 维护规则

新增决策注明来源与日期；验证结论记录环境、输入和实际结果；设想只有经确认后才能进入首版范围。功能未实现、已实现未验收、已验证与已发布分别记录。
