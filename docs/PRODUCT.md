# 产品定义

状态：产品方向已确认；多年份 City 年份布局与 Terrain 已实现，新版实装和完整 MVP 待验收。更新日期：2026-10-31。

本文件记录产品范围。技术可行性见 [数据与隐私](DATA_AND_PRIVACY.md)、[性能](PERFORMANCE.md)，开发状态见 [路线图](ROADMAP.md)。

## 已确认决策

| 议题 | 决策 |
| --- | --- |
| 名称 | 正式命名 CodeYears；不再继续本轮命名比较 |
| 产品形态 | 首先是 Chrome / Edge Manifest V3 浏览器扩展 |
| 成本与账户 | 完全免费，无 GitHub Token、独立登录或后端 |
| 数据方向 | 利用 GitHub 个人主页已有会话，同源请求贡献页面，分年获取真实每日贡献数量 |
| 缓存 | 本地按年份缓存，必须隔离登录访问者身份 |
| 视图 | City（贡献之城）、Terrain（时光山脉）；不开发独立 Classic 或 Orbit |
| 设计 | Apple 式精致克制；Signature 与 Natural 两种主题 |
| 时间 | Time Travel 生长动画，缓存完整也可从历史起点逐渐呈现，支持暂停、跳过 |
| 资源 | 按需激活、静止停止连续帧、离开释放 WebGL，性能优先 |
| 技术方向 | TypeScript、Vite、Three.js 按需随扩展打包加载、Shadow DOM；数据/缓存/时间轴/渲染可分离 |
| 顺序 | 数据、身份缓存与 20 年性能验证 → City MVP → Terrain → 发布 |

“真实数量”指当前访问者在 GitHub 贡献页面被允许看到的每日贡献数量，不代表全部 Git 提交，不保证能看到隐藏的私有活动。不以颜色等级生成估计数量。

## 计划中的主要流程

1. 用户正常访问 GitHub 个人主页。只进行必要的页面识别，提供轻量入口；不自动请求全部历史或初始化 Three.js。
2. 用户选择 City 或 Terrain。识别主页所有者与当前访问者，读取对应年度缓存，按需补齐缺失数据。
3. 数据通过校验后交给时间轴；时间轴从历史起点驱动逐日或分段生长。数据获取完成与动画播放完成是两个独立状态。
4. 用户可暂停、继续、跳过到已可用的最终状态。完整缓存不会强制跳过动画。加载中、失败和部分年份缺失要有明确状态。
5. 画面静止停止连续绘制；隐藏标签暂停；关闭、离开主页或销毁视图后释放资源。原生 GitHub 内容继续可用。

这段是目标行为。当前已实现主动打开、起止年份、逐年加载、各年概览、完整缓存重播、播放控制、旋转缩放及关闭；City 按年份组织独立城区，Terrain 按同一布局呈现高度场。两视图共享播放头、相机和已加载数据，切换不重新请求；失败或取消不展示不完整历史。主题选择未接入。后台沿用身份保护策略，清除结果并销毁风景，返回后重新生成。新版本地/受控 UI 与真实 MV3 证据分开记录，见 [年份风景报告](reports/YEAR-LANDSCAPES.md)。

## 视觉边界

- City 用几何体、比例、材质与光线表现贡献积累；不追求道路车辆、行人或游戏场景。
- Terrain 当前以真实每日数量的对数映射作为每日中心高度，只在相邻日期公共角点做视觉插值；没有数据的未来位置不生成地形面，不据此估算任何每日数量。该表现方式已在本地查看，正式主题与性能仍需验证。
- Signature 与 Natural 是已确认的主题名称；具体配色、材质参数与数值映射尚未冻结。
- 轻量、清晰反馈和自然动画优先于复杂特效；减少动态效果的系统偏好需要纳入验收。
- 不覆盖或删除 GitHub 原生贡献图；没有数据或 WebGL 不可用时仍保留正常浏览路径。

## 技术待验证项

- 同源贡献页面能否在现有会话下可靠按年获取；响应形式、登录重定向、限流与站点导航行为。
- 每日数量解析、日期范围、零贡献、闰年、语言和年份差异；页面显示总数与逐日合计是否一致。
- 当前访问者的可靠识别、登录切换与缓存失效；权限或私有贡献可见性变化。
- 内容脚本、资源加载和所需权限的最小组合；Chrome / Edge 的实际行为。
- 20 年数据下 City 与 Terrain 的性能、静止帧停止、后台暂停与资源释放。

上述均不能因产品选型已确认而标记为已验证。

## 后续设想

只有扩展取得真实使用与传播反馈后，才考虑另立免费独立网站项目，承载确实受扩展形态限制的体验。目标是传播、引流与声誉，不是收费。现在不建设网站，也不为它提前加入登录、服务器或通用平台框架。

截图导出、动画导出、可分享作品链接、扩展独立大视图、自动画质分级和社区协作可记录为候选，尚非首版交付承诺。仓库已于 2026-10-29 按用户决定公开；开源许可证和商店发布策略尚待决定。
