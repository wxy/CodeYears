# P1-B · 访问者隔离与年度缓存

状态：原型已通过 [PR #5](https://github.com/wxy/CodeYears/pull/5) 合入 `e502e32`，构建与 18 项受控主线检查通过；修复 `adb5eab` 已通过真实 Chrome 已登录缓存主流程，跨年有效期修复 `2220030` 的 9 项针对性检查通过。真实身份矩阵及 Edge 待验收，详见 [报告](../reports/P1-B-VIEWER-CACHE.md)。原分支 `codex/p1-viewer-cache`；从 `main`（`12b00e2`）开始，后续验收由 P1-G 收敛。

## 主线范围

- 增加 `chrome.storage.local` 按访问者、主页和年份隔离的年度缓存，仅保存日期/数量和必要版本、抓取时间。
- 已知身份在缓存读取前、结果使用/写入前通过同源主页请求重新确认；身份不明不读写缓存，变化或取消不使用旧请求结果。
- 获取、缓存命中、强制刷新、清除此访问者在当前主页的缓存，明确报告缓存失败；后台隐藏后清空显示并取消请求。
- 先采用简单失效策略：当年 1 小时且跨日失效，历史年 30 天；不实现通用淘汰框架或后台预取。

## 必要验证

核心失败方式：A/B/未登录/身份不明作用域混用；请求期间身份变化或取消后写入；过期/损坏/旧版本缓存被使用；缓存读写失败妨碍有效网络结果或伪装成功；刷新失败覆盖有效缓存；清除误删其他作用域。先写受控浏览器检查再实现，真实 API 边界只在无法可靠构造账户/存储状态的地方模拟。

验证正常写入和命中、作用域分离、刷新/清除、身份变化/取消、过期/损坏及缓存读写失败；类型、MV3 构建通过后交付独立 PR。真实 Chrome 单账户缓存主流程已验证；A/B/退出登录、跨标签页和 Edge 验收仍单列，不把受控输入当作真实身份隔离验收。

非目标：City/Terrain 集成、SSO 权限变化全矩阵、反复账户瞬时往返的检测、极端并发机制、收费或网站。P1-G 未通过前不进入正式 3D MVP。

云端并行任务 `codex/time-travel-probe` 只改时间轴与独立演示、自己的任务/报告；本任务独占缓存、GitHub 适配、主入口/权限和全局文档。两者独立 PR，不互相等待非相关验收。
