# 年度历史组装任务 C

日期：2026-10-30。范围：独立 City / Time Travel 数据前置模块；不代表 P1-G 或正式 City MVP / P2 完成。

## 职责与边界

新增 `src/data/history.ts`，输入期望主页、年度列表、已校验的 `ContributionYear`；输出只读每日快照、已提供/缺失年份及完整/部分状态。真实日期字符串直接排序，不转换时区、不补零、不改数量。不涉及请求、缓存、GitHub 适配、时间轴或 UI 集成。

主页登录名忽略大小写；重复期望年度、重复记录年度、跨主页和非所需年度直接拒绝。内部逐日日期/数量不重新校验。调用方负责提供同一有效访问者作用域的数据，不能把主页名作为访问者身份。

`complete` 仅表示所有期望年度都有记录，当年可能只覆盖到解析截止日。空期望/空记录为 complete；非空期望/空记录为 partial。输出使用冻结的独立快照，不冻结或修改输入，无播放状态或播放动作。

## 实现前确定的失败方式

1. 年份/每日输入乱序导致历史日期错序。
2. 闰日或真实零数量被过滤，缺失日期/年份被填零。
3. 缺年被误报完整。
4. 重复年度、其他主页、非所需年度被静默合并。
5. 原地排序或共享可变对象修改调用方输入/返回快照。

先在系统临时目录写隔离检查并运行（模块尚不存在，ERR_MODULE_NOT_FOUND），再实现模块。检查和复现输入见报告；没有新增测试依赖或实现后补单元测试。
