# 魔法小镇独立地图类型

2026-11-11 用户授权：将模型接入扩展，增加独立地图类型；首版按贡献强度与区域组织聚落，悬停沿用真实项目和活动摘要。绘制、校准并行，主代理负责正式接入。实现经 PR 交付，当前未获发布授权。

## 主线与验收

1. **素材与透视**：已接入圆形观星台、法师工坊、温室、炼金庄园、行会、学院，以及居民、花树和魔法公共设施；畜舍源图含动物。不准入比例不一致的旧动物组合、集市、长椅及旧整图农场。共同人尺度的44张运行 PNG由共享离线流程生成，原始设计源图保留；手工包络、推定和精确像素验收分开记录。
2. **独立组织模型**：已实现七列分别为周一至周日，每行一周，按 ISO 周年归属；同强度档的相邻真实日期组成不同长宽的矩形。当前最多十六日、每边最长四格，不以固定四周或十三周窗口强切；未知日期不补零。按真实院落尺寸选建筑，全部倍率为1，每栋各有围院；低强度大区域可组合长屋/农舍与独立畜舍，空余地安排菜畦、花树与支路。
3. **扩展接入**：现代城市与魔法小镇选择入口，类型切换复用已核对的同一贡献快照；现有身份核对、数据缓存边界不变。小镇使用自己的庭院、边界路网和公共空间，复用缩放、平移、命中和悬停。类型切换失败或取消不误换旧视图。
4. **验证与交付**：编译、受控真实浏览器的入口/切换/悬停/隐藏恢复/失败取消路径；真实数据与一/二十年代表样本完成规划及实际绘制，验证覆盖、守恒、地块退让和资源释放。只长期保留报告，真实数据、截图等过程文件清理。更新现有 PR，不将本机受控路径写成登录 MV3、Edge 或性能预算已通过。

## 产品约定与候选

- 面积决定平面/组合，区域均值决定工艺、设施及繁荣形态；高度不是贡献数的线性编码。人物、动物与公共设施不代表真实贡献者人数、项目数量或额外贡献。
- 贡献类型和项目目前来自按需悬停活动查询。首版不新增分类批量请求，不从每日总量猜提交、评审或 Issue；用户已选择先保留真实项目摘要。
- 河谷沿路街镇、阶段聚落群与中心环形街区仍是布局候选，见 [组织形式比较](../design/ancient-town-concepts/2026-11-11/ORGANIZATION-OPTIONS.md)。首版不同时引入多套布局，也不把示意图当真实数据重排通过。
