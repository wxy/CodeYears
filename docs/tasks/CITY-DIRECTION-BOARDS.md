# 出城方向牌与整段道路访问

日期：2026-11-11。状态：实现与直接路径验证完成，已重建本机 `dist/`；尺寸与画面仍需用户本地验收。继续更新 PR #79，不自动合入；实际证据见[方向牌报告](../reports/CITY-DIRECTION-BOARDS.md)。

## 本轮需求

- 路牌采用道路自己的方向和地图透视，不只左右镜像。
- 牌面直接显示目的城市名；没有目的地时显示“？”。
- 牌面、支架与建筑一样使用世界尺寸，随缩放一起变化，不设置屏幕像素保底或上限。
- 已指定的整段出城道路可直接前往目标；小路牌不再承担唯一点击入口。
- 保留本人编辑、四至八条出城路、独立多跳返程及原有贡献数据规则。

## 本轮方案选择

先实现“大型路侧指示牌 + 整段道路点击”。牌面承担名称，保持现有道路宽度；路面写名、加宽道路作为后续候选，不同时叠加两套常驻文字。现代城市用金属导向板，小镇用木制告示板；名称在牌面显示，编辑卡片保留完整名称和修改入口。

牌面和立柱使用 Canvas 的同一世界投影，名称沿牌面方向排列并保持正向可读。接近侧视的分岔牌轻转 30°，额外出口向外拉开，返程牌退到对侧草地，避免遮住相邻名称。点击区域使用同一计划的牌面/路面多边形；空路仅本人可设置，其他访问者查看未知信息。拖动地图与点击道路区分，避免拖动后跳走。

尺寸按世界单位试排，不把初次选择写成用户已定稿的美术规范。长账号允许牌内分行；不增加文字的屏幕固定字号。返程牌同样缩放，仍不占出城道路名额。

## 实施顺序

1. 以当前源码的 `20–46px` 尺寸钳制和横向镜像为已定位原因，移除屏幕尺寸约束。
2. 集中计划牌面、文字、支架和命中范围，使用道路切向与竖直高度投影绘制；复用既有按需帧，不增加连续动画。
3. 接入城市名、问号与返程标题；已指定路面继续直达，空路点击按本人权限处理。
4. 验证方向、缩放比例、名称、道路点击和拖动取消；复核本人权限和返程不受影响。
5. 更新报告、同一 PR 与用户要求的本机 `dist/`。
