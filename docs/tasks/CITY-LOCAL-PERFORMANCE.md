# City 本机性能基线

日期：2026-10-31。起点：`e432b1020518df414819b7202f305e53fbda218d`（PR #15 合入），分支 `codex/city-local-performance`。

## 目标与边界

在实际本机 Chrome 中，为当前 Canvas 2D City 建立可复现的二十年常规数据性能基线。关注首次素材准备、全景生长、5 倍与细节上限、生长暂停和实际平移；不修改正式渲染器、素材、数据/缓存、权限或依赖。

只交付本任务及对应报告，通过独立 PR 提交，不自动合入。其他本地验收任务先独占浏览器操作权；本任务在准备完成后等待协调者授权，再使用实际 UI 测量，避免并发干扰。云端结果、旧 3D 原型结果和本轮 Canvas 结果分别绑定版本。

## 输入与方法

- 复用正式 `generateDays('regular')`：UTC 2006-01-01 至 2025-12-31，7,305 天，LCG 种子 20060101；只用示例数量，不读取真实账号数据。
- 独立临时页面直接导入本分支 `createLandscape`；最小临时插桩记录单次 `layer.draw` CPU 提交耗时、该渲染器的 RAF 时间戳、素材解码/烘焙准备总时间、位图创建/关闭及可观察画布尺寸。
- 指标通过临时页面的可见 DOM 展示，浏览器只经正式 UI 操作并读取 DOM，不通过隐藏运行时或未经允许的 CDP 脚本测量。
- 实测实际窗口所在屏幕；25 Hz 与 60 Hz 分开说明，不把显示器节奏算成代码优化或退化。实际 GPU 支持能力与 Canvas 是否硬件加速分开，无法直接观测的后端不推断。
- 首轮只用常规数据。仅当实际失败指向密度差异时再扩大矩阵；不测与本次热点无关的数据请求、账户或极端时序。

## 记录与停止条件

报告记录环境、输入、可重复命令、测量位置、样本数、实际结果及局限。CPU 提交耗时不等于 GPU 时间，位图和画布像素数不等于浏览器内存或显存；未可靠测得的内存、功耗明确列为未验收。不在本轮为取得更好数字实施优化。

完成必要路径后停止重复测试，关闭本任务窗口/标签，停止临时服务，删除临时输入、配置、Swift 缓存和过程输出；只将任务和报告加入 Git。用户使用的项目 `dist/`、原窗口和原始素材保持不动。

实际数值、尖峰与未验收范围见 [本机性能报告](../reports/CITY-LOCAL-PERFORMANCE.md)。
