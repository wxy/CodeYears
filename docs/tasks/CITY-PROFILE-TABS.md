## 最新加载流程修正

- 所选展示年份只作为布局元数据，先准备完整空场地和路网；未返回、未提供或未来日期保持待填充，不生成虚假0数量日期或当作真实零贡献选材。
- 复用原身份确认、年度缓存、ISO 源年与日期筛选。逐年返回的已校验累计快照按所选窗口筛选后驱动 City，合并地块整体填入，素材只按新批次实际需要增量加载；不等所有数据读完后再统一裁切生长。
- 新数据批次可以重新规划建筑，最终日期索引、合并及贡献映射规则不变；观看缩放、平移和展开不重新规划。完整缓存走同一真实数据填入过程与短过渡，不人为拖慢或另开重播流程。
- 正式 City 移除进度条、暂停/继续、跳过、重播等独立生长控制，保留必要状态说明、取消、年份选择、缩放平移/全景和展开。
- 必要源年失败或取消后清除已显示的部分数据地块，回到空场地/路网并提供重试；不将部分结果留作成功，也不改写已经校验的年度缓存。
- 主代理负责 content 与入口接线，渲染子代理负责 City/landscape 的批次填入；文档子代理仅同步本任务、PRODUCT、ARCHITECTURE。权限、身份/缓存/解析/源年规则、正式素材文件、公共时间轴、Terrain 及旧预览不改。按实际验证范围记录，历史报告不改写为新流程通过。

## 最新布局修正

- 贡献日历与 root 内 Activity overview/蜘蛛图一起切换，替代前轮仅隐藏日历、Activity overview 仍留的做法；root 外 Contribution activity 流水保持可见。
- 原生 h2 内从左到右为 City、贡献图、GitHub 原统计文字，原设置保持原节点；默认仍是贡献图。City 模式隐藏原统计和原设置，不向顶部另造合计或状态。此修正覆盖上一轮“顶部统计随视图变化为城市合计”的方案，去除城市统计节点及面板统计回调。
- City 保留自己的年份选择、缩放与展开等控件；内部局部摘要仅展开时显示，加载/失败/取消仍在 City 自身面板提供反馈。顶部轻量入口不因此提前读取贡献数据。
- City 常态不再新增大边框、圆角卡片包围；展开 dialog 保留必要边界与控件。窄屏统计和 tab 可以换行，但不能溢出贡献区。
- 上述布局继续成立；新加载流程按前节扩大面板/渲染调度，仍保持默认原图与点击后才取历史。主代理维护入口/面板及报告/README/开发计划，历史报告不改写为新流程验收。

## 已确认范围

1. GitHub 个人贡献区自动出现左侧“城市 · CodeYears”、右侧“贡献图”切换入口，默认选原图。不自动获取历史、加载城市素材或创建渲染器；点击城市后读取默认最近三年，可改范围后应用。
2. 日历与 Activity overview/蜘蛛图作为整体切换，保留原生 DOM 和 root 外流水，可随时切回；原统计文本及原设置仅原图模式显示。tab 位于原生 h2 最左侧，City 顶部不另造统计，常态无额外卡片框，不上下堆叠整张面板；取消重复标题和两层关闭。
3. 页内画布先试约 340px，自适应宽度；在当前页面内展开查看，Esc/关闭返回紧凑视图，保留当前实例和视角。继续缩放、平移和“全景”。
4. 点击城市先出完整空场地/路网，再逐年填入已校验真实地块，未返回日期保持待填充；短过渡由数据到达驱动。移除正式入口的进度条和独立生长控制，取消保留；完整缓存同路径填入，不人为拖慢。失败/取消清部分数据地块并回空场地+重试，切换后重新核对身份。
5. 数据说明、逐日明细、刷新/清缓存、右键保存帮助收进“更多”。不恢复图片生成或分享功能。入口和控件支持键盘焦点及状态表达。
6. 自动入口声明仅 GitHub 的内容脚本匹配范围，不新增 Cookie、所有网站权限或后端。保留工具栏快捷打开；移除弹窗中的二次确认。

只在页面识别边界检查 URL/贡献容器/年份，继续复用身份确认、年度缓存和 ISO 源年筛选。不改素材源文件、最终空间/数据映射或公共时间轴契约；数据批次可重规划，观看缩放不重规划，不提前增加通用扩展框架。

## 核心失败路径与停止条件

需要覆盖：未点城市无历史/素材加载；点击先有完整场地/路网，预留年份不制造日期或零贡献；逐个公历源年已校验快照填入真实地块，合并单元整体出现，素材增量；全缓存同路径且无人工等待；数据批次可重规划但缩放不重规划；失败/取消清部分数据画面回空场地+重试，晚到结果不能回填旧请求；无进度条或独立生长控件。

同时保留入口与资源边界：非个人页/延迟日历/Turbo 不重复或遗留隐藏；左 City/右贡献图且默认原图，City 不显示原统计/原设置或顶部新合计；切回恢复原生内容，root 外流水不受影响；后台取消并清空，身份不明不复用缓存；展开退出/焦点、窄屏不溢出及关闭释放；原图还原不删除 GitHub DOM。

优先端到端，使用正式构建及明确合成数据验证这些路径；不事后补单元测试。真实 MV3 的站点访问提示、自动注入、资源及导航仍须用户可见环境验证。目标路径通过后停止，不为次要边界扩展复杂度。过程文件放系统临时目录并清理，仅保留报告。
