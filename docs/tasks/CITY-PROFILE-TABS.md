# 贡献区城市视图改造

来源：2026-11-01 用户确认前一轮产品评估，要求制定计划并实施。基线为 PR #37 发布准备分支 `12c847f`；本地实现分支 `codex/city-profile-tabs`，向发布准备分支提交独立 PR，不自动合入。#35 分享实验继续暂缓，#38 资源压缩独立交付，不混入本轮。

## 已确认范围

1. GitHub 个人贡献区自动出现“贡献图 / 城市 · CodeYears”切换入口，默认原图。不自动获取历史、加载城市素材或创建渲染器；点击城市后读取默认最近三年，可改范围后应用。
2. 城市占用原图对应位置，保留原生 DOM，可随时切回；不再上下堆叠整张控制面板。取消重复品牌标题、“关闭城市”和“关闭 CodeYears”。
3. 页内画布先试约 340px，自适应宽度；在当前页面内展开查看，Esc/关闭返回紧凑视图，保留当前实例和视角。继续缩放、平移和“全景”。
4. 加载显示真实进度及取消；生长显示暂停/继续与“直接查看”；完成后显示重播。City 生长约三秒；不修改公共时间轴默认时长。切换回城市不强迫重播，仍先核对身份。
5. 数据说明、逐日明细、刷新/清缓存、右键保存帮助收进“更多”。不恢复图片生成或分享功能。入口和控件支持键盘焦点及状态表达。
6. 自动入口声明仅 GitHub 的内容脚本匹配范围，不新增 Cookie、所有网站权限或后端。保留工具栏快捷打开；移除弹窗中的二次确认。

## 实施顺序与边界

| 阶段 | 文件/职责 | 验收 |
| --- | --- | --- |
| A | 独立轻量入口、manifest/构建、工具栏快捷打开 | 原图默认可见，未点击不请求历史/不加载城市；贡献区延迟出现、Turbo 站内导航、重复注入不产生重复入口 |
| B | 城市面板与状态控件、按需加载 | 点击即加载；范围应用、错误重试、取消、数据明细/清缓存直接路径；原数据/解析/缓存模块不改 |
| C | 紧凑/展开、City 三秒生长与焦点 | 展开/退出保留同一画布和取景；全景/暂停/直接查看/重播；关闭与后台释放资源并隐藏敏感结果 |
| D | 权限/隐私/产品文档、打包、受控与真实验证 | build/check/package 及直接受影响的完整 UI 路径；真实 Chrome 重载与自动注入单独记录，受控页面不冒充 MV3/Edge |

只在页面识别边界检查 URL/贡献容器/年份，继续复用身份确认、年度缓存和 ISO 源年筛选。不改素材、布局、数据含义或公共时间轴契约，不提前增加通用扩展框架。

## 核心失败路径与停止条件

需要覆盖：非个人页不插入；日历延迟及站内切换不重复/不遗留原图隐藏；模块或图片失败仍可回原图/重试；加载取消与切换标签取消请求，晚到结果不重建已离开的城市；后台清空可见数据，身份不明不复用缓存；展开 Esc/按钮退出与焦点恢复；原图还原不删除 GitHub DOM。

优先端到端，使用正式构建及明确合成数据验证这些路径；不事后补单元测试。真实 MV3 的站点访问提示、自动注入、资源及导航仍须用户可见环境验证。目标路径通过后停止，不为次要边界扩展复杂度。过程文件放系统临时目录并清理，仅保留报告。
