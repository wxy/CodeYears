## 最新布局修正

- 贡献日历与 root 内 Activity overview/蜘蛛图一起切换，替代前轮仅隐藏日历、Activity overview 仍留的做法；root 外 Contribution activity 流水保持可见。
- 切换入口放在原生 h2 顶部统计行，替代单独一行。原生模式恢复原统计文本，City 模式显示所选年份实际可信范围的合计；加载/失败/取消显示相应状态，不能沿用原生或旧 City 总数。必要源年未完整成功时不显示部分合计为成功。
- City 常态不再新增大边框、圆角卡片包围；展开 dialog 保留必要边界与控件。窄屏统计和 tab 可以换行，但不能溢出贡献区。
- 本轮只修改展示组织、状态和统计接线。主代理独占 entry/content、报告/README/开发计划；文档子代理只同步本任务、PRODUCT、ARCHITECTURE。权限、数据缓存、素材、City 空间规划及时间轴不变，默认原图与点击后才读历史不变。历史报告不改写为新布局验收。

## 已确认范围

1. GitHub 个人贡献区自动出现“贡献图 / 城市 · CodeYears”切换入口，默认原图。不自动获取历史、加载城市素材或创建渲染器；点击城市后读取默认最近三年，可改范围后应用。
2. 日历与 Activity overview/蜘蛛图作为整体切换，保留原生 DOM、原统计文本和 root 外流水，可随时切回。tab 与原生 h2 同行，City 常态无额外卡片框，不上下堆叠整张面板；取消重复标题和两层关闭。
3. 页内画布先试约 340px，自适应宽度；在当前页面内展开查看，Esc/关闭返回紧凑视图，保留当前实例和视角。继续缩放、平移和“全景”。
4. 加载显示真实进度及取消；生长显示暂停/继续与“直接查看”；完成后显示重播。City 生长约三秒；不修改公共时间轴默认时长。切换回城市不强迫重播，仍先核对身份。
5. 数据说明、逐日明细、刷新/清缓存、右键保存帮助收进“更多”。不恢复图片生成或分享功能。入口和控件支持键盘焦点及状态表达。
6. 自动入口声明仅 GitHub 的内容脚本匹配范围，不新增 Cookie、所有网站权限或后端。保留工具栏快捷打开；移除弹窗中的二次确认。

## 实施顺序与边界

| 阶段 | 文件/职责 | 验收 |
| --- | --- | --- |
| A | 独立轻量入口、manifest/构建、工具栏快捷打开 | 原图默认可见，未点击不请求历史/不加载城市；贡献区延迟出现、Turbo 站内导航、重复注入不产生重复入口 |
| B | 城市面板与状态控件、按需加载 | 点击即加载；范围应用、错误重试、取消、数据明细/清缓存直接路径；原数据/解析/缓存模块不改 |
| C | 紧凑/展开、City 三秒生长与焦点 | 展开/退出保留同一画布和取景；全景/暂停/直接查看/重播；关闭与后台释放资源并隐藏敏感结果 |
| D | 权限/隐私/产品文档、打包、受控与真实验证 | build/check/package 及直接受影响的完整 UI 路径；真实 Chrome 重载与自动注入单独记录，受控页面不冒充 MV3/Edge |

只在页面识别边界检查 URL/贡献容器/年份，继续复用身份确认、年度缓存和 ISO 源年筛选。不改素材、City 空间布局、数据含义或公共时间轴契约，不提前增加通用扩展框架。

## 核心失败路径与停止条件

需要覆盖：非个人页不插入；日历延迟及站内切换不重复/不遗留原生日历或 Activity overview 隐藏；模块/图片失败和取消时，顶部不能残留原生或旧 City 总数且仍可回原图/重试；切回恢复两块原内容及原统计文本，root 外流水不受影响；晚到结果不重建已离开的城市或覆盖当前标题；后台清空可见数据，身份不明不复用缓存；展开 Esc/按钮退出与焦点恢复；窄屏统计/tab 换行不溢出；原图还原不删除 GitHub DOM。

优先端到端，使用正式构建及明确合成数据验证这些路径；不事后补单元测试。真实 MV3 的站点访问提示、自动注入、资源及导航仍须用户可见环境验证。目标路径通过后停止，不为次要边界扩展复杂度。过程文件放系统临时目录并清理，仅保留报告。
