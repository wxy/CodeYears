## 目标与边界

复用本机已加载的项目 `dist/`，核对真实 Chrome 中的生成、近景、播放/视图切换、关闭、后台返回及页内导航。只维护本任务与 [报告](../reports/CITY-LOCAL-BROWSER.md)，不修改产品源码、素材、权限、依赖、全局文档或主目录构建，不切换主目录分支。

云端示例或本地受控页面不能代替真实会话；本任务也不替代 A/B/退出登录、私有可见性、Edge 或性能预算的完整验收。真实贡献总数、逐日数量、页面响应、缓存和凭证不进入报告或 Git。

## 直接路径

1. 在已有 GitHub 个人主页中生成所选缓存历史，核对年份/日期数、来源和单画布；原生日历保留。
2. 重播、暂停、City/Terrain 往返，核对暂停进度与单画布；继续、跳过、近景缩放和平移。
3. 关闭风景并重新生成，核对画布移除和恢复。
4. 原生切走/返回，核对结果清空及重新核对身份提示；若控制工具改变可见性，单列无法定论，不把工具状态当成产品结论。
5. 通过 GitHub 真实年度链接导航，核对扩展清理、原生日历和目标页面。

## 停止与交付

覆盖直接路径后停止；不扩大极端时序。发现严重问题先报告，不自行修改源码。测试仅保留可复现报告，不保留截图、日志、真实数据或临时构建。独立 PR 向 `main` 交付，不自动合入。
