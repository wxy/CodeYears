# v1.0.0 — Explore your GitHub contribution city

## What's New

- Switch between GitHub’s original calendar and a miniature city on the contribution graph. Open City to explore years of contributions at a larger scale.
- Explore tree-lined streets, river crossings and villages outside the ring road. Hover over a village to see when its public repository was created.
- Follow exit signs to people mentioned in the profile’s Bio. Blank signs offer short English examples you can copy into your own Bio.

## Fixes & Engineering

- Continue the main rivers past the ring road before turning, with bridges aligned to road crossings.
- Find the data visibility rules under More → Data privacy. The settings popup points to Chrome’s extension details when automatic access to GitHub needs to be enabled.

## Deployment Notes

- Use `codeyears-1.0.0-city.zip` to update the existing Chrome Web Store listing. Preferences and annual contribution records use the existing local storage keys.
- [Store materials](../store/city-1.0.0/README.md) include updated English and Simplified Chinese descriptions and review instructions. All four screenshots in each group come from the previously approved material.

## Verification

- See the [1.0.0 verification report](../reports/CITY-1.0.0-RELEASE.md) for package checks and Chrome coverage.

## 新功能

- 在 GitHub 原图和贡献图中的微缩城市之间切换，或打开「城市」浏览多年的贡献地图。
- 探索林荫路、河流和跨河桥。悬停环外村庄可查看对应公开仓库的创建日期。
- 沿路牌去往个人简介中提到的账号。点击空白出口牌，可复制适合放在 Bio 里的英文例句。

## 修复与工程

- 主河穿过外环后保持直行一段距离，桥梁与跨河路段对齐。
- 「更多」中的「数据隐私」说明各类记录的可见范围。Chrome 需要开启 GitHub 自动访问时，设置弹窗会提供扩展详情入口。

## 部署说明

- 使用 `codeyears-1.0.0-city.zip` 更新现有 Chrome 商店条目。界面偏好和年度贡献记录沿用原有本地存储键。
- [商店材料](../store/city-1.0.0/README.md)提供更新后的英文、简体中文详细说明及审核步骤。各组沿用此前确认的四张截图。
