# v0.1.2 — A city shaped by your contributions

## What's New

- Explore irregular neighborhoods shaped by active plots, with wilderness between long quiet periods and roads connecting separated districts.
- Discover more homes, shops, civic and cultural buildings, clearer English road labels, refined static vehicles and signals, and two bridge styles.
- Hover over a highlighted building for time patterns, related repositories and approximate commit, PR, review and issue totals. Details load on demand and reuse a five-minute page-local cache.
- Mark an explicitly confirmed “Joined GitHub” day with a distinctive tower. The milestone keeps its original single-day contribution record.

## Fixes & Engineering

- Reuse the completed city, layout, decoded artwork and unchanged canvas when returning from GitHub's graph or a background tab, after confirming identity and cache validity. Load up to two source years in parallel.
- Improve shared annual roads, quarter-road widths, rounded bends, signalized junctions, short feasible district connections and bridge supports/approaches. Normal empty activity results no longer produce warnings.
- Relabel the former 150% view as 100%; set a 50% minimum and a 2000% ceiling, subject to the existing artwork detail limit.

## Deployment Notes

- Keep the CodeYears name. This release includes the accepted mainline city changes; the five city-polish prototypes in PRs #71–#75 are excluded.
- Download `codeyears-0.1.2-city.zip` and its SHA-256 file from this release. Chrome Web Store upload, review and publication are separate; submission of 0.1.2 has not been confirmed.
- No new extension permissions, token, separate login, backend or telemetry. Hover details stay in page memory; contribution dates/counts retain their existing scoped local cache. Live identity checks still require a network connection.
- See the [privacy policy](https://github.com/wxy/CodeYears/blob/v0.1.2/PRIVACY.md) and [release verification report](https://github.com/wxy/CodeYears/blob/v0.1.2/docs/reports/CITY-0.1.2-RELEASE.md) for data handling, package details and evidence boundaries.

## Verification

- The release package is checked against a fresh build for version consistency, ZIP integrity, inventory, resource references, permissions, localization and notices.
- Prior feature reports distinguish controlled Chrome checks from user confirmation on GitHub. Release-specific checks are recorded in the verification report.
- Edge, a separate-account visibility matrix and long-term memory/GPU/power budgets have not been independently verified. GitHub activity pages are not a stable API; project summaries are explanatory, not complete statistics.

## 新功能

- 城市轮廓随活动地块变化，长空闲区域保留为野外，分离街区通过公路连接。
- 增加住宅、商铺、公共及文化建筑，完善英文路名、静态车辆与红绿灯，并提供两种桥梁。
- 悬停建筑时高光，以简洁浮层解释时间规律、相关仓库及大致提交、PR、评审和Issue数量；按需读取，详情在同页内存中复用五分钟。
- 明确确认“Joined GitHub”单日事件后，用独特高塔纪念加入GitHub；保留原始日期与数量。

## 修复与工程

- 切回官方贡献图或其他标签页后，核对身份与缓存期限，复用完整城市、布局、素材和未变化的画布；最多并行读取两个源年。
- 改善年度共用道路、季度路宽、圆角、平交路口、片区较短可行连接，以及桥墩和引桥；正常空活动不再输出警告。
- 原150%取景改标100%，最小50%、最大不超过2000%，仍受素材细节上限约束。
