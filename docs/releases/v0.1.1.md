# v0.1.1 — A smaller city, a closer view

## What's New

- Explore the city with a compact Fit view / percentage / Maximum zoom toolbar. Use the wheel or keyboard +/− to zoom.
- Start the City view at 150% for a closer default view; Fit view still shows the complete city.
- Find CodeYears under its localized name: **CodeYears: GitHub Contribution City** / **CodeYears：GitHub 贡献之城**.

## Fixes & Engineering

- Reduce the extension ZIP from 112.53 MB to 7.87 MB, about 93%, by distributing pre-baked runtime artwork.
- Preserve all original artwork and calibration files in the repository. Keep current rendered pixels, building placement and contribution counts unchanged in the verified Chrome paths.
- Prepare complete English and Simplified Chinese screenshot sets; the global set matches the English set.

## Deployment Notes

- This package is version 0.1.1. Chrome Web Store upload and submission are performed by the maintainer; preparing this release does not mean the store update is live.
- `codeyears-0.1.1-city.zip`: 77 files, 7,870,656 bytes; SHA-256 `43d3f9f028c5d5bf6683a1b378a82df8dd10b0fa74d9e9c7bdd9858afb4b3898`.
- The current published Chrome Web Store version is 0.1.0. Store review and GitHub release status are tracked separately.
- No new permissions, remote asset service, account, token, backend or telemetry. Existing local language preferences and contribution caches are unchanged.
- The original 0.1.0 ZIP remains preserved. Code and artwork licensing remain separate under LICENSE, ASSETS.md and THIRD_PARTY_NOTICES.md.

## Verification

- Tests: 57 runtime images and nine complete 1/3/20-year scene comparisons match the prior rendering pipeline pixel-for-pixel in local Chrome. Real GitHub loading, zoom/expand, graph switching and cancel/retry paths passed.
- Builds: TypeScript checks, release build, ZIP CRC, inventory, resource references, versions, permissions and notices passed for the 77-file 0.1.1 package.
- Edge, cross-platform pixel equivalence, full assistive-technology coverage and long-term memory/GPU/power budgets were not independently verified.
