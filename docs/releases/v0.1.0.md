# v0.1.0 — Contribution City milestone

## What's New

- Open a City view directly in GitHub profile contribution sections, with multi-year selection, gradual filling, pan, zoom and an expanded view.
- Use English or Simplified Chinese, with a saved browser-local language preference and a native extension Options page.
- Read daily contribution counts through the existing GitHub session. No token, separate account, developer backend, ads or telemetry.

## Fixes & Engineering

- Yearly caches are scoped to the viewer and profile, with live identity checks, refresh and clear actions.
- Cancel loading and release the city when returning to GitHub's graph, hiding the page or navigating away; the renderer stops continuous frames when idle.
- Include the application icon, runtime artwork notices, bilingual store materials, and published homepage, support and privacy pages.

## Deployment Notes

- This is the first GitHub milestone. **Chrome Web Store submission is still under review**, as confirmed by the maintainer; no verified store installation link is available yet.
- Download `codeyears-0.1.0-city.zip`, verify its SHA-256, extract it into a permanent folder, then load that folder as an unpacked extension in Chrome's developer mode. Open a GitHub profile and choose City.
- The attached ZIP is the frozen 0.1.0 candidate previously supplied for submission, not a rebuilt package. It has 79 files, 112,526,864 bytes, SHA-256 `b0f004a227a68d8acce314343cf91cc053121a35ca09f009aa48106a99208018`. The exact file uploaded to Google's console was not independently inspected.
- Edge, Terrain, Signature/Natural theme selection, and the compact fit/percentage/maximum toolbar are not part of this milestone. The compact toolbar is deferred to the next version; 0.1.0 retains its existing zoom buttons.
- Code is MIT-licensed; artwork and dependencies retain the separate terms in ASSETS.md and THIRD_PARTY_NOTICES.md.

## Verification

- Existing release checks passed: build/type checks, package inventory, CRC, references, permissions, licenses and notices. The frozen package remains byte-for-byte unchanged.
- Local Chrome acceptance covers reinstall, default graph/City entry, contribution loading, cache actions, menus, language settings, expansion and native background cancellation/resume. User-performed browser-management and native Options steps are identified in the reports.
- Bilingual official/support/privacy pages and store media have their own verification records. These do not replace real extension or hardware acceptance.
- Edge, a full accessibility matrix, long-term memory/GPU/power budgets and a dedicated multi-account matrix were not verified. The maintainer explicitly removed dedicated account-isolation testing from this release scope; prototype 60 Hz observations are not a current City FPS claim.

## 新功能

- 在GitHub个人贡献区直接切换城市，选择多年范围，逐年填入地块，支持平移、缩放和页内展开。
- 英文与简体中文，可保存本地语言偏好，并通过扩展原生“选项”设置全局语言。
- 使用已有GitHub会话读取每日贡献数量，无Token、独立账户、开发者后台、广告或遥测。

## 修复与工程

- 年度缓存区分访问者和主页，使用前核对实时身份，支持刷新与清除。
- 切回原图、后台或离开主页时取消请求并释放城市，静止时停止连续帧。
- 正式图标、素材/依赖说明、双语商店媒体和已上线的官网、支持、隐私页面均有对应记录。
