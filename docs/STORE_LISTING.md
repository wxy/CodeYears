适用版本：0.1.0 发布候选。尚未上传、提交审核或上线。只描述当前 City，不宣传 Terrain、独立图片生成、分享服务或未实现主题。

## 可复制文案

名称：**CodeYears · 贡献之城**

简短说明：把 GitHub 的每日贡献，化作逐渐生长的城市。免费、本地缓存，无需 Token。

详细说明：

> 代码岁月，自成风景。
>
> 在 GitHub 个人主页打开 CodeYears，选择年份范围，看每日贡献从平地、草木长成街区、楼宇与奇观。固定视角支持放大和平移；可以暂停、继续、跳过和重播生长动画。已有缓存也可以从起点重播。
>
> 数据来自当前 GitHub 会话可见的每日贡献，不要求 GitHub Token 或独立登录。扩展没有后端、广告和遥测；年度数据只在当前浏览器本地缓存，并按访问者和主页隔离。
>
> 调整缩放和平移后，在城市图上右键，使用浏览器的“图片存储为…”或“复制图片”保存当前画面。
>
> 在“设置与数据说明”中可刷新或清除当前主页缓存，也可展开每日真实数量。年份按完整周组织，边界日期会归入相邻年份，因此画面合计可能与 GitHub 公历年度不同。
>
> 使用方法：进入 GitHub 个人主页，等待贡献日历出现，点击扩展图标并打开 CodeYears，再选择年份生成城市。仅在主动打开后运行，保留原 GitHub 贡献图。
>
> 当前为 City 预览版。GitHub 贡献页不是稳定公开 API，语言、页面结构或访问权限变化可能使获取停止；不会把失败或缺失数据当作零。当前主要验证英文贡献页面。Edge 仍待独立验收。

## 权限及隐私字段依据

单一用途：在用户主动打开的 GitHub 个人主页，将当前会话可见的每日贡献可视化为 City。

| 字段 | 与实物一致的说明 |
| --- | --- |
| activeTab | 用户点击扩展后，临时访问当前 GitHub 主页；不持久访问任意网站 |
| scripting | 注入安装包内的 CodeYears 面板；不下载执行远程脚本 |
| storage | 按访问者、主页和公历年缓存贡献日期/数量，并提供刷新与清除 |
| 远程代码 | 不使用。GitHub HTML 仅作为数据解析，程序和图片均在安装包中 |
| 处理的数据 | 主页用户名、访问者用户名/登录状态、所选范围、贡献日期数量及缓存元信息；本地处理仍应如实披露，不能直接勾选“完全不处理用户数据” |
| 传输 | 仅向 GitHub 发起同源请求；没有项目服务器、遥测或自动上传图片 |

以提交时控制台的实际分类填写；这份依据不是已提交表单。官方要求权限解释与数据使用声明匹配实物，并提供隐私政策链接：[隐私字段](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy)。
