## 可复制文案

名称：**CodeYears · 贡献之城**

简短说明：把 GitHub 的每日贡献，化作逐渐生长的城市。免费、本地缓存，无需 Token。

详细说明：

> 代码岁月，自成风景。
>
> 在 GitHub 个人主页的贡献区切换到“城市 · CodeYears”，看每日贡献从平地、草木长成街区、楼宇与奇观。首次默认最近三年，也可以修改年份范围后应用。固定视角支持放大、平移与全景，并可在页面内展开欣赏；可以暂停、继续、直接查看结果或重播生长动画。
>
> 数据来自当前 GitHub 会话可见的每日贡献，不要求 GitHub Token 或独立登录。扩展没有后端、广告和遥测；年度数据只在当前浏览器本地缓存，并按访问者和主页隔离。
>
> 调整缩放和平移后，在城市图上右键，使用浏览器的“图片存储为…”或“复制图片”保存当前画面。
>
> 在“更多”中可查看数据说明、刷新或清除当前主页缓存，也可展开每日明细。年份按完整周组织，边界日期会归入相邻年份，因此画面合计可能与 GitHub 公历年度不同。
>
> 允许扩展在 GitHub 运行后，个人贡献区会自动出现“贡献图 / 城市 · CodeYears”切换，默认仍显示原图。轻量入口不自动读取历史或加载城市素材；点击城市后才开始。随时切回贡献图，或通过工具栏快捷打开，无需弹窗二次确认。
>
> 当前为 City 预览版。GitHub 贡献页不是稳定公开 API，语言、页面结构或访问权限变化可能使获取停止；不会把失败或缺失数据当作零。当前主要验证英文贡献页面。Edge 仍待独立验收。

## 权限及隐私字段依据

单一用途：在 GitHub 个人贡献区提供可切换 City 视图，用户点击后将当前会话可见的每日贡献可视化为城市。

| 字段 | 与实物一致的说明 |
| --- | --- |
| GitHub 自动入口 | content_scripts.matches 仅 https://github.com/*，自动识别个人贡献区并挂轻量切换；不因此提前读取访问者/贡献缓存或加载城市。属于 GitHub 站点运行范围，不能填写成完全没有网站访问 |
| activeTab | 用户点击工具栏扩展后临时访问当前标签页，提供快捷打开 |
| scripting | 工具栏按需执行安装包内的入口脚本；不下载执行远程脚本 |
| storage | 按访问者、主页和公历年缓存贡献日期/数量，并提供刷新与清除 |
| 远程代码 | 不使用。GitHub HTML 仅作为数据解析，程序和图片均在安装包中 |
| 处理的数据 | 主页用户名、访问者用户名/登录状态、所选范围、贡献日期数量及缓存元信息；本地处理仍应如实披露，不能直接勾选“完全不处理用户数据” |
| 传输 | 仅向 GitHub 发起同源请求；没有项目服务器、遥测或自动上传图片 |

以提交时控制台的实际分类填写；这份依据不是已提交表单。官方要求权限解释与数据使用声明匹配实物，并提供隐私政策链接：[隐私字段](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy)。
