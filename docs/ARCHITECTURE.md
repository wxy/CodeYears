## 当前骨架

轻量入口与按需面板的职责不变：`entry.js` 仅在 GitHub 范围以 `document_idle` 运行，识别个人页 URL、贡献容器及年度入口。最新布局在原生 h2 内前置切换 host，顺序为“城市 · CodeYears”“贡献图”，后接 GitHub 原统计；原设置仍使用 GitHub 原节点。窄屏允许原统计和切换换行，但须限制在贡献区宽度内。默认原图，未点击不导入 `content.js`、不请求历史、不读写缓存或初始化渲染。

本轮切换边界为 `.js-yearly-contributions` root 内的贡献日历及 Activity overview/蜘蛛图整体。入口将原 h2 子节点保留到 `#codeyears-native-stat`，在其前放入 `span#codeyears-profile-tabs`；不再建立城市统计节点。城市内容由 h2 后的 `div#codeyears-city-content` 承载另一 Shadow DOM。城市模式临时隐藏日历对应的原生兄弟元素、`#user-activity-overview`、原统计和原设置；切回原图、后台或销毁时恢复保存的原生显示值和统计内容，不删除或重新挂载这组原生内容。root 外的 Contribution activity 流水不隐藏，销毁入口时解开原统计包裹并恢复 h2 原样式。

面板接口不再通过统计回调改写顶部 h2，城市模式不另造合计或顶部状态统计。City 内部继续维护年份范围、读取/失败/取消状态，可信范围的局部摘要仅在展开 dialog 时显示；常态摘要隐藏。顶部只负责模式切换，原统计文字和原设置仅原图模式可见。原始日期、数量与统计口径不因这项展示修正改变。

上述顺序和显示边界继续成立，覆盖前轮顶部显示城市合计，以及更早入口单独占行/Activity overview 仍留的方案。本轮进一步改造正式 City 的加载与显示调度，实际结果须以追加报告证明。轻量 DOM 观察继续配合 Turbo 导航处理延迟日历、重复执行与销毁，不轮询历史数据；权限、数据缓存、素材源文件和公共时间轴不变。

点击城市后才动态导入 `content.js` ES 模块并挂面板。面板的 activate/deactivate/dispose 分别负责开始读取、取消并清空/释放当前城市、移除实例和监听；入口选择代次与请求 AbortController 身份分别阻止晚到结果挂回已离开的城市或撤销新请求状态。工具栏沿用 activeTab/scripting 快捷定位并激活此入口，不再用弹窗中的“打开”作第二次确认。这是当前实现结构，实际 Chrome/Edge 注入、资源和导航证据仍须本轮验证。

P1-B 通过 `load-year.ts` 连接页面身份确认、缓存与年度请求；`year-cache.ts` 使用 `chrome.storage.local`，在读取边界校验作用域、版本、日期覆盖和有效期。已知身份在读缓存前、使用/写入结果前通过禁止浏览器缓存的同源主页请求再次确认；身份不明仅联网获取，不读写缓存。入口改造不更改这些模块及隔离规则，浏览器真实会话与跨标签页验收仍以报告为准。

正式 City 的新加载路径已实现待完整验收：面板激活后先把所选展示年份作为布局元数据交给渲染层，建立完整空场地及路网；此时不构造零数量的 `DailyContribution`，空位表示待填充而非零贡献。默认最近三年，修改范围后应用。ISO 周年推导相邻公历源年、`loadContributionHistory` 升序读取、年度缓存与身份确认均复用原路径。

每个源年完成后，面板消费加载器给出的已校验累计快照，按所选年份的真实日期窗口筛选，再把可用日期/数量交给正式 City 填入。合并地块以整体出现，不再把完整楼体按独立播放进度逐栋裁切；素材按新批次实际需要增量载入。新快照允许重新规划建筑，但最终数量/索引与合并映射规则不变；缩放、平移和展开只改变观看状态，不触发规划。完整缓存同样按已校验快照填入并作短过渡，不插入人为等待。

正式 City 不显示进度条或暂停/跳过/重播等独立生长控制，保留取消、年份选择与观看控制，必要的读取/失败说明仍由面板提供。任一必要源年失败或取消，都清除已显示的部分数据地块并回到空场地/路网，提供重试；这只清当前画面，不改变已经校验成功的年度缓存策略。最终完成后，城市、局部摘要与每日明细共用筛选后的可信数据；每日表格仍按需展开，不将加载中的部分结果宣称为完整历史。

面板常态无额外大边框与圆角包围；340px画布提供缩放/平移/全景，窄于500px的页面使用300px。展开将同一面板与画布移入原生 `dialog`，保留局部摘要、必要边界和观看控件；收起或 Esc 后放回原位，不重建渲染器或重新读取贡献。正式入口此前固定3000ms的独立生长不再使用，公共时间轴及 Terrain/旧预览行为不改。切换与展开的前轮证据只覆盖对应版本，新数据填入与失败清空路径待本轮验证。

原有 `createLandscape` 继续服务 Terrain 与旧预览，保留共享时间轴、有限动画帧、尺寸/主题监听和观看交互；本轮正式 City 另按上文使用数据批次驱动的填入路径。City 空间规划仍以周为列、周一至周日为行，完整周归周四所在 ISO 年，历史周年为52或53列；年界借取相邻公历源年，未提供/未来日期不填零。预留年份只影响空间范围，实际地块始终带有明确源日期索引与真实数量，不能用连续索引区间代表跨周成员。

每日真实数量固定分级：0自然地块、1–2平房（band0）、3–5低层（band1）、6–19公寓（band2）、20–49办公楼（band3）、50+大厦（band4）。平房只1×1，低层2×1/1×2/1×1；H2保持2×2/1×1，H3保留两向长条，H4保留2×2与两向长条。先对单日分档，再在同年度同档完整矩形内合并，保留成员索引/count/date；后到极值不改变既有日期档位。零值空旷邻域才可选池塘、草地和树木，城市邻域才可广场。第13/26/39周后插路，第53周在末段，不改日期、不跨路或缺失格。

`city-view.ts` 的 `planCityScene` 按占地、强度档与稳定位置选择素材；主色来自原图，不表示精确贡献数。2×2 可将合适的 1×1 建筑等比放大两倍；中高层缺少匹配长条素材时不合并为 2×1/1×2，不再以较小原生楼体和大庭院代替跨格楼体，仍不拉伸楼身。正式 City 可以在新的可信数据批次到达后重新规划，观看缩放只改变投影尺寸、平移、可见范围和采样质量，不重建合并。真实零贡献地块可按环境选择草地、池塘或广场；尚未返回日期的待填充空位不参与这种零值选材，五年景观带装饰另作表达。

City 通过视图的 `maxZoom(viewport)` 按全景适配比例计算细节上限，目标使一个逻辑格横向约 192 CSS 像素，最低保留全景 5 倍；Terrain 仍为 5 倍，切换时重新约束当前倍率。街区底面改为绿地庭院，建筑下方紧凑铺装与入户步道连接沿合并地块边界的窄支路，避免切开已融合建筑。远景地面在创建时绘入离屏缓存，比例上限 48、宽度预算约 3072 像素。高倍近看发现整张缓存放大会模糊，因此当投影比例 `scale > unit × 1.25` 时，改将可见矢量底面、道路与原烘焙平地贴图重绘到视口尺寸的近景缓存；仅尺寸、缩放或平移改变时重建，静止镜头下的生长动画复用它。销毁时近景、远景缓存一并清零；近看画质和实际开销单独验收。

City 地面、道路与组间公园由本地 Canvas 代码绘制，平地、植被和建筑使用随包图片。景观带从所选历史起点每五年一组，组内普通道路，组间增加公园/湖泊；只在已显示组之间留带，三年不插带、二十年三条，不依赖贡献强弱。

`city-unit-catalog.ts` 直接引用设计目录的标定 JSON，与本地标定工具共用 `unit-calibration.ts`，没有第二套量测数据。当前目录为 27 个 id / 25 个文件：22 款新图、3 款旧中高层，以及复用单树文件的两个幼树变体。`city-assets.ts` 只加载当前场景实际需要的文件，同源文件只解码一次；将双轴仿射、平地四角映射与边缘显示处理一次烘焙到长边不超过 384 像素的透明画布，随后关闭源位图和清理缓存。逐帧只复用烘焙结果，不重新执行像素处理或地表三角映射。

地图采用 2:1 轴测投影；建筑以实测主边映射到 ±0.5，保持竖线竖直，并以 L/F/R 地面包络居中、每边至少退让 0.1 格；平地按记录四角映射，植被按根部和单株高度定尺度。四款低层设施受占地限制，按实际低矮比例绘制，不强行拉高达到 H1。这些是对 AI 图的显示校正，不是物理相机或完整三维模型恢复。源 PNG 保留原样，按接地远近排序与视口外剔除。旧预览的向上揭示仍保留；正式入口本轮改为真实批次中合并地块整体填入，不采用统一裁切生长。

Terrain 独立 `terrain-view.ts` 继续跨年份连续，以对数强度、局部平滑、褶皱和渐隐边缘塑形；当前高度混合低地/高地/岩石/雪顶。其远景网格仍可降低细节，不把高度解释为精确数量。City / Terrain 切换保留播放头与缩放平移，不再请求 GitHub 数据；旧视图立即释放。进入 Terrain 才动态导入其 Three.js 分包并创建 WebGL，回到 City 即释放几何、材质、纹理和上下文。

两种画布均透明；UI 跟随 GitHub 明暗，主题/尺寸/交互变化请求单帧。暂停或完成后停止连续帧。关闭移除输入/主题/尺寸监听，中止素材请求并清空 City 烘焙画布；加载失败则释放部分成功结果并明确显示失败。源位图在烘焙后即关闭，开发预览内的引擎切换复用当前控制器的烘焙结果；Terrain 仍释放 WebGL。没有远程素材、远程执行代码或新增依赖；本轮新增的 GitHub 自动入口声明和面板模块公开范围另见下方构建说明，不能沿用旧版“清单未改变”的结论。

## 目标模块

| 模块 | 职责 | 约束 |
| --- | --- | --- |
| GitHub 适配器 | 识别主页、访问者、同源请求、响应提取 | 页面 DOM 和请求都是外部边界；规则须有实测依据 |
| 数据 | 校验日期/数量、排序、年度覆盖和统计对照 | 内部只接收校验后的真实每日数量；不依赖 Chrome API |
| 缓存 | 按访问者、主页所有者、年份读写；版本和刷新 | 当前直接使用 Chrome 存储，在读取入口校验；身份不明不复用缓存 |
| 时间轴 | 保留 Terrain 与旧预览的播放行为 | 正式 City 不再暴露独立生长控制，改由真实数据快照驱动填入 |
| 渲染 | City / Terrain、主题、相机、按需帧、释放 | 不直接发 GitHub 请求或访问 Chrome 存储 |
| 扩展 UI | 原 h2 左侧轻量切换、按需面板与城市控制 | 默认原图；原统计/设置只随原图显示，日历/Activity overview 整体恢复，流水保留 |

边界以当前职责为准；确有需要时再提取实现接口。不为尚未启动的网站编写第二个平台适配器。

## 目标数据流

```text
个人主页 + 当前访问者
  → GitHub 适配器（识别身份和年度页面）
  → 当前身份的年度缓存命中 / 同源请求补齐
  → 入口解析与校验 → 可信年度数据 → 对应作用域缓存
  → 已校验的累计年度快照 → 日期窗口筛选
  → 正式 City：完整场地/路网 + 已提供日期的地块填入
  → 最终可信快照 → 摘要/按需每日明细

旧预览 / Terrain：可信历史 → 原有独立时间轴 → 渲染
```

未取得数据的日期不是零贡献，预留年份不构造每日数据。正式 City 的加载中画面只代表当前已校验的快照；失败或取消必须清除部分数据地块并保留空场地，不悄悄将其视为完整历史。完整缓存不另走慢速动画，旧预览的跳过操作也不能代表网络已经补齐。

## 平台与构建

- TypeScript 定义数据、缓存作用域与播放状态；Vite 生成本地 MV3 资源。
- 入口 IIFE、按需面板 ES 模块、风景模块、Terrain / Three.js 分包及建筑 PNG 随扩展安装包打包。点击城市后通过 `chrome.runtime.getURL()` 导入 `content.js` 与本地渲染模块，先按年份布局元数据准备场地/路网，再消费真实数据批次；不执行 CDN 远程代码，未点击时仍不载入城市。
- UI 使用 Shadow DOM 隔离样式；它不是身份或数据的安全边界。
- 首版计划在 GitHub 页面上下文可用的位置完成同源数据请求；不能假设后台服务可以自动复用完全相同的会话语义。
- manifest 以 `content_scripts.matches: ["https://github.com/*"]` 自动运行 `entry.js`，这属于 GitHub 站点运行范围；权限列表仍为 activeTab/scripting/storage，不另加 host_permissions、Cookie 或所有网站权限。popup 使用原权限作快捷入口，不需要常驻 service worker。popup、入口 IIFE、面板 ES 模块、风景 ES 模块分别构建到同一目录；manifest 将 `content.js`、`landscape.js`、`chunks/*.js` 和 `assets/city/*.png` 仅向 GitHub 声明为 web accessible resource，供隔离环境按需加载。
- content script、扩展页面与页面脚本的执行环境不同；若实测确需桥接，再针对真实数据边界设计消息协议，不预先增加 MAIN world 注入。

Chrome 官方说明了内容脚本的隔离执行环境和可用能力，不能由此推导 GitHub 会话请求已经通过：[Content scripts](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)。

## 生命周期目标

| 状态 | 目标行为 |
| --- | --- |
| 未激活 | 自动识别并挂轻量入口，原图默认可见；无面板/图片/渲染器加载、贡献缓存访问或历史获取 |
| 激活/加载 | 先以年份布局元数据建立空场地/路网；核对身份，随已校验源年快照填入真实地块，提供取消 |
| 数据批次/交互 | 数据更新可重新规划，合并地块整体填入；观看缩放/平移不规划，短过渡完成即停连续帧 |
| 失败/取消 | 清除部分数据地块，保留空场地/路网并提供重试，不篡改已校验缓存 |
| 静止 | 无连续帧；必要的单帧更新由 invalidate 触发 |
| 原图切换/标签隐藏 | 取消请求、清空可见数据、释放城市，恢复原生内容；再次进入重新核对身份，完整缓存同样填入而不人为拖慢；旧预览沿用原行为 |
| 退出展开 | 返回紧凑显示，不重建画布或重读贡献，恢复入口焦点 |
| 导航离开 | 取消请求和待执行帧，移除面板监听、释放图片/画布，恢复原生显示及统计文本；新个人页重新识别入口 |

GitHub 的页内导航、浏览器后退、主页切换和重复激活必须实测。不能只处理整页刷新，也不默认使用全页面高频 DOM 轮询。

## 错误与边界校验

外部页面响应、持久化缓存及跨环境消息各自在入口集中校验，内部使用可信类型。失败明确区分网络、会话、身份不明、解析不支持、缓存不可用与 WebGL 不可用；不给未知数据填零。

只在可以恢复或转换错误的层处理异常。页面结构失配时停止该路径并保留原 GitHub 页面。缓存结构版本与解析器版本的失效策略在 P1 确定。
