## 当前骨架

本轮分为轻量入口与按需面板：`entry.js` 是仅 GitHub 范围、`document_idle` 运行的 IIFE，识别个人页 URL、贡献容器及年度入口后挂“贡献图 / 城市 · CodeYears”。默认原图，未点击不导入 `content.js`、不请求历史、不读写缓存或初始化渲染。入口在原图显示区前提供切换，暂时隐藏/恢复该显示区，不移动或删除 GitHub 原生 DOM。轻量 DOM 观察配合 Turbo 导航处理延迟日历、重复执行与销毁，不轮询历史数据。

点击城市后才动态导入 `content.js` ES 模块并挂面板。面板的 activate/deactivate/dispose 分别负责开始读取、取消并清空/释放当前城市、移除实例和监听；入口选择代次与请求 AbortController 身份分别阻止晚到结果挂回已离开的城市或撤销新请求状态。工具栏沿用 activeTab/scripting 快捷定位并激活此入口，不再用弹窗中的“打开”作第二次确认。这是当前实现结构，实际 Chrome/Edge 注入、资源和导航证据仍须本轮验证。

P1-B 通过 `load-year.ts` 连接页面身份确认、缓存与年度请求；`year-cache.ts` 使用 `chrome.storage.local`，在读取边界校验作用域、版本、日期覆盖和有效期。已知身份在读缓存前、使用/写入结果前通过禁止浏览器缓存的同源主页请求再次确认；身份不明仅联网获取，不读写缓存。入口改造不更改这些模块及隔离规则，浏览器真实会话与跨标签页验收仍以报告为准。

面板初次激活读取默认最近三年，范围更改后应用。选择起止年份，以 ISO 周年起止日期推导必要的相邻公历源年，通过 `loadContributionHistory` 升序复用年度加载器和历史组装；缓存仍按公历年。完整加载后按真实日期筛选，城市、总量与明细共用筛选结果，周年合计不与 GitHub 公历年度强行相等。加载进度、缓存警告和生长状态分别维护，全部成功后才把完整可信日期/数量交给 `landscape.js` 与时间轴；失败或取消不把部分结果生成完整风景。每日表格仍在“更多”的明细展开时才建立，刷新及清除继续使用原身份隔离路径。

新面板以340px画布提供缩放/平移/全景，窄于500px的页面使用300px。页面内展开将同一面板与画布移入原生 `dialog`，收起或 Esc 后放回原位，不重建渲染器或重新读取贡献。City 生长为3000ms，公共时间轴默认时长不改；加载、生长、完成状态各自显示必要操作。已呈现过城市的面板再次激活时仍重新确认身份和加载数据，再直接显示完成态；主动重播仅影响已加载画面。实际取景、Esc/焦点与状态控件待本轮浏览器验收。

`createLandscape` 负责共享时间轴、有限动画帧、尺寸/主题监听、缩放和平移及视图释放。City 在 `city-parcels.ts` 一次规划年度横向街区：周为列、周一至周日为行；完整周归周四所在ISO年，年首/尾借取相邻公历源年，历史周年为52或53列，不再有54列的碎周年界；未提供/未来日期不填零。每个合并地块保留明确的源日期索引与真实数量，不能用连续索引区间代表跨周成员。

每日 0、1–2、3–5、6+ 分为平地、幼树、树木、建筑。建筑数量经相对对数强度分四档，同年同档的相邻格按当前可用素材贪心合并为矩形：第一档支持 3×3、2×1、1×1，第二/四档支持 2×2、1×1，第三档只用 1×1；树林支持 2×2、2×1、1×2、1×1，平地支持 2×2、1×1。展示分段固定在第13、26、39周后插路，第53周在末段，并非公历季度；不改日期、不跨路合并。具体阈值和支持组合是当前实现选择，不代表设计目录全部完成。

`city-view.ts` 的 `planCityScene` 按占地、强度档与稳定位置选择素材；主色来自原图，不表示精确贡献数。2×2 可将合适的 1×1 建筑等比放大两倍；中高层缺少匹配长条素材时不合并为 2×1/1×2，不再以较小的原生楼体和大庭院代替跨格楼体；仍不拉伸楼身。规划、类型与占地只在创建 City 时确定，缩放只改变投影尺寸、平移、可见范围和采样质量，不重建合并。零贡献 2×2 地块可选草地、池塘或广场，其成员日期明确；五年景观带内的水体与树木另作装饰。

City 通过视图的 `maxZoom(viewport)` 按全景适配比例计算细节上限，目标使一个逻辑格横向约 192 CSS 像素，最低保留全景 5 倍；Terrain 仍为 5 倍，切换时重新约束当前倍率。街区底面改为绿地庭院，建筑下方紧凑铺装与入户步道连接沿合并地块边界的窄支路，避免切开已融合建筑。远景地面在创建时绘入离屏缓存，比例上限 48、宽度预算约 3072 像素。高倍近看发现整张缓存放大会模糊，因此当投影比例 `scale > unit × 1.25` 时，改将可见矢量底面、道路与原烘焙平地贴图重绘到视口尺寸的近景缓存；仅尺寸、缩放或平移改变时重建，静止镜头下的生长动画复用它。销毁时近景、远景缓存一并清零；近看画质和实际开销单独验收。

City 地面、道路与组间公园由本地 Canvas 代码绘制，平地、植被和建筑使用随包图片。景观带从所选历史起点每五年一组，组内普通道路，组间增加公园/湖泊；只在已显示组之间留带，三年不插带、二十年三条，不依赖贡献强弱。

`city-unit-catalog.ts` 直接引用设计目录的标定 JSON，与本地标定工具共用 `unit-calibration.ts`，没有第二套量测数据。当前目录为 27 个 id / 25 个文件：22 款新图、3 款旧中高层，以及复用单树文件的两个幼树变体。`city-assets.ts` 只加载当前场景实际需要的文件，同源文件只解码一次；将双轴仿射、平地四角映射与边缘显示处理一次烘焙到长边不超过 384 像素的透明画布，随后关闭源位图和清理缓存。逐帧只复用烘焙结果，不重新执行像素处理或地表三角映射。

地图采用 2:1 轴测投影；建筑以实测主边映射到 ±0.5，保持竖线竖直，并以 L/F/R 地面包络居中、每边至少退让 0.1 格；平地按记录四角映射，植被按根部和单株高度定尺度。四款低层设施受占地限制，按实际低矮比例绘制，不强行拉高达到 H1。这些是对 AI 图的显示校正，不是物理相机或完整三维模型恢复。源 PNG 保留原样；隐藏角点、完整屋顶和高 alpha 晕边等仍待美术复核。按接地远近排序、视口外剔除；整体生长用向上揭示，低建筑先完成，并非真实三维拉伸。

Terrain 独立 `terrain-view.ts` 继续跨年份连续，以对数强度、局部平滑、褶皱和渐隐边缘塑形；当前高度混合低地/高地/岩石/雪顶。其远景网格仍可降低细节，不把高度解释为精确数量。City / Terrain 切换保留播放头与缩放平移，不再请求 GitHub 数据；旧视图立即释放。进入 Terrain 才动态导入其 Three.js 分包并创建 WebGL，回到 City 即释放几何、材质、纹理和上下文。

两种画布均透明；UI 跟随 GitHub 明暗，主题/尺寸/交互变化请求单帧。暂停或完成后停止连续帧。关闭移除输入/主题/尺寸监听，中止素材请求并清空 City 烘焙画布；加载失败则释放部分成功结果并明确显示失败。源位图在烘焙后即关闭，开发预览内的引擎切换复用当前控制器的烘焙结果；Terrain 仍释放 WebGL。没有远程素材、远程执行代码或新增依赖；本轮新增的 GitHub 自动入口声明和面板模块公开范围另见下方构建说明，不能沿用旧版“清单未改变”的结论。

## 目标模块

| 模块 | 职责 | 约束 |
| --- | --- | --- |
| GitHub 适配器 | 识别主页、访问者、同源请求、响应提取 | 页面 DOM 和请求都是外部边界；规则须有实测依据 |
| 数据 | 校验日期/数量、排序、年度覆盖和统计对照 | 内部只接收校验后的真实每日数量；不依赖 Chrome API |
| 缓存 | 按访问者、主页所有者、年份读写；版本和刷新 | 当前直接使用 Chrome 存储，在读取入口校验；身份不明不复用缓存 |
| 时间轴 | 历史起点、播放头、暂停、继续、跳过 | 与获取进度解耦；完整缓存仍可从起点重播，不强迫每次切回重播 |
| 渲染 | City / Terrain、主题、相机、按需帧、释放 | 不直接发 GitHub 请求或访问 Chrome 存储 |
| 扩展 UI | 轻量自动入口、按需 Shadow DOM 面板、加载/失败反馈与控制 | 默认原图，用户点击后才读取历史/激活 City；隐藏原图须可恢复 |

边界以当前职责为准；确有需要时再提取实现接口。不为尚未启动的网站编写第二个平台适配器。

## 目标数据流

```text
个人主页 + 当前访问者
  → GitHub 适配器（识别身份和年度页面）
  → 当前身份的年度缓存命中 / 同源请求补齐
  → 入口解析与校验 → 可信年度数据 → 对应作用域缓存
  → 完整或明确标记缺失的历史数据
  → 时间轴播放头（独立于请求/缓存进度）
  → City / Terrain 渲染
```

未取得数据的日期不是零贡献。缓存完整不等于动画已播放；跳过动画也不等于网络已经补齐。部分成功需要显式表达可用范围，不能悄悄构造完整历史。

## 平台与构建

- TypeScript 定义数据、缓存作用域与播放状态；Vite 生成本地 MV3 资源。
- 入口 IIFE、按需面板 ES 模块、风景模块、Terrain / Three.js 分包及建筑 PNG 随扩展安装包打包。入口点击后通过 `chrome.runtime.getURL()` 动态 `import()` `content.js`，有效历史准备好后再导入 `landscape.js`；不执行 CDN 远程代码。
- UI 使用 Shadow DOM 隔离样式；它不是身份或数据的安全边界。
- 首版计划在 GitHub 页面上下文可用的位置完成同源数据请求；不能假设后台服务可以自动复用完全相同的会话语义。
- manifest 以 `content_scripts.matches: ["https://github.com/*"]` 自动运行 `entry.js`，这属于 GitHub 站点运行范围；权限列表仍为 activeTab/scripting/storage，不另加 host_permissions、Cookie 或所有网站权限。popup 使用原权限作快捷入口，不需要常驻 service worker。popup、入口 IIFE、面板 ES 模块、风景 ES 模块分别构建到同一目录；manifest 将 `content.js`、`landscape.js`、`chunks/*.js` 和 `assets/city/*.png` 仅向 GitHub 声明为 web accessible resource，供隔离环境按需加载。
- content script、扩展页面与页面脚本的执行环境不同；若实测确需桥接，再针对真实数据边界设计消息协议，不预先增加 MAIN world 注入。

Chrome 官方说明了内容脚本的隔离执行环境和可用能力，不能由此推导 GitHub 会话请求已经通过：[Content scripts](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)。

## 生命周期目标

| 状态 | 目标行为 |
| --- | --- |
| 未激活 | 自动识别并挂轻量入口，原图默认可见；无面板/图片/渲染器加载、贡献缓存访问或历史获取 |
| 激活/加载 | 识别身份、可取消请求、加载本地渲染模块 |
| 播放/交互 | 仅在有视觉变化时申请帧；日期数量不逐帧重建 |
| 暂停/静止 | 无连续帧；必要的单帧更新由 invalidate 触发 |
| 原图切换/标签隐藏 | 取消请求、清空可见数据、释放城市并恢复原图；再次进入城市重新核对身份，不强迫重播；独立本地预览只暂停 |
| 退出展开 | 返回紧凑显示，不重建画布或重读贡献，恢复入口焦点 |
| 导航离开 | 取消请求和待执行帧，移除面板监听、释放图片/画布，恢复原生显示；新个人页重新识别入口 |

GitHub 的页内导航、浏览器后退、主页切换和重复激活必须实测。不能只处理整页刷新，也不默认使用全页面高频 DOM 轮询。

## 错误与边界校验

外部页面响应、持久化缓存及跨环境消息各自在入口集中校验，内部使用可信类型。失败明确区分网络、会话、身份不明、解析不支持、缓存不可用与 WebGL 不可用；不给未知数据填零。

只在可以恢复或转换错误的层处理异常。页面结构失配时停止该路径并保留原 GitHub 页面。缓存结构版本与解析器版本的失效策略在 P1 确定。

## 仍需决定

当前缓存选择 schema 1、解析器版本 2、当年 1 小时且跨日失效、历史年 30 天；这些是可调整的原型策略。City 合并成员可以跨周且索引不连续，不能把建筑称为连续日期统计。身份源长期可靠性、SSO 变化、容量预算和正式主题仍待验证。各报告结论以记录版本和环境为准，不继承旧渲染性能或浏览器验收结论。

## 画布原生保存

City画布继续只绘制当前缩放、平移和播放状态，Canvas 2D透明背景。Chrome右键菜单负责将该画布当前位图保存/复制，不调用插件额外的导出API，也不包含DOM按钮和GitHub页面背景。画布像素仍按视口CSS尺寸×min(devicePixelRatio,1.5)，不是固定8K；缩放只改变其内部构图。前轮exportImage、额外输出画布和city-share模块已移除，本轮将保存帮助收进“更多”，不常驻额外说明行。

City缩放的逐级预滤波图片与完整生长后不再逐栋裁切的修正保留；不改变地块、合并与数量。关闭仍按原视图生命周期清零采样资源，不添加保存相关后台任务或权限。
