# 高速公路指路牌

两根镀锌立柱、铝合金卷边和单道浅色反光边构成出城及返程牌。两款共用[正视母版](motorway-guide-source.png)，离线为反光膜配蓝漆和绿漆。母版的顶边、紧固环和法兰保留建筑素材的暖侧光。用户名与方向箭头在运行时绘制；空牌只显示硬件。

## 制作

在 macOS 仓库根目录运行 `node scripts/bake-direction-boards.mjs`。脚本用本机 Chrome 裁切源图、清除物体外的淡光、转换反光膜颜色，并写出两张 1466×689 的透明运行 PNG、素材包围盒与牌面标定。生成后使用 `npm run build` 构建扩展。

牌面宽 6.5 个世界单位，高 1.5 个单位。以两个脚座的落点连线为基准，整块母版接受一次沿道路法线的竖直面投影。牌面、字、箭头与点击区域共用坐标。单行文字优先，长用户名分为两行，以箭头占位及反光边内侧宽度限制字号。

## 原图生成

使用内置 ImageGen，将[旧高速牌](../v1/modern-highway-mutual-source.png)作为对象参考，[城市办公楼](../../../../public/assets/city-runtime/office-h3-a.png)作为材质参考。最终绘制要求如下。

> 透明底单个高速公路指路牌，宽蓝色空牌面，接近水平的正视平行投影。单道暖白内边、略有厚度的铝制卷边、左上方受光。两根均匀布置的镀锌金属管，有紧固套环、法兰和小螺栓。足底完整，中央为动态用户名留白。四周留透明空间；无路面、文字、箭头、石座或场景投影。参照现代城市建筑素材的明暗、金属质感和缩小时的清晰轮廓。
