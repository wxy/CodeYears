# 接地一致性：三款可撤回小样

不是重绘素材或最终精绘成果。直接使用固定基线正式预烘焙 PNG；没有新增图像文件，没有调用生成 API。

| 代表 | 保留的正常差异 | 本轮参数（占原生占地的比例） |
| --- | --- | --- |
| cottage-gable | 红瓦、花园、低层住宅体量与自带门前铺装 | 0.60，中心不偏移 |
| tower-h4-a | 细长塔身、金属与玻璃、细窄基座 | 0.40，W/D 中心各偏移 +0.06 格 |
| police-a | 宽矮台基、蓝灰屋顶、入口台阶 | 0.84，中心不偏移 |

参数只用于静态接触阴影包络试排，来自正式图的可见接地范围目测；不是重新标定的楼体四角或物理光照证据。共同三层菱形内缩 0 / 0.025 / 0.05 格，透明度 0.025 / 0.035 / 0.045，颜色 RGB(38,43,39)。不画方向性长投影，不替代源图自带阴影，也不据此判断每种材质曝光应相同。

投影共用 W=(0.5,0.25)、D=(-0.5,0.25)。每款一次生成 384×192 透明画布，作为仅装饰的 flat item，位于正式铺装之后、楼体之前，由已有地面远近缓存消费。全部非平地楼体对象、原始 indices、道路与桥对象保留引用。阴影小于地块包络，不跨年度/季度路。程序几何只是候选环境遮蔽，不能称为精绘新楼体。

第一版把阴影附加到 createOrganicGround 后，但该回调之后还有正式铺装，城市像素差异为零；已改用既有平地贴图阶段。此修正说明应在正确层级接入，不能在整城绘完后补画、移动或删除对象。

后续最小接入：若用户选中此方向，只需在生产场景准备完成、createCityView 前，将三个命中的装饰 flat item 与对应已烘焙透明画布加入候选场景；保持数据地块和正式默认不变。当前无需修改共享渲染器、素材库、路网或建立通用框架。正式采用前仍应逐款确认接地四角与阴影可见范围，尤其塔身邻居遮挡和住宅重复阴影；也可仅选中警局，放弃其余两款。
