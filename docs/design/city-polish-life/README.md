# 城市生命感：最小候选

方向：少量精绘轿车的短程单向装饰运动。工程入口默认关闭，提供1辆/2辆，保留静态基线，不增加交通或人口状态。

## 规划与遮挡

先取得正式 `planOrganicCity`，沿 `planRoadGeometry` 输出的外围环路直线选4格短段，切点两端再留2格；使用正式车道宽度与右行偏移。沿已确定方向选 `transport-sedan-xp/xm/zp/zm`，不旋转或镜像图片。

候选将车辆整段扫过的投影包围矩形与全部非平面场景素材包围矩形比较，额外留0.06投影单位，拒绝任何重叠；再排除路口、路名和相邻候选。它会拒绝透明区域也相交的可用路段，这是有意的保守取舍。只接受已知可见短段，不穿建筑/静态车辆，不接桥、不经过弯道、不处理信号灯或寻路。规划发生在车辆层创建前，不在绘完城市后挪路、挪楼或移除静态车辆。

每段单向0.7格/秒，周期约5.7秒，前后12%淡入淡出。没有折返、倒车或追赶后台时间。新增动态层内部按地面深度设置顺序；与静态场景的遮挡依靠规划时拒绝重叠解决，不对正式画布做像素修补。只保证本原型已验证的四类输入，不声称这是通用交通算法。

## 素材与绘制

直接读取 `public/assets/city-runtime/transport-sedan-*.png` 与正式 baked catalog，原图/提示/标定沿用既有素材档案；没有生成、复制或新增PNG。四方向现有PNG分别249×180、257×170、248×181、249×178，均小于384。每个移动实例复制一次到小Canvas，之后只改变CSS transform/opacity，独立层不持有主城画布或重绘回调。不假设GIF或精灵图更省，也未引入它们。

主城使用 `createCityView(scene, images, 0, createOrganicGround(plan))` 后直接绘完。相机复刻其预留布局包围盒；平移/缩放才重画主城，动画帧不重建场景、地面缓存或图片。动态关闭/暂停时车辆层隐藏，不改变原有静态车辆。

## 如果后续决定接入

1. 在正式最终道路规划结果上调用局部路段筛选；安全段不足时少放或不放，不能改道路或楼体补救。
2. 由正式 City 实例创建单独车辆层，把当前 fit/scale/投影原点提供给它。当前工程入口的相机公式是就近复制的实验代码，正式接入应直接使用渲染器内部现有相机结果，避免双份公式漂移。
3. 仅在相机失效时更新车辆层镜头，动画 tick 不调用 `invalidate`。现有同页隐藏/核对后恢复、范围变更和销毁节点分别转发启停/释放，不能绕过身份核对提前显示。
4. 默认关闭；系统减少动态时禁用，页面隐藏/原图/暂停/销毁必须取消 RAF，恢复清空上一帧时间戳。目标设备确认收益与功耗后再决定入口，不提前做设置持久化。

本轮不实施这些共享接口变更，不建立通用动画/实体系统。实际结果与建议见 [报告](../../reports/CITY-POLISH-LIFE.md)。
