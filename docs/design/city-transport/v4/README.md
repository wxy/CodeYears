# 单桥墩梁桥透视修正

2026-11-08。用户更正：所指的是单个T形桥墩的现代梁桥，先前改石拱桥对错了对象。本轮只修梁桥，保持当前桥面高度及引桥。

原支撑图沿桥长展开，加上约0.504倍的桥下压缩，看起来像沿桥侧的薄片。现在盖梁沿局部W轴横跨1.44格桥宽、Z向厚0.32格；柱体中心为(nativeWidth/2,nativeDepth/2)，竖线X不变，水平面的两轴投影斜率严格为±0.5。柱底四角终止于共享水面，不绘制浮在水面的基础台，不逐列缩放。盖梁和直柱按原桥面/纵梁遮挡。

原桥面高度0.18、河面下沉0.75不变。素材中的水面屏幕落差为(0.18+0.75)/2=0.465，扣除放置时桥面抬高的0.09，正好等于河面绘制的0.375。盖梁和短柱只占现有净空，不把原画长柱当作运行高度。

材料由内置imagegen定向编辑提供；生成外形未作为准确几何使用，只保留混凝土纹理。完整源图pier-material.png为1479×1063、965,889 bytes，提示见[PROMPTS.md](PROMPTS.md)；离线坐标和贴材质见calibration.json及scripts/bake-city-transport.mjs。原第二版源图保留。运行只解码PNG，不增加几何或像素处理。

最终运行图1152×828、565,443 bytes，较旧图增加20,197 bytes，不增加素材数量。583,488个桥面及上部保留像素差异0，桥下39,366像素改变；世界宽深、车幅、桥高、引桥、桥位和支撑锚点元数据完全相同。运行PNG重新解码RGBA差异0。制作继续使用bake-city-transport.mjs --outDir <临时目录>/baked --canvasModule <Canvas模块>/index.js。当前生产河道近景已检查；真实GitHub地图仍待用户重载验收。
