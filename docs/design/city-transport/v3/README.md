# 石拱桥下部结构修正

2026-11-08，用户指出单拱桥的桥墩透视错误，缺少竖直支柱没入水中的感觉。第二版制作流程在桥面标定后按列伸缩下部，近远支撑的比例不同，拱洞和石缝也随之变形。本版不改变桥面和岸路布局。

使用内置 imagegen，以第二版运行图为参照定向生成刚性石墩和单拱。正式源图 `bridge-stone-supports.png` 为1515×1038 RGBA、1,300,747 bytes；完整提示见 [PROMPTS.md](PROMPTS.md)，不是人工绘制或第三方下载。原始第二版源图保留。

制作继续使用 `scripts/bake-city-transport.mjs --outDir <临时目录>/baked --canvasModule <已有Canvas模块>/index.js`。新图只作保持竖线的整体仿射投影，与原有桥面端点对齐；原图前侧桥面以下才替换为新石材结构。墩体按共享河面水位裁切，不伸缩各列。运行仍只解码PNG，不增加逐帧裁切、资源数量或模型变体。

运行图仍为1152×789、643,712 bytes，比第二版减少19,419 bytes。541,440个桥面及上部像素与原运行图逐像素相同；桥下89,142个像素发生变化。世界宽深、车幅、桥面高度、引桥端点和两岸锚点不变，梁桥未替换。PNG重新解码RGBA差异0。生产河道近景已检查；真实GitHub地图效果由用户重载后验收，不将本地样本当作真实会话通过。
