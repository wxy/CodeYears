两图均1774×887源尺寸，不随发行包分发；运行图合计1,208,377 bytes，相对旧桥净增801,596 bytes。每座桥按真实年度与季度序号固定选型，缩放不重新随机选择；只解码场景选中的桥型。桥身标定石桥约2.094×5.234、梁桥1.92×4.8，实际桥面车幅按各自原画量测，不把装饰桥当作物理工程图。

`calibration.json`记录桥面上沿端点、横向坡度、近端沥青封口遮罩与端面车幅。保持竖向构件方向，桥纵轴按基础间距确定，石桥5.234格、梁桥4.8格；烘焙去除近端沥青竖直封口，源图不改写。引桥使用同一份端面车幅，在实际剩余岸带内从季度路宽度缓和过渡，并在岸路靠河路缘以零高度接入。桥面继续抬升0.18，河面下沉0.75；岸路车道不在引桥下面穿行。

制作命令：

```sh
node scripts/bake-city-transport.mjs --outDir <本轮临时目录>/baked --canvasModule <已有Canvas模块>/index.js
```

输出21张交通PNG及catalog/report；每张重新解码后RGBA差异必须为0。车辆和信号灯的19张PNG与第一版逐字节一致。桥内容横向预算1148像素，含两侧透明边实际长边不超过1152。运行只解码正式PNG，不执行标定、像素处理或生成桥梁路径。
