# 道路桥梁第二版

2026-11-07，用户要求引桥从岸路路面接出、桥墩协调并增加桥型。两张正式源图由内置 imagegen 生成及定向编辑，保留透明 alpha；不是从商业素材下载，也不是程序占位图。第一版源图继续保留。未选中的生成尝试不进入运行目录。

| 桥型 | 正式源图 | 支撑方式 | 运行图 |
| --- | --- | --- | --- |
| 石拱桥 | bridge-stone-wide.png | 单拱、成对同式端部支撑，无中间桥墩 | transport-bridge-stone.png，768×527，307,192 bytes |
| 现代梁桥 | bridge-girder-compact.png | 单个居中 T 形桥墩、低梁和金属栏杆 | transport-bridge-girder.png，768×552，284,110 bytes |

两图均1774×887源尺寸，不随发行包分发；运行图合计591,302 bytes，相对旧桥净增184,521 bytes。每座桥按真实年度与季度序号固定选型，缩放不重新随机选择；只解码场景选中的桥型。占地标定为1.6×4，实际桥面车幅按各自原画量测，不把装饰桥当作物理工程图。

`calibration.json`记录桥面上沿端点、横向坡度、近端沥青封口遮罩与端面车幅。保持竖向构件方向，桥纵轴映射为4格；烘焙去除近端沥青竖直封口，源图不改写。引桥使用同一份端面车幅，在1.6格内从季度路宽度缓和过渡，并在岸路靠河路缘以零高度接入。桥面继续抬升0.18，河面下沉0.45；岸路车道不在引桥下面穿行。

制作命令：

```sh
node scripts/bake-city-transport.mjs --outDir <本轮临时目录>/baked --canvasModule <已有Canvas模块>/index.js
```

输出21张交通PNG及catalog/report；每张重新解码后RGBA差异必须为0。车辆和信号灯的19张PNG与第一版逐字节一致。桥内容横向预算764像素，含两侧透明边实际长边不超过768。运行只解码正式PNG，不执行标定、像素处理或生成桥梁路径。

提示词和迭代见[PROMPTS.md](PROMPTS.md)。仅本机离线实际Canvas渲染已检查；最终浏览器观感及性能仍待验收。
