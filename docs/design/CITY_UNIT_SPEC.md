## 统一坐标、占地与高度

单元记为 **W×D×H**：W 是横跨的周列数，D 是横跨的星期行数，H 是建筑的逻辑高度。1×2 与 2×1 是不同地面方向，不可交换。每年仍是周列、周一至周日七行；首尾不足周保留实际日期，不填未来零值。

建议建筑高度先用 H1、H2、H3、H4 四档，对应 1、2、3、4 个统一高度单位；H0 是平地。高度单位是素材设计用的比例尺，不解释为精确楼层数。树木/灌木使用独立的自然高度尺，在各自低贡献等级内表达，不以树冠像素高度与建筑档做精确的跨类别比较。

| 视觉属性 | 建议表达 | 不混入的因素 |
| --- | --- | --- |
| 占地 W×D | 实际参与合并的日期格 | 不凭建筑图片大小增减日期 |
| 高度 H | 地块成员的日均贡献强度，经统一规则分档 | 不因合并日期更多而再次加高 |
| 建筑类型、颜色 | 住宅、办公、公共/功能设施和材质差异 | 不用警局/消防局等类型暗示某种真实 GitHub 活动 |
| 单树、树林和地面 | 低贡献等级与景观变化 | 装饰性公园仍单独说明 |

高度建议按 `地块真实总量 / 成员天数` 决定。同一建筑只能合并同一高度档的相邻格；档内允许真实数量不同。当前 0、1–2、3–5、6+ 的草地/灌木/树木/建筑分界可先作为试排基线，建筑内部 H1–H4 的阈值和低贡献平地范围待样稿、实际分布和视觉检查后确定。映射在生成城市时固定，不能随视口缩放重新计算。

例如四个相邻格都为每日 12 次，融合后总量 48、日均仍为 12，使用同一高度档。真实明细保留四个日期；跨周合并的成员索引可能不连续。

## 建筑的比例复用与视口缩放

用户后续要求：未占满格子的建筑按**地面占地包络居中**，并在建筑之间留出空隙；不能用透明画布、屋顶或冠部中心代替地面包络中心。当前标定样板采用每边至少0.1格退让，相邻建筑逻辑地面间至少0.2格；数值是试排参数，后续按画面调整。合并建筑按整个合并地块居中，不重新拆出内部缝隙。

两种缩放分开处理：素材比例复用发生在城市规划时；用户放大/缩小画面只改变观看大小，不换素材、改高度或重新融合。

允许对素材统一缩放三个轴，目标必须满足 `(W',D',H') = s×(W,D,H)`。因此 **1×1×1 放大两倍可用于 2×2×2**；1×1×2 放大两倍可用于 2×2×4。目标高度必须符合其贡献档，不能把低贡献地块为了填满面积而强行变高。第一轮先验证原尺寸和两倍复用，不预设任意倍率都有足够清晰度。

1×2 不能等比变为 2×3；2×1 也不能靠旋转屏幕上的图片变为 1×2。固定相机下这会同时改变立面方向或竖直线。需要另一方向时绘制相应朝向，或用匹配占地的独立造型，不镜像带文字/明显入口的素材。

同一组合的候选依据年份和日期集合稳定选择；重播、缩放、平移和视图往返不重新随机抽取。将来如做远景简化，也须保留同一建筑、同一占地和高度，只减少显示细节。

## 树木、树林与低贡献平地

植被使用与建筑相同的固定地面投影、左上照明和透明边缘规范，替换目前风格较简单的程序树木。树林是多个低贡献日期的组合表现，保留日期集合与真实数量，不用林木数量伪装精确贡献次数。

| 单元 | 首轮占地 | 每个支持占地的至少两个选择 |
| --- | --- | --- |
| 灌木/小树 | 1×1 | 圆冠矮灌木；疏枝小树 |
| 单树 | 1×1 | 宽冠落叶树；较窄的锥形树 |
| 小树丛 | 2×1、1×2 | 疏密错落的混合树丛；较整齐的小林带，各朝向分别检查 |
| 树林 | 2×2 | 深浅混合阔叶林；较疏的混合林 |
| 草地/平地 | 1×1、2×2 | 连续草坪；稀疏草丛/裸地边缘 |
| 湖泊/池塘 | 2×2 | 不规则小池塘；有草岸的浅湖 |
| 广场 | 2×2 | 暖石铺地小广场；冷灰铺地休憩广场 |

零或极低贡献区域可形成草地、湖泊、广场；具体阈值待定，并在图例说明这几类同属低贡献平地，不能靠颜色推算数量。小到不足以形成池塘/广场的区域使用小地面单元。共享草岸/铺地过渡负责衔接，避免每格都像放着一张有硬边的图片。

装饰性中央公园和湖泊继续与数据单元分开：前者不代表任何日期，后者有明确成员日期。建筑、林地和低地都不跨道路、年份或未知/未来日期合并。入口和站台朝向附近道路；铁路只画占地内必要的站台识别元素，不引入列车或铁路模拟。

## 年度街区内的季度交叉道路

2026-11-01 用户再次明确：使用 ISO 周年，周一至周日完整归周四所在年，52或53周，不再把元旦切断的周放在两年。保留年度横向大街区及长边主路，在第13、26、39周后插入三条交叉路；第53周放末段。此为13周展示分段，并非公历季度；道路使用固定轴，同档合并不跨路。源日期/数量不变，必要时从相邻公历年请求后筛选。混排52/53周年仅短年末端一列余量拓宽路面，不当作贡献地块。

季度支路当前试排宽度为 0.8 个地面格，窄于年度主路；固定道路属于装饰，未取得的历史和未来日期均不补零。根据用户实测的灰白底面与孤立建筑反馈，街区底面已改为绿地庭院，加入建筑脚下紧凑铺装、入户步道，以及沿已合并地块边界相连的窄支路；支路不切开合并建筑。入口可见性、长历史密度与整体观感仍待实际画面验收。

## 五年景观带与普通年间道路

此前空带是按所选年份数量的中间位置放置的装饰性公园与湖泊，与真实贡献无关。按本轮要求，已改为从所选最早年份起，每五个年份一组，仅在相邻组之间插入较宽景观带；组内年度街区之间保留普通道路。1–5 年无组间景观带，6–10 年一条，11–15 年两条，20 年三条。不在历史末尾补空带或年份；它不表示贡献低谷，也不替代数据地块。

## 统一投影是接入硬约束

[精确投影模板](city-units/v2/projection-guide.svg) 使用共同基向量：`W=(48,24)`、`D=(-48,24)`、`H=(0,-48)`，地面两组边的斜率分别为 +0.5、−0.5。场景、道路、建筑落地四角、直线铺地和楼身主边均从同一投影展开，竖直边不倾斜、不出现透视汇聚。3×3 只是延长格子，不另选镜头；模板中的所有占地共用同一格尺寸。

八张 AI 设计板只确定造型和材质，不能用其绘制网格当量尺；目前尚未逐款达到严格统一的几何。独立素材以两组主地面边、地面包络、落地点和结构高度标定；只凭提示词或 alpha 轮廓大小不能认定同一相机/比例。当前 22 款 [首轮标定单元](city-units/v2/calibration/README.md) 已接入运行库，包含方向换算、四角包络、树高、居中和退让；警局、消防局、体育场、总站按受到占地限制后的实际低矮比例使用，不通过拉高冒充原 H1 目标。完整顶部、隐藏角点和透明边缘仍待复核，不等于全部生产验收。具体状态见 [设计交付](city-units/v2/README.md)。

## 正式素材的交付契约

每个实际素材记录以下最少信息；先以清晰的表/就近元数据维护，不提前构建通用素材平台：

| 信息 | 用途 |
| --- | --- |
| 稳定名称、类别、A/B 变体、文件与实际尺寸 | 追溯与稳定选型 |
| 原生 W×D×H、允许的等比倍率/目标组合 | 防止占地和高度混乱 |
| 地面四角、落地点、结构顶部 | 以占地和高度标定，不能仅按整张透明图或轮廓宽度缩放 |
| 实际可见裁切框、阴影边界 | 绘制、遮挡排序和视口剔除 |
| 面向道路的方向、主地面轴线 | 固定视角下的入口/朝向一致性 |
| 来源、生成提示/参考、检查状态 | 区分样稿、已标定、已接入和已验收 |

地面继续使用 2:1 轴测投影，竖直边竖直，光源方向固定；建筑、植被、湖泊和广场使用同一地面比例尺与高度参考尺。先制作带格子和高度尺的正式设计参考，再生成独立透明素材。工具生成不保证投影或比例准确，须实际量测和并排检查；原图保留，运行时标定独立记录。文件只包含单元及必要接触阴影，不带展示底色、编号、整块公路或文字标签。

同一占地不同高度的校验看地面四角与结构顶部；不能用屋顶、天线、树冠的外接矩形代替占地。标准尺寸与两倍复用均需检查门窗、层高、透明晕边、道路贴合和遮挡。超大阴影不能把邻居压暗，铺地边缘应可衔接。

## 分批落地与验收

1. **规范与试排参考**：八张设计板、精确投影模板与首轮标定已完成；原图、量测依据与待复核限制分开保留。
2. **首批素材与季度街区（已接入待验收）**：22 款新单元、3 款旧中高层、季度支路与五年景观带接入稳定布局；地面包络居中留距，生成后不随缩放变化。先收敛整体观感、街区衔接与细节观看，再扩充剩余目录，不宣称每档两个候选已经完成。
3. **补齐目录**：补 1×2、2×3、3×2 功能设施和景观组合；只为实际支持的组合补齐至少两个候选，不为理论组合生成大量素材。
4. **直接检查与预算**：检查每日数量守恒、同档合并、道路阻隔、高度单调性、标准/两倍复用、候选稳定性、透明明暗、增长/暂停/跳过及资源释放。二十年图像的包体、首次解码、内存和交互预算需重新测量。

素材分批加入，解码和复用只围绕当前城市实际需要的 PNG；同文件只解码一次，标定结果一次烘焙为长边不超过 384 像素的透明画布，随后关闭源位图，逐帧复用。City 缩放上限按全景适配比例计算，允许近看一个逻辑格横向约 192 CSS 像素；只改变观看，不改变布局。该目标、源图清晰度与加载成本仍需结合实景检查，不因变体增多而提前搭建复杂框架。原有身份、Edge、后台和发布门槛仍按 [开发计划](../DEVELOPMENT_PLAN.md) 推进。
