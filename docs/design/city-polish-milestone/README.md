# 个人经历里程碑最小接入

候选仅在工程入口开启，正式入口未改。复用基线 `planOrganicCity`、`createOrganicGround`、`loadCityImages` 和 `createCityView`。基线/候选切换仅改变摘要，固定同一输入、画布、取景和缩放；不会在绘制之后移动或删除道路/楼体。

首库证据要求：当前地图范围存在明确注册塔；创建事件从注册日起覆盖完整；按原日期排序的最早创建事件在当前范围内。缺任一条件不认定。相机位置不参与。`completeFromJoined` 是合成证据契约，当前没有真实解析器能够提供这个保证。不能将“当前获取到的最早仓库”当成“首仓库”，删除、隐藏、权限与历史截断都使证明更难。

同日只补注册塔摘要，不新增楼。异日只给日期与关联说明，不为每仓库加楼。组织事件无可靠来源，本轮不实现。范围活跃天数、最高单日数仅由既有日数据计算，不推断工作时间或绩效。

后续最小接入：先在现有活动读取边界证明事件完整性与身份范围，再在注册塔摘要生成处调用本规则；零贡献注册日需检查正式规划是否真的生成塔。不能只把 joinedOn 在日期范围内等同于塔已存在。若异日另设地标获接受，再在地块规划阶段预留原日期成员，而不是绘完加楼。

预览命令：`npx vite --config probes/city-polish/milestone/vite.config.ts`，端口4185。选择证据场景与输入；固定镜头后切换“候选摘要”。“注册日近景”从整体命中注册日后调整镜头，同页隐藏/恢复保留画布。
