## 主地面边标定

用户指出建筑与地图角度不同。检查原图的主要直边后确认生成图视角不一致；alpha 下部边界的方向投票用于辅助量测，体育场为曲线轮廓，改看场内白色直线。采用近似角度如下，分别是画面向右下/向右上的主地面边绝对角度：

| 建筑 | 向右下 | 向右上 |
| --- | ---: | ---: |
| 住宅 | 17.75° | 36.25° |
| 公寓 | 23° | 26° |
| 办公楼 | 27.5° | 30° |
| 塔楼 | 22° | 32.5° |
| 会展馆 | 20.75° | 28.75° |
| 体育场 | 27.75° | 29° |

令 `L=tan(向右下)`、`R=tan(向右上)`，绘制变换采用 `x'=x`、`y'=shear*x+scaleY*y`，其中 `scaleY=1/(L+R)`、`shear=(R-L)/(2*(L+R))`。两条输入主轴变为 ±0.5 斜率，竖直边保持竖直。运行时同步更新可见边界与揭示裁切，避免校正后被错误剔除。这种标定改善主地面方向，不保证 AI 图中所有透视细节严格一致，也不作为真实米制比例。
