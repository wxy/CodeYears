## 已确认的新方向

- 固定视角展示城市，交互保留缩放和平移，取消用户旋转；旋转现仍存在于旧原型，移除在接入阶段完成。
- 先形成统一建筑视觉，再接入数据地块；本轮不直接把总览裁成素材铺满城市。
- 同一套预绘素材保持统一地面投影、光照、建筑比例与材质语言。贡献数、占地合并、原始明细沿用已确认的数据边界。
- Terrain 继续跨年份连续；不因 City 素材化而拆成年度山群。Terrain 的固定视角/平移适配另行验证。

## 这张图与正式素材的区别

`building-studies.png` 是 **1536×1024、RGB、非透明**的设计总览，约 2.62 MB。每格为了看清建筑分别取景，画面带底色、接触阴影和编号；**不能将它当作已对齐、可直接裁切的运行时图集**。

正式接入前需要完成：

1. 按选定样式逐款生成/整理透明背景建筑素材，保留一致视角与光照；去掉编号和展示底色。
2. 固定地面轴线、统一楼层/门窗尺度，为每款记录占地、透明边距、建筑落地点（锚点）和绘制尺寸。暂以 2:1 等距地面投影为候选规范，不把本张样稿当作量测通过。
3. 对照大/小建筑、不同高度和邻接道路检查遮挡，采用从远到近的绘制顺序；不能把建筑图片简单居中塞进每格。
4. 确定有限的缩放档和素材分辨率，宏观视图减少细节；草地/灌木/树木素材也需统一风格。深浅页面使用透明素材，阴影/边缘须检查浅色晕边。
5. 接入固定视角的缩放、鼠标/触控平移，再核对整体生长、暂停/跳过、视图切换、二十年表现及离开资源释放。生长可用图片揭示/显现等方案，具体运动仍待验证，不宣称图片具备真实 3D 拉伸效果。

City 的 Canvas 2D / WebGL 精灵实现尚未选定；性能以实际二十年场景决定。无需为了预绘建筑保留可旋转的实时模型，也不因改成图片就宣布性能自动通过。Terrain 可以继续使用现有 Three.js 高度场，接入方案尚未实施。
