## 已接入规则

- City 使用 Canvas 2D；Terrain 保留按需 Three.js 连续高度场。两者取消旋转，保留缩放、拖动平移与重置。
- 每年一条横向街区，周列、周一至周日七行。年度边界不足周保留列，不强行截为 52 列，不把当年未来日期填零。同年同建筑强度档可矩形合并，保留明确的真实日期索引和数量。
- 地块合并、类型、占地与落地点在创建 City 时确定。**缩放不重新采样、合并或换建筑**，只改变大小、可见范围和采样质量。草地/灌木/树木表示贡献强度；公园树木、道路和湖泊是装饰。
- 素材按地块视觉尺度绘制，主色保留原材质；由占地、强度档与稳定位置选择类型，不把建筑像素高度当贡献数。
- 地面使用 2:1 轴测投影，地面方向为 ±atan(1/2)，约 ±26.565°。六张生成图实际底边并不一致，不能仅凭生成提示词认定对齐。运行时按量测的主边方向做仿射校正，保持竖直边竖直；这是图像近似标定，不是恢复真实相机或保证所有装饰边逐像素一致。
- 以地面落点由远到近绘制，生长采用向上揭示，低建筑先完成，不宣称是真实 3D 挤出。透明画布适配明暗页面；树木仍由代码绘制，精细度未声称与建筑相同。
