## 标定与统一比例设计板

每个源图记录像素尺寸、RGBA/alpha范围、SHA-256、原工具路径。原图不修改；正式独立候选须每款独立生成。裁框取alpha>8的半开范围，保留原始透明残留。分别量两组墙脚/檐口主轴、可见竖墙的脚点与顶点、结构最高点；隐藏角点标为推断并记录误差。院墙/花圃纳入支撑包络，树冠不作地面角点。

目标投影P(w,d,h)=(48(w-d),24(w+d)-48h)。地块中心P(W/2,D/2,0)；包络中心对齐此点，每边退让≥0.1格。源四角O/W/WD/D与anchor独立于透明画布中心。先校正主轴方向，再统一等比缩放满足全部退让，输出实际墙身H与峰值H，禁止单独拉高。1×2与2×1分别生成、标定，不镜像替代。

正式比例板应使用统一48/24/48标尺同排放置10款，标出量得的包络/峰值与0.1格内边界，另排现有H2/H3/H4参考。若图未取得或未标定，只能称比例模板/概念板，不能称合格素材对照板。浅深背景、紧邻拼接、远近缩放须目视检查，未运行项保持待验证。

## 接入前门槛

用户先审阈值与造型，再量测/修订偏差、补足每组合双变体和4款平房，最后独立授权接入。未知/未来日期不生成零地块；院子不增加日期；普通合并保留原成员、真实count/date、同档和道路边界。未经复核不复用×2生成新高度组合；不改变既有奇观规划。本轮无运行性能结论。
