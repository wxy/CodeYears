## 主地面方向检查

精确规范来自 [projection-guide.svg](../../projection-guide.svg)：W 向右下，D 向左下；地面两组边斜率必须为 +0.5 / −0.5，竖直结构只沿图像竖直方向。模板约 ±26.565° 是规范值，不是本图片测量结果。

本轮在原尺寸图中人工观察两侧入口铺装的长直边、外墙底线，排除独立花池短边与弧形屋顶。可见落地长边大致为：

| 候选 | 可见方向的人工估计 | 结论 |
| --- | --- | --- |
| 体育场 A | 向右下、向左下两组边已较对称，约 ±30°，斜率量级约 ±0.58 | 两轴仍比 ±0.5 模板更陡，统一投影未通过 |
| 铁路总站 B | 正面入口铺装与右侧墙脚约为 +30° / −30°，斜率量级约 +0.58 / −0.58 | 同样偏陡，统一投影未通过 |

上述是依据可见长直段做的粗读，受花池遮挡、铺装边缘与像素抗锯齿影响；**不是像素级直线拟合，也没有精确角度测量精度**。不把 ±0.58 当作可直接用于变形的参数。竖边视觉上保持竖直，但没有逐条拟合。后方落地两角被建筑遮挡，无法可靠自动提取完整地面四角；单靠建筑最外轮廓或 alpha bbox 无法补足这一证据。

## 落地标定建议与未完成范围

1. 在标定预览里单独标记真正的 O、W、W+D、D 地面四角，入口花池和罩棚外挑不当作占地角。后方遮挡角需要由建筑设计者确认。
2. 选定全组共用的每格基向量 `u=(s,s/2)`、`v=(-s,s/2)`，以同一 s 定义 `O`、`O+3u`、`O+3u+3v`、`O+3v`；不能分别扩大图片填满框。
3. 现图需要重绘/重投影再核对这些方向。单纯旋转、统一缩放或调整锚点不能同时修正两组偏陡边；直接压扁整张图片也会改变竖直高度，不作为已完成的标定方法。
4. 在共同 3×3 地图模板上确认贴地、四边同向、邻接不穿插，并检查 H1 高度、玻璃屋顶/球场识别和浅深背景边缘。以上尚未进行。

本轮为独立造型素材与说明，不涉及运行控制流程、资源引用或构建配置，因此只做文件规格、alpha、可见造型与投影方向的静态检查，没有编译或端到端测试。
