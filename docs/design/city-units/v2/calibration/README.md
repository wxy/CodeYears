## 绘制时的标定规则

- **共同投影**：W=(48,24)、D=(-48,24)、H=(0,-48)。地面两组方向为±0.5，观看缩放不改变任何素材标定或位置。
- **建筑方向**：由实际主边端点得到mW、mD，使用 `x'=x`、`y'=-(mW+mD)/(2(mW-mD))*x + y/(mW-mD)`，将所记录的两条方向映射为±0.5，并保持竖线竖直。它不保证AI图中所有未测细节都来自同一个物理相机。
- **建筑居中与间距**：以L/F/R的逻辑地面包络中心定位，不用整张透明图、屋顶或冠部中心；缺失后角只用于摆放包络的平行闭合推断。按两向包络范围等比缩放，试排每边至少退让0.1格；相邻建筑在逻辑地面上至少留0.2格，不因此改变占用的日期格。0.1是当前试排参数，不是已冻结产品常数。
- **高度和占地同时约束**：先按可见楼身参考尺确定高度比例，再限制在留有间距的占地内。若两者冲突，保留等比形态并显示较低的实际高度，不拉伸楼身、不把它写成H1完全通过。这里是楼身基准，曲面屋顶、灯架和冠部另行检查。
- **平地四角**：按记录包络作四点单应映射，以三角网格绘制；源图的四边不平行时，不能用一个仿射伪装四边均通过。自然草岸四角是逻辑包络，不是物理相机证据。带木凳、花池等立体附属物的整图映射可能轻微倾斜，不能据此宣称附属物三维几何已恢复。
- **树木高度**：按可辨认单株根→顶统一试排为0.85自然高度；整片树林地面纵深不计入树高。被遮挡的根部推断仍需目视复核，自然枝叶不要求有地面平行边。
- **显示边缘**：仅在预览缓存中将alpha≤8归零、8–32渐进抑制，保留较高alpha和RGB；这能减轻极低值散点/软光，不是原PNG去底或叶片颜色修复。裁框保留来源中说明的边界，深浅合成仍单独检查。

预览单次解码后将图片长边限制为 768 像素，原缩略位图与边缘显示缓存复用；无连续动画，只有设置/尺寸改变时画单帧。离开中止请求、关闭位图并清空三个画布，不新建 WebGL。上述是本地标定工具行为，不能当正式扩展二十年性能验收。

City 直接引用以上 JSON，与预览共用 `src/renderers/unit-calibration.ts`；`probes/city-units/calibration.ts` 仅重导出，不维护第二套规则。运行时只加载场景需要的文件，同文件变体共用一次解码；双轴校正、地表映射和 alpha 显示处理只在加载时烘焙为长边不超过 384 像素的透明画布，随后关闭源位图。每帧复用烘焙结果，关闭控制器时清空这些画布。幼树由单树的相同原图以 0.35 自然高度复用，不增加新 PNG；单树/树林沿用 0.85 自然高度。此处描述资源所有权与规格，实际加载、失败和关闭证据需以对应运行报告为准。

## 当前明确限制

居中与 0.1 格退让后，两款住宅楼身参考为 1H；警局约 0.606H、消防局 0.575H、体育场 0.714H、总站 0.788H，四款受到占地/高度比例约束。它们当前以实际低矮设施形态进入 City，不拉高楼身；不能同时宣称原占地与 H1 目标完成。后续可按实际观感调整造型或适用组合，不为追求标签数字破坏等比形态。旧中高层的目标 H2/H4 也只是楼身参考，完整塔冠未据此验收。

低值alpha抑制不解决所有黄绿叶缘或主体旁较高alpha光晕；花池等立体道具的平地变形、后角/遮挡根部、完整顶部高度与邻接遮挡仍待美术复核。当前完成的是可复核的测量、显示映射和拼接检查，不将这些限制降格为“全部素材已验收”。

实际构建、逐款浏览器、缩放/间距及失败/离开检查见 [标定报告](../../../../reports/UNIT-CALIBRATION.md)。
