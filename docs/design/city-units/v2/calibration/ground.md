# 地表候选视觉标定

日期：2026-10-31。范围：两款池塘、两款广场、四款草地。状态：**原图只读测量与逻辑包络建议；未修改 PNG，未接入，未作地图接缝验收。** 数据见 [ground.json](ground.json)。

## 坐标与依据

- 全部坐标使用原 PNG 的绝对像素，左上为原点。`crop=[x0,y0,x1,y1]` 的右/下为开区间，不是 xywh；`anchor` 是逻辑地块中心，不是图像中心或 alpha 质心。
- 目标方向固定为 W=(48,24)、D=(-48,24)，竖直线保持竖直。`footprint` 是设计的世界格占地；`targetHeight=0` 不表示草叶、花池或芦苇没有可见高度。
- 广场用可见铺地直边，沿用来源文档的手工粗测点并再次查看原图。两个近侧方向独立记录，没有用一条边推定另一条。
- 草地/池塘没有可恢复的精确直边。`axes` 记录近侧自然轮廓的代表弦：对每个指定 x，读取 x−5 至 x+5 共 11 列中 alpha≥64 的最下 y，取中位数。这些是实际可重复的轮廓采样，不是物理相机或地块直线的恢复。草叶、石岸的自然起伏会影响短弦斜率。
- `footprintCorners` 的 T/R/B/L 是后/右/前/左地表包络点，均为目视粗估，数像素到局部十余像素的不确定性未量化。草地和池塘的四点只定义逻辑包络；广场 B 的 T 被花池部分遮挡，为沿可见远边延长的推断。`anchor` 取两条包络对角线交会处，取整到像素。
- `crop` 统一采用 alpha≥8 主体外框向四周扩 8px，以包含细叶和软边、排除远离主体的极低 alpha 残留。它是建议显示区域，不是硬性 alpha 清理规则，不删亮色叶缘，不改原图。

## 尚存限制

广场 A 有明显的低 alpha 黄绿光晕。所给矩形裁剪只能限制远外围残留，主体旁仍位于矩形内的光晕不会消失，不能据此认定透明边缘合格。其四边斜率并不完全一致；广场 B 也有较小的不平行。单个仿射变换不能让原本不平行的两条边同时变平行；统一近侧方向后，仍应在拼接图上检查远边残差。

池塘和草地的包络无需严格平行，自然岸线与草缘不得被当成几何错误逐点抹平。1×1 与 2×2 草图在原始像素上没有统一世界尺度，文件画幅与 alpha 外框不能作为最终比例尺。高度参考均为 null，不使用芦苇、花池或草叶推导建筑高度。

本次仅进行原图目视、Pillow alpha 只读统计与轮廓取点，以及 JSON 的静态检查；未运行应用编译或端到端检查，因为没有应用代码和运行资源变更。后续接入与拼接验收由统一标定流程处理。
