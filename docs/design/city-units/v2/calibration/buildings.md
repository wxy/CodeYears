# 六款建筑候选的只读标定

日期：2026-10-31。状态：**已记录供投影预览使用的坐标；未接入运行库，未完成地图验收。** 数值见 [buildings.json](buildings.json)。本批只写这两份元数据文件，原 PNG 未改动。

标定是**渲染时坐标映射**，不修改原 PNG。目标为 W 轴向右下斜率 +0.5、D 轴按 x 递增向右上斜率 −0.5，竖边保持竖直。二维仿射映射能够校正选定两组主边的方向；不能由此证明遮挡部分的物理几何、真实占地四角或所有细部均已满足同一相机。H1 仍是视觉单位。

## 字段与证据边界

- `file` 相对 `docs/design/city-units/v2/`；所有坐标均为原图像素，未按预览尺寸换算。
- `crop=[x0,y0,x1,y1]` 为 Pillow **alpha>8** 主体边界框，左闭右开；是绝对边界，不是 xywh。它保留 alpha 9–128 的可见边缘，同时排除很浅的残余；没有修改源 alpha。
- `axes` 使用 `{W:{points,basis},D:{points,basis}}`，两组独立记录。每组给出实际采样首末点，供计算端点斜率；文字中的最小二乘拟合是对整段采样的结果，两者会有亚像素取整差异。
- `anchor` 为目视选择的可见落地接触点，约 ±5px；部分取入口台阶、铺装或花池底脚，并非暗示这些都是逻辑占地的最前角。
- `supportEnvelope={L,F,R,basis}` 为可见贴地部分的左、前、右三个摆放包络点，约 ±10px。包括必要入口铺装、台阶和贴地花池，排除树冠、屋檐、曲顶和宽柔光；没有从整图或 alpha 包围框换算占地。它供双轴校正后与 W×D 地块比较，属于逻辑摆放包络；局部台阶突出、转角削切与不对称仍需显式显示，不能宣称三点已经证明物理矩形足迹。
- `heightReference` 选同一竖线上的可见楼身基底与檐口/柱帽，约 ±10px，提供主楼身的视觉高度参考。烟囱、设备、挑篷和灯架不作 H1 标尺。前后立面进深造成的图像高度不算楼身高度。
- 六款的后方地面角均被建筑遮挡，本批没有输出伪装成可见证据的四角。如果后续预览从轴线和目标 W×D 补出后角，必须标记 `inferred`。`footprint` 是已确认的设计目标，不是这批图片已经证明的物理尺寸。
