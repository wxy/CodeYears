# City 奇观单元 · v4

## 已确认的方向

第一版仅体育馆、剧院、地标公园。奇观表达持续密集贡献区域，以较大占地替代部分楼宇丛林；不是新的 GitHub 活动分类，也不是对贡献数量的改写。地标公园具有温室、轴线园路和中心景观，区别于低贡献的普通草地。

沿用固定视角、透明素材、W=(48,24)、D=(-48,24)、竖边竖直、居中留距。缩放、平移与重播不能重新规划奇观。原始PNG保留，运行副本与来源一致；渲染时复用现有标定与烘焙流程。

| 单元 | 原生占地 | 主体参考高度 | 特征 |
| --- | --- | --- | --- |
| 体育馆 | 4×3 | 约0.809H，上限1.1H受占地约束 | 石材、青铜支撑与蓝灰环形顶棚 |
| 剧院 | 3×3 | 主柱2H，弧顶高于标尺 | 赤陶石材、青铜拱顶、入口台阶 |
| 地标公园 | 4×3 | 主温室参考1.5H，顶饰另高 | 温室、轴线园路、修剪树木与喷泉 |

高度是所记录构件的视觉参考，不能称作整张素材精确物理高度。园区包络及隐藏角点有推断，屋顶、曲面、植物细节未恢复为精确3D模型。为避免大占地素材缩成小单元，剧院/公园保留较饱满比例，不强压到最初讨论的1–1.5H。

三款完整提示、源文件路径、哈希和可见/推断量测依据在各自 `candidates/wonders/*-SOURCES.md`，运行与预览共同使用 `calibration/*.json`。

## 初版布局参数与待验证项

先选奇观区域，再在剩余日期格做普通同档合并。候选只能使用已加载日期，不能跨季度道路或年份；每年最多两处，区域不得重叠。保留完整成员索引、每日日期和数量、区域合计与均值。

以活跃比例≥90%、建筑比例≥80%、中高档比例≥75%筛选，均向上取整；先按建筑密度、再按日均贡献×√面积排名，兼顾强度与疏解楼群的覆盖面积。3×3剧院与4×3体育馆/公园不要求成员同高。阈值和评分是首版可调设计参数，不是验证出的最佳值。不能保证每年生成，稀疏/全零区域不应为了凑齐目录生成奇观。纯规划默认关闭，本地绘制接入后显式启用；对照页面使用同一份输入分别开/关。

验收使用同一份确定性输入并排显示普通楼群与奇观；核对成员守恒、类型覆盖、道路边界、浅深外观、近远景、缩放平移稳定与播放释放。真实MV3结果与示例结果分开记录。完整性能预算和用户最终美术选择另行验收。
