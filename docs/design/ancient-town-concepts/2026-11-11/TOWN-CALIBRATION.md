# 小镇素材校准与正式运行资源

> 初轮记录。接入前独立复核发现包络拟合不足以证明可见构件方向，最新方法、41张准入资源与农场组件替换见 [透视复核](PERSPECTIVE-AUDIT.md)。下方45张资源规格和旧接地跨度对应初轮快照，不代表最新校准验收。

日期：2026-11-11。范围：透视与人尺度校准、预烘焙资源、实际浏览器加载/释放路径。这里不代表扩展入口、真实登录、整张地图性能或主线合入已经验收。

## 选用的素材与方向

- 旧小屋与多格长屋/农场继续使用 2026-11-10 原始 PNG，透视数据放在 [classic-projection-v2.json](classic-projection-v2.json)。
- [magic-town-v2.json](magic-town-v2.json) 为混合来源目录：0/1 圆形小屋继续使用 v1 的紧凑造型，2–8 采用 v2 的低矮建筑与设施；`source` 明确标记使用 v1 的两帧。宽平台版圆形亭院不冒充适合单格的小屋。
- [town-life-v1.json](town-life-v1.json) 标定人物、动物、花树、集市、长椅与泉台。人物与动物只表达生活场景，不代表贡献者人数或产出。

地面有可见主边的素材，记录左、前、右三个接地参考点，得到两条斜率 `mw`、`md`；使用 `vertical=1/(mw-md)`、`shear=-(mw+md)/(2*(mw-md))`。变换保持 `x` 不变，故竖边仍竖直，地面主边映射为 `+0.5/-0.5`。圆形水平基底记录椭圆参考，归一到 2:1。它们都是人工设计包络，不声称恢复隐藏地面的真实物理几何。

v1 温室和 U 形行会的源图视角过低，直接方向校正会把总投影图高放大到约 4.02 / 5.84 原型单位。v2 重画后主边更接近目标方向：温室约 `(+0.429,-0.397)`，U 行会约 `(+0.516,-0.505)`，实际只需约 1.21 / 0.98 的纵向方向校正。

在有可辨认居民的六个魔法建筑上另标人物参考：完整人物上限 0.44 原型单位，工作窗内可见上半身上限 0.24。取地面适配与人物上限中较小的**同一个缩放倍率**，不为填满名义占地再次拉高。最终温室和 U 行会总投影图高约 2.36 / 2.87；这里包含地面深度，不是楼层高度或真实建筑高度。

源 PNG 不变；方向校正、低 Alpha 边缘处理和缩图只产生新的运行 PNG。Alpha ≤8 清零、8–32 逐渐减弱的规则与既有城市素材一致，避免生成图极低透明度边缘在反复缩小时污染轮廓。

## 名义预留与实际接地跨度

`nativeWidth/nativeDepth` 是目录预留尺寸。`groundWidth/groundDepth` 是校准并受人尺度限制后的接地包络跨度。两者均不是建筑翼间真实实体占用面积；U 形院落和农场内空隙仍在包络中。人物等只有点锚的装饰，使用声明占地并标记 `groundBasis="declared-decoration"`，不伪称量测得到零面积；有接地参考的项目标记 `manual-source-envelope`。

## 运行资源与复现

- [预烘焙脚本](../../../../scripts/bake-town-assets.mjs)：只监听 `127.0.0.1` 的一次性服务，使用独立临时 Chrome 配置，完成后关闭服务并清理配置。
- [目录元数据](../../../../src/renderers/town-baked-catalog.json) 与 `public/assets/town-runtime/`：45 张 RGBA PNG，全部长边 ≤384，总计 **5,300,863 字节**。源文件大小不是内存、显存或性能测量。
- ID 为 `cottages-0..11`、`forms-0..8`、`magic-0..8`、`life-0..8`；`forms-0/1/3/4/7`、`magic-2` 另有 `-x` 水平镜像，镜像交换地面两轴。
- [运行加载器](../../../../src/renderers/town-assets.ts) 兼容 `CityImages`，只解码所选预烘焙 PNG；运行时不再校准或处理源图。释放共用 `closeCityImages`。

素材脚本命令：

```sh
node --check scripts/bake-town-assets.mjs
node --check probes/fantasy-city/project-sprites.js
node scripts/bake-town-assets.mjs \
  --outDir public/assets/town-runtime \
  --catalog src/renderers/town-baked-catalog.json
```

需要查看校准板时加 `--board "$TASK_TMP/board.png"`，查看结束后删除该过程图。目录的 `left/top/width/height` 按正式 `createCityView` 的 `[(x-z)*0.5,(x+z)*0.25]` 投影单位计算，以名义地面左上角为原点；没有把原型的整幅图当作扩展运行贴图。

全部 45 张运行 PNG 已完整解码、核对尺寸/Alpha，并在本机浏览器校准板实际查看。可见的主地面方向统一，竖边不倾斜，低矮 v2 建筑没有 v1 的高教堂形态。目录 SHA-256 为 `8b6925efcb9ce82f7e0e05b27520f170cb3ceb49597ff3d4f7964c6d81f31477`。

## 加载器浏览器验证

环境：本机 Chrome 157.0.8103.39 headless、Node v26.7.0。一次性 Vite library build 编译**实际** `town-assets.ts` 和 `closeCityImages`，临时本机服务提供真实 45 张运行 PNG。素材 base URL 使用与正式调用一致的绝对 URL。测试页记录真实 `ImageBitmap` 解码/关闭和画布尺寸，不替换实际加载实现。

| 路径 | 实际结果 |
| --- | --- |
| 成功载入全部资源，再释放 | 解码 45、关闭 45；45 张画布全部归零 |
| 一图 HTTP 404，另外两图成功 | 整批失败明确上抛；解码 2、关闭 2，两张画布归零 |
| 调用前已取消 | `AbortError`；解码/画布均为 0 |
| 解码阶段触发取消 | 整批取消失败；解码 3、关闭 3，三张画布归零 |
| 全部路径 | 未处理 Promise 拒绝为 0 |

最初测试页误用相对 base URL，纠正为接口要求的绝对 URL。随后 `--dump-dom` 的虚拟时钟在最后取消路径结束前退出，取得请求序列后定位为测试等待方式；改为真实时钟的持久 headless 浏览器，等待页面 POST 完成报告后关闭。最终四条路径均通过，没有修改生产加载器来掩盖测试错误。

校准板、初轮烘焙目录、临时模块/页面、浏览器配置及测试结果 JSON 在记录后清理。这里保留校准源数据、正式素材生成器、运行产品素材和本报告，不保留测试过程附件。

## 限制

本轮完成主轴方向和可见人物的比例约束；精确 Alpha 地面包络、所有隐藏接触点、每个门洞对齐及复杂建筑之间的遮挡仍需主场景验证。人物参考是手工可见特征，不是摄影测量。运行加载器的释放证据不代替整张地图切换、真实登录 MV3、Edge 或硬件预算验收。
