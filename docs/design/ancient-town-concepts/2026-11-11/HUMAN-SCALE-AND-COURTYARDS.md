# 建筑、门窗、人物与独立围院校准

日期：2026-11-11。用户指出上一轮农舍与畜舍不协调、人物偏小，并要求每栋建筑各有围墙。本轮先完成可复看的美术校准原型，**暂停继续接入地图**；没有覆盖 `src/`、41张运行PNG、正式地块选择或扩展入口，也没有合入主线或发布。

## 原因与共同尺度

旧流程分别按名义占地适配建筑、按整图高度适配人物，六栋魔法建筑的人员参考也只是缩小上限。院落组合又对不同建筑使用不同倍率。地面方向相同，并不能证明门窗、建筑和人物共享尺度。

本轮改为由净门高或实际可见人体参考决定唯一等比倍率，接地范围随这个倍率计算，不再被原名义占地反向缩小。比较图使用同一镜头倍率（140像素/原型单位），单个模型和人物不按卡片或庭院重新fit；大建筑扩大展示空间。

| 项目 | 本轮设计尺 |
| --- | --- |
| 标准成人头顶至脚底 | 0.8原型单位，约1.7米；帽子、发髻另算 |
| 普通人行门净高 | 1.0原型单位，约2.1米 |
| 普通工作窗参照 | 约0.48原型单位，约1米；特色大窗单独说明 |
| 矮墙/木栏 | 0.32原型单位，约0.7米 |
| 立柱 | 0.4原型单位，约0.9米 |

米制是美术设计基准，不是对源建筑的物理测绘。各类门窗不强制形状相同：行会中央仪式门约为普通侧门1.35倍，学院中央门约1.12倍；炼金庄园的大特色窗保留其功能。被花遮挡的玻璃只记可见段下界，不能称完整窗净高。

## 素材处理

- [经典尺度观测](scale-classic-v1.json) 覆盖10小屋、6旧形态及首版单体畜舍。`cottages-1`、`forms-0`、旧`forms-7`的人门源净高约88/42/28像素，说明直接沿用占地适配无法建立共同尺度。没有可见门的旧变体保留推定或未识别状态。
- 旧`forms-7`包含多栋建筑，不能按最后一栋的小门证明整图各栋尺度一致。本次农场改用单体农舍与单体畜舍，分别标定、分别围院。
- 新畜舍v1在第一次合成后发现门虽等高，净宽仅约0.155原型单位。再次用内置图像工具只针对门口重画；[v2观测](scale-stable-v2.json) 的源净高213像素、宽端点横跨188像素。最终门净高1.0、净宽约0.348原型单位；没有靠缩小居民来迁就门。v1保留为被替代的设计源，不用于最终预览。
- 新圆形工坊没有烘焙小人物，[门窗及遮挡观测](scale-mage-workshop-v1.json) 明确门净高280像素、工作窗约135像素。预览将同一标准学徒放在窗内，保持完整人体尺度，下半身由窗台遮挡；先限定窗口，再逐个扣除木撑/瓶子遮挡，避免越界孔反向露人。
- 新行会、学院提供明确人行入口，[观测](scale-guild-academy-v1.json) 分开记录普通侧门与中央大门，不把不确定的符文板当门。统一尺度的学者和居民放在开放院内。
- [魔法与生活组件观测](scale-magic-life-v1.json) 修正几处旧人员参考偏移，区分全身与仅上半身。温室只见上半身，按约0.55成人的设计比例推定；不能声称取得隐藏双腿的独立测量。

工具、版本文件及完整提示词见 [生成提示词](HUMAN-SCALE-PROMPTS.md)。原来的五张图集、旧标注和所有运行图保留不变。

## 每栋建筑自己的围院

[围院绘制](../../../../probes/fantasy-city/private-courtyards.js) 按每个独立建筑生成矩形庭院，侧边留0.3、后侧0.2、前侧0.8原型单位。矮石墙或双横木栏高度固定，不随庭院变大而加高；四边留稀疏断口，前侧院门连入户路。

后墙先画，建筑/居民随后，前墙最后画，保持遮挡。农舍和畜舍拥有两个互斥的院落及两个院门，分别接到共同小路；没有用一条总围栏代替两栋建筑自己的院界。连成一体的行会/学院侧翼作为一栋建筑，围住整栋及其内院。

## 接入门槛与未完成范围

这组图建立共同人物/门窗尺度及一栋一院的原型。28项诊断记录不是28项都已准入：没有可见门的旧小屋、短线误差可能影响结论的净门宽、旧混合农场及内部比例不一致的动物组合仍需逐项取舍；不会把它们一起送进正式地图。

统一尺度使长屋、温室及学院占地显著增大，后续必须按真实容量重新匹配贡献区域，不能为了塞回旧八日/四格容量再缩小人物或建筑。本轮尚未改正式合并算法、地图摆放或运行资源。没有重跑扩展登录、地图切换或性能矩阵；新增的是独立美术工具，已选语法检查及直接浏览器成图验证，不把原型结果写成正式扩展验收。

最终两张设计图仅保存在本机可视化目录，不入Git；源PNG、人工标注、原型工具、提示词与本报告属于正式设计输入。一次性预览、中间图、裁图、诊断JSON、日志、浏览器配置及临时工作树在报告后清理。
