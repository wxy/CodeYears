# 经典小屋与多格建筑：独立方向证据复核

补充：整板复看时为42张，后续再排除过窄集市，最终运行目录为41张；其余图片不变。

日期：2026-11-11。本记录针对 10 个旧小屋、9 个旧多格形态；魔法与生活图集由另一位审阅者独立处理。源 PNG 保留不变，测点坐标相对各自 crop。

## 本次纠正的验证边界

此前从支撑包络 `L/F/R` 反算校正矩阵，再检查这两条包络连接线变成 `±0.5`，只证明矩阵按输入工作，**不是独立可见构件的透视验收**。本次将方向 `axes` 与支撑包络 `ground` 分开：方向参考来自可辨认的基脚、门槛、水平系梁，支撑包络仅用于适配与锚点。

`axisBasis` 明确区分 `measured` 与 `inferred`。人工可见测点通常约 ±2 源像素，forms-7 的短线约 ±3；短段对应较大的角度不确定性，不能据小数位数宣称高精度。共享构造推定、遮挡线和缺少足够独立证据的素材不写成逐项量测通过。

## 19 个原生素材的处理

| 组别 | 证据与处理 |
| --- | --- |
| `cottages-0/6` | 两条实际可见基础/门槛方向，另记一条长立柱用于复看竖边 |
| 其余 8 个小屋 | W 明确沿用同族共享基础构造推定；1/3/4/7/8 的 D 另记暴露基脚段，2/5/9 的 D 保留推定。不是八帧各有两条独立测量 |
| `forms-0/1/2/3/4/7` | 分别使用可见水平系梁、门槛、庭院石砌边或同一马厩木梁，必要时附短段 `checkAxes`；没有把斜屋脊当水平轴 |
| `forms-5/8` | 基脚短碎或被装饰遮挡，只有低精度/部分推定。首版未引用，标记 `runtime:false`，保留候选图与注释 |
| `forms-6` | 复合农场内不同建筑的局部朝向与统一相机尚未充分确定，标记 `runtime:false`，不再由一组全图轴强行拉齐 |

典型独立证据：`cottages-6` 的 W 为 `(63,287)→(102,300)`，D 为 `(227,306)→(316,276)`，斜率约 `+0.333/-0.337`；旧包络反推却约为 `+0.423/-0.313`。它说明旧包络方向不能替代真实可见基础方向。

排除 forms-6 并不等于证明原图相机错误：不同房屋可以有意采用不同 yaw，不能仅因单独的 D 方向不同就判错。JSON 保留同一谷仓的成对参考及另一幢马厩的 `checkOrthogonals`，并注明矩形平面假设和点误差；缺少充分确定的结果时不作统一相机通过结论。新生成农场候选也未形成足够独立证据，不因已经生成就采用。

## forms-7 的关键复核与撤回记录

原图坐标尺板和轴叠加后，保留同一前部马厩的：

- W：`(24,258)→(81,271)`，山墙底水平系梁。
- D：`(104,280)→(143,260)`，右侧下方水平木栏。
- 独立 D 短段：`(103,258)→(138,241)`，右侧檐下/上方水平木梁，约 `-0.486`。它与下方木栏约 `-0.513` 接近，但仍是端点约 ±3 像素的短段佐证。

最初提出的主仓长线 `(166,242)→(222,214)` 在叠加后发现穿过干草/开口，没有连续可见构件支持，**已撤回**，不能保留其残差或把它当作长主仓方向证据。当前短段只支持同一马厩的方向，不证明整个线形农场每一幢建筑均为同一 yaw。

## 交付状态

独立方向、推定理由、短段与竖边注释位于 [classic-projection-v2.json](classic-projection-v2.json)。旧 forms-5/6/8 的图与测线保留为设计记录，首版用已选择且证据较充分的形态与低矮附属屋组合，避免分发未充分确定的旧候选。

方向校正、重烘焙及 42 张最终运行图的统一板由主代理执行和输出。对最终板另做了一次整体独立视觉复看，未发现新的明显倾斜、脱地或错误扭曲：竖柱直立，保留长屋与线形农场及镜像没有明显错误翻转，v2 魔法建筑保留低矮形态，人物/动物/花树没有被硬套建筑地面轴。

这一结论限于可见方向与整体观感，仍保留共享构造推定、人工圆基底和装饰仅落脚/尺寸的边界；不能改写为 42 张每个构件都已通过完整独立相机验证。临时坐标尺板属于本次复核过程，记录后清理。完整 Alpha 包络、隐藏接触面和所有装饰构件仍不是本次有限方向复核所能证明的内容。
