## 原型与正式模型的区别

[设计原型](MAGIC-TOWN-PROTOTYPES.md) 按公历年度、严格相近矩形再按区域均值档二次合并，真实三年为 270 个地块。

正式模型按现有数据入口的 ISO 周年组织，同日强度档的相邻矩形按建筑容量合并，最多八日、最长四格，不固定按四周/十三周切块；同一输入为 296 个正贡献地块、300 个主/附实体。两者都保持真实日期与贡献总量，不将原型截图当作正式地图运行结果。具体参数仍可经设计反馈调整。
