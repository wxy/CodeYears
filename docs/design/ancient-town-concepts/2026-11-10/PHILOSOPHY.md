# 聚落节律

空间以连续的土地承接时间。房屋、院落与小径形成可辨认的整体，像素颗粒与轮廓经过精细推敲，让屋瓦、木梁和植物保持清楚层次。采用 Agent Control Plane 原创中世纪魔法小镇的视觉语言，细致而自然的秩序来自统一的投影与熟练的材质处理。

材料承担发展的线索：茅草、深色木构、苔石逐渐组合为规整瓦顶、完整院墙与铺装。工坊与行会的开敞立面露出工作台、工具和书架，建造形态与陈设完成度传递成熟感，建筑保持低层尺度。轮廓、屋瓦接合和室内细部需要熟练工匠般的克制，每一处变化都具有可辨认的作用。

色彩来自赭红与蓝灰屋瓦、温暖木石、金绿草地和蓝绿植被。灯笼和室内暖光形成小而清楚的亮点，藤蔓、花盆与苔石补充生活感。精心控制冷暖和材质对比，让不同建筑在远观时能区分，在近观时有可探索的细节；颜色辅助识别，形态和完成度承担主要含义。

较大的土地由完整建筑平面组织：长屋、连续侧翼、U 形院落与围合回廊各自形成可辨认的整体。合并的尺度决定单元数量，平均强度决定形态与完成度；门窗和檐口保留共同尺度，内部院落承担空间变化。独立建筑落在连续地面和公共道路之上，严谨的包络与反复校正的退让使整体保持秩序。

画面使用留白充足的浅色版面、清楚的上下对齐与少量标注。文字只负责说明比较条件，主要信息由材质、组合和空间关系呈现。细微的边界与参考刻度帮助观者比较，精确到位的对齐使整体像一组经过仔细审订的建筑研究图。
