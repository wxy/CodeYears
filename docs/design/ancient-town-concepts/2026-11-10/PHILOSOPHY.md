# 聚落节律

空间以连续的土地承接时间。贡献接近的相邻日期自然形成大小不同的地块，屋舍、工坊与村落随占地组织成可辨认的整体。采用 Agent Control Plane 原创西式奇幻小镇的细致像素语言，陡坡山墙、半木构、石砌烟囱与铅框玻璃形成清楚的建筑轮廓，统一投影和精确的细部处理使变化保持秩序。

材料承担繁荣的线索：茅草、深色木构、苔石逐渐组合为精细门窗、交错山墙、完整铺装与讲究的作坊陈设。半木构村屋、铁匠铺、行会和精致奇幻工坊拥有不同的平面与功能外观，低层尺度中的完成度传递发展差异。轮廓、屋瓦接合和室内细部需要熟练工匠般的克制，每一处变化都具有可辨认的作用。

色彩来自赭红与蓝灰屋瓦、温暖木石、金绿草地和蓝绿植被。灯笼和室内暖光形成小而清楚的亮点，藤蔓、花盆与苔石补充生活感。精心控制冷暖和材质对比，让不同建筑在远观时能区分，在近观时有可探索的细节；颜色辅助识别，形态和完成度承担主要含义。

土地的大小来自可合并的连续范围，繁荣来自区域平均强度。宽阔地块可以是一处朴素村落，紧凑地块也可以容纳精致的奇幻工坊；大小、繁荣和建筑高度保留各自含义。门窗和檐口有共同尺度，独立建筑与少量建筑组成的聚落落在连续地面上，严谨的包络与反复校正的退让使整体保持秩序。

画面使用留白充足的浅色版面、清楚的上下对齐与少量标注。文字只负责说明比较条件，主要信息由材质、组合和空间关系呈现。细微的边界与参考刻度帮助观者比较，精确到位的对齐使整体像一组经过仔细审订的建筑研究图。
