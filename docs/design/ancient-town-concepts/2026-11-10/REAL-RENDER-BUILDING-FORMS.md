# 真实贡献渲染：长屋、侧翼庄园与完整农场

日期：2026-11-10。状态：**独立本机设计原型，未接入正式扩展**。针对大地块仍只有一栋小屋、空院过多的问题，新增专用多格建筑素材和形态选择。矩形合并、日期网格及边界路网沿用 [庭院版](REAL-RENDER-COURTYARDS.md)，不为新建筑重排或扩大数据地块。

## 形态与贡献如何对应

占地的面积、长宽和方向决定平面，区域均值决定乡间/工坊、普通侧翼/行会等完成度；没有把贡献值乘到建筑高度上。规则为本轮设计候选：

| 条件，按此顺序匹配 | 建筑形态 |
| --- | --- |
| 单格 | 原单格小屋，继续使用五档外观 |
| 低两档、至少四格、宽高均至少二格 | 农舍、谷仓、马厩与工作院组成完整农场 |
| 低两档、至少四格、窄长 | 线形农舍与仓储、畜舍组合 |
| 宽高均至少二格，宽高比至少 1.6 | 宽厅与相连双侧翼的庄园 |
| 其他宽高均至少二格 | 第三档为 L 形庄园，更高档为 U 形行会庄园 |
| 其余多格 | 低两档为乡间长屋，较高档为工坊长厅；按长边选择方向与版本 |

完整农场最低四格，是因为本轮需放下附属建筑和通行空间。上一版三格低档区域只有主屋配菜畦，本版三格区域可用乡间长屋。两者都是候选造型规则，未修改正式合并阈值。

新增九格通用图集包含乡间长屋、工坊长厅、深长版本、L 形庄园、U 形庄园、完整农场、线形农场与宽侧翼庄园。初次生成的门窗相对小屋偏大，因此通过内置图像工具重画为低矮、多开间形态，再用于最终渲染。没有把素材整体压扁或拉长。

新素材使用人工初标的地面名义包络、前角落脚点与像素比例。按可用长宽取**同一个等比倍率**，最大 1.15；需要时水平反射交换两条地面方向，不把平面图片旋转成错误透视。沿后边界退让，前方保留入户路。花圃/菜畦避开建筑包络和入户路线。

名义矩形包含侧翼间的院落和农场建筑间的空隙，面积不代表真实屋顶或墙体面积。实际等轴屋檐仍允许正常前后遮挡，精确 Alpha 包络尚未验收。
