日期：2026-11-10。状态：**真实公开来源的数据分析，非扩展运行验收**。仓库只保留本报告，真实 HTML、逐日数组、地块明细和临时脚本不进入 Git；用户查看的最终数据可视化成果保存在本机可视化目录，不属于测试过程截图，也不纳入 Git。

## 结论

七列日期网格与互斥矩形可以完整表达这组真实数据，但现阶段“相近”的定义过严，实际合并效果远小于此前合成样本。按前稿复算代码的排序和 `max−min <= max(2,25%×均值)` 条件，三年最大地块都只有 4 个日期格。

2026 年的 222 个活跃日合成 166 个单元，其中 119 个是单格；只减少 25.2%。将相对容差放宽到 50% 后为 148 个单元，最大 6 格，仍不能据此规划大量大村落素材。

诊断性地去掉贡献强度限制、仍只允许网格上相邻的非零日期格组成矩形时，2026 年可以出现 3 列 × 18 行、54 格的矩形；但该区域成员日为 2–104 次，不能直接解释为贡献相当。当前主要限制是所选相近条件与实际日间波动，而非网格无法容纳大矩形。诊断结果不是建议采用的合并规则。

## 解析与覆盖核对

- 标题须唯一匹配英文年度及合计；只在唯一 `ContributionCalendar-grid` 内读取 `data-date`。
- 数量来自 `tool-tip[for]` 与日期格 ID 的唯一绑定；校验 tooltip 月日、合法日期、重复日期、完整源年覆盖和非负整数，没有读取 `data-level` 推算数量。
- 三个响应的逐日合计均与其年度标题相等；2026 的未来零占位剔除后合计仍相等。
- 六组正式试算及三组诊断均核对：每个活跃日期恰好归属一个矩形，没有重叠、丢失贡献或跨入范围外日期；矩形宽不超过 7。
- 单元数不是物理房屋数，不据此推断帧率、性能、代码质量或产出。
- 解析采用 Python HTMLParser，校验规则参考现有 `src/data/parse-year.ts`；没有运行正式浏览器扩展解析路径，不能写为真实登录 MV3 通过。

3. 映射坐标：`x = 日期.weekday()`（周一 0）；`y = (日期 − 该年首个日期所在周的周一).days // 7`。首尾没有提供的格子不加入输入。

5. 如需连续性诊断，保持其余条件，临时移除强度差判断；该结果只作原因分析。

以下为已校验逐日数组 `days` 的网格与合并核心。它可直接用于复算年度公开快照，不依赖临时绘图脚本：

```python
from datetime import date, timedelta
anchor = date.fromisoformat(days[0]["date"])
anchor -= timedelta(days=anchor.weekday())
grid = {}
for item in days:
    day = date.fromisoformat(item["date"])
    grid[day.weekday(), (day-anchor).days//7] = item["count"]
rows = max(y for x,y in grid) + 1
def trial(relative):
    candidates = []
    for y in range(rows):
        for x in range(7):
            if grid.get((x,y),0) <= 0: continue
            for width in range(1,8-x):
                values = []
                for height in range(1,rows-y+1):
                    row = [grid.get((xx,y+height-1)) for xx in range(x,x+width)]
                    if any(v is None or v == 0 for v in row): break
                    values += row; mean = sum(values)/len(values)
                    if max(values)-min(values) <= max(2,relative*mean):
                        candidates.append((x,y,width,height,mean))
    candidates.sort(key=lambda p: (-p[2]*p[3],-min(p[2],p[3])/max(p[2],p[3]),p[1],p[0]))
    used = set(); selected = []
    for x,y,width,height,mean in candidates:
        cells = {(xx,yy) for xx in range(x,x+width) for yy in range(y,y+height)}
        if cells & used: continue
        used.update(cells); selected.append((x,y,width,height,mean))
    assert used == {p for p,v in grid.items() if v>0}
    assert sum(grid[p] for p in used) == sum(item["count"] for item in days)
    return selected
```
