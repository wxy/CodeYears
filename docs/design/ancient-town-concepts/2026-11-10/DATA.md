## 可重复计算

下列代码可在 Python 3 中复算此文件表格；`weeks` 为上方逐周表的 D1–D7 数字。

```python
import hashlib, json
days = [value for week in weeks for value in week]
print(hashlib.sha256(json.dumps(days, separators=(",", ":")).encode()).hexdigest())
for span in (4, 13):
    for start in range(0, 52, span):
        values = [v for week in weeks[start:start + span] for v in week]
        mean = sum(values) / len(values)
        level = 0 if mean == 0 else 1 if mean < 1.5 else 2 if mean < 3 else 3 if mean < 8 else 4
        print(start + 1, min(start + span, 52), sum(values), len(values),
              mean, sum(v > 0 for v in values), level)
```
