# 七列日期网格上的矩形自适应合并

状态：2026-11-10 概念研究。用户明确西式奇幻、按相近贡献合并，以及每周七天为一行的规则网格。当前图只做设计与数据试算，尚未实现产品渲染器；相近容差、素材尺寸目录和四周分组边界策略仍待确认。

## 网格与拼接规则

- 基础网格固定为 **7 列**，一行对应一周，列对应星期；本例 52 行，共 364 个已知日期格。
- 每四行显示一次四周分组导引。四周不是固定公历月份，真实月份应按实际日期标记，不删去每月第 29–31 日。导引线在本轮只作视觉节奏，不强制切断相近区域。
- 合并单元限定为轴对齐的整数矩形，记录 `(x, y, width, height)`；`x + width <= 7`。面积可以不同，方向和格子边界一致。
- 已分配的日期格不再参与其他合并。一个日期格最多属于一个单元；剩余已知日期可用较小矩形或 1×1 单元覆盖。
- L 形、T 形等相近连通区域拆成多个矩形，不能直接把不规则外轮廓当作一张建筑素材。
- 本轮零值日保留自然地面，不生成建筑；它们仍属于完整日期网格。没有建筑的格子不等于遗漏日期。
- 地块占用互斥保证地面占地不交叉。正式素材另需满足屋檐/地面包络、退让和入口要求；等轴投影中的正常前后遮挡仍需按深度绘制，不能把地块不交叉误写为屏幕上绝无遮挡。
- 所有建筑共用连续地面和道路，西式奇幻建筑采用不同合法矩形占地；较大地块可以容纳少量建筑构成的村落，较小地块可以是一栋精致工坊。

## 输入与相近条件试算

- 沿用 DATA.md 的 52 周 / 364 天输入，2,206 次贡献、210 个活跃日；SHA-256 为 `b3bf1875db6618a0ca2987a4c4028e768296ceecdb9fb23441e456f36941e46a`。
- 每个候选矩形包含的非零、已知日期满足：`最大值 - 最小值 <= max(2, 0.25 × 区域均值)`。2 和 25% 仅为出图参数，未获用户确认为产品阈值。
- 对完整矩形判断相近程度，避免仅凭邻格接近把差异很大的日期串入同一单元。候选按面积、紧凑程度、周行和星期列排序，再依次选择未占用的矩形。这是贪心示例，不声称全局最优。
- 区域均值 = 成员日总贡献 / 成员日数，决定繁荣形态；面积表达连续相近贡献的范围，高度不用于编码贡献等级。

## 结果

得到 **57 个矩形合并单元**，占用互不重叠的 210 个活跃日期格；154 个零值格保留自然地面。总贡献仍为 2,206。单元数不是最终物理房屋数量。

实际占地（列×行）包括 7×8、6×4、7×3、5×2、7×1、1×4、3×1、1×3、1×2、2×1 和 1×1。所有宽度不超过 7。

## 可重复复算

`weeks` 为 DATA.md 中 52 行的 D1–D7 数字。本代码仅作概念试算，不是扩展实现。

```python
grid = {(x,y): weeks[y][x] for x in range(7) for y in range(52)}
candidates = []
for y in range(52):
    for x in range(7):
        if grid[x,y] == 0: continue
        for width in range(1,8-x):
            for height in range(1,53-y):
                cells = [(a,b) for a in range(x,x+width) for b in range(y,y+height)]
                values = [grid[p] for p in cells]
                if not all(values): continue
                mean = sum(values) / len(values)
                if max(values)-min(values) <= max(2,mean*0.25):
                    candidates.append((x,y,width,height,cells))
candidates.sort(key=lambda p: (-p[2]*p[3], -min(p[2],p[3])/max(p[2],p[3]), p[1],p[0]))
used = set(); selected = []
for x,y,width,height,cells in candidates:
    if used.intersection(cells): continue
    used.update(cells)
    selected.append((x,y,width,height,cells))
assert len(selected) == 57
assert len(used) == 210
assert sum(grid[p] for p in used) == 2206
```
