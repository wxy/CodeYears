## 2026-11-08：同页未变化时跳过绘制

### 原因与实现

当前面板已保留完整 CityScene，包括合并地块、日期归属、模型 id、占地和路网。普通往返会重用同一场景和画布，但 `setVisible(true) → resize → zoomAt(1)` 仍请求帧，CityView.draw 会再次提交地面和可见建筑。因此本轮修复绘制入口，不再添加一份重复的地图缓存。

CityView 为每个固定数据实例记录上一次成功绘制的进度、尺寸、DPR、缩放、平移与主题；调用参数相同时，在画布清空、投影及地面/建筑绘制之前返回。新数据仍创建新实例，其首帧不会命中旧记录；绘制进度和取景发生变化则正常绘制。只增加一个短字符串，不复制图片或画布，不增加持久化字段、权限、请求、定时器或持续帧。既有身份确认、有效期、手动刷新、取消及释放策略保持。

## 原因与方案

原协调器按年 await 网络读取；渲染虽已另有Promise链，但每个年度累计快照都排队制作场景。切回原图或隐藏标签时，入口主动选择原图，面板 `deactivate()` 销毁Canvas与解码素材。项目已有按访问者隔离的年度磁盘缓存，不能称为完全没有数据缓存；磁盘命中还逐年核对身份，使重新进入看起来仍在重做整条流程。

选择最多两个公历源年并行读取，复用原年度解析/身份确认/磁盘缓存。乱序响应组装为按日期排序的不可变累计快照。任何年度失败会取消其余在途请求，不显示部分成功；已完成且校验通过的年度记录仍可按原策略留在磁盘。

渲染继续使用一个Canvas和一个城市规划，不为每年建立renderer。一个更新处理中，只保留最新待更新快照；后到数据不等待上轮制作完成才开始请求，过时快照不逐份排队。JS场景制作仍在主线程，不声称实现了多核并行渲染。

## 同页内存保留与可见性

仅在所需源年全部成功、场景更新成功且访问者已知时，当前面板保留一个完整城市实例及其数据、图片、地面缓存和取景。切回原图隐藏城市并停止帧；浏览器标签隐藏不强制切成原图，返回仍选中城市。

恢复前画布保持隐藏且工具栏贡献总数为空，发一次 `cache:no-store` 同源主页GET确认访问者。主页/访问者/年份范围一致且源年记录仍有效，才重新显示同一个Canvas及贡献总数；没有年度数据GET、新素材请求、场景重新规划或PNG重新解码。可因取景尺寸、主题等正常变化提交单帧，不等于重新制作整座城市。隐藏ResizeObserver不把保留取景改成1px。

缓存期限与磁盘年度记录共用 `yearCacheExpiresAt`：抓取时为当年则一小时且不跨本地日历日，历史抓取30天；整体画布取最早源年期限。范围改变/到期走原缓存读取，手动刷新强制取数，清除会释放画布和对应年度缓存。身份变化/未知/确认失败会销毁旧画面，不能离线免核对显示。导航、页面离开和面板销毁释放资源。未完成切出仍取消并清空部分场景，不把它记为完整内存缓存。

没有新权限、Token/Cookie读取、账户切换、后台轮询或持久化字段。仅保留当前页面一个实例，不增加多用户/多范围缓存池或淘汰框架。此体验会保留更多常驻图片/画布内存，不宣称降低内存、功耗或完整性能预算通过。真实账户及SSO可见性局限沿用原数据说明。
