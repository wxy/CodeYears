# 魔法小镇独立地图类型：集成与交付记录

日期：2026-11-11。状态：已实现并完成本机编译、受控 Chrome 直接路径与安装包结构检查；尚未合入或发布。真实登录 MV3、Edge 与硬件性能预算未验收。

## 用户目标与最终行为

扩展新增“现代城市 / 魔法小镇”选择。现代城市保留原模型；小镇独立按七日一行的 ISO 周年网格组织相近贡献，使用长屋、农场、圆形观星台、法师工坊、炼金庄园和主/附建筑组表达面积与日均强度。当前目录容量为最多八日、最长四格，合并位置随实际数据决定，不按固定四周或十三周边界切分。

小镇使用自己的庭院、格边路网、广场和生活设施，复用现有 Canvas 缩放、平移、Alpha 命中、高光及真实项目悬停。较大区域可有主建筑与附属建筑；两者都对应同一组真实成员日，不增加贡献数。居民、家畜、花树、集市、长椅、水井、路灯和传送门是装饰，不代表贡献者人数、实际项目分类或额外贡献。

用户已选择首版按强度和区域组织聚落，悬停继续查询实际项目/提交/PR/评审/Issue 摘要；本次没有增加分类批量请求或猜测项目。河谷沿路街镇、阶段聚落群与环形街区仍是设计候选，首版不引入多套运行布局。

## 切换与资源归属

- 选择新地图时复用同一份完整逐日快照；已确认的访问者在切换前联网核对，素材就绪后再检查页面作用域。未知身份、过期或作用域变化走现有读取流程。
- 新地图的图像和画面准备完毕后才交换；失败保持旧地图，取消在交换前检查并回收晚到资源。选择项和实际画面不会因中途退出错配。
- 交换完成释放上一地图的图像与视图，不同时保留两套解码资源。关闭、隐藏、返回与身份核对沿用既有面板边界；静止不新增持续动画。
- 补齐旧本地预览不传 `reservedYears` 时的 Town 进入/退出资源清理，避免回到 City 误用 Town 的图片目录或场景缓存；原 City/Terrain 路径保留。
- 45 张预烘焙运行 PNG 共 5,300,863 字节，全部长边不超过 384。方向、低 Alpha 清理和缩图在离线生成阶段完成。运行资源仅为本地扩展文件，不新增外部服务、权限、登录或持久化字段。

## 发行结构检查

在系统临时目录建立仅用于检查的项目目录：原样复制 `package-city.py`、`verify-city-package.py`，将所需项目源码、产品说明与最终构建以符号链接指向实际工作区/临时构建。两份脚本未修改其打包和校验逻辑，运行目录使 ZIP 和校验值只产生在该任务临时目录；没有覆盖仓库既有 `dist/` 或 `release/`。

```sh
python3 "$TASK_TMP/package-project/scripts/package-city.py"
python3 "$TASK_TMP/package-project/scripts/verify-city-package.py" \
  "$TASK_TMP/package-project/release/codeyears-0.1.2-city.zip" \
  --build-dir "$TASK_TMP/package-project/dist"
```

实际结果：**163 文件，28,820,116 字节**；CRC、完整清单、JS/图片引用、权限和说明文件均通过。ZIP SHA-256 为 `3eb062777f84a3c401714d0cc55f08f066bc4e2a6c15b77ca595fa30004b4adc`。这是功能分支内部检查包，版本仍为 0.1.2，未替换或发布冻结发行包。

首次检查定位到旧校验器把所有 PNG 文件名都视为 `assets/city/`，新小镇资源会报缺引用。已按小镇目录清单区分 `assets/town/`，再通过同一检查；没有忽略缺失引用。权限仍为 `activeTab`、`scripting`、`storage`，仅在相同 GitHub 范围增加本地小镇 PNG 的可访问资源路径。
