# 小镇时间拼图、年份木牌与成员日历

2026-11-12。继续分支 `codex/town-activity-settlements` / PR #81；本轮不合入或发布。用户确认累计贡献决定建设等级。本报告记录本轮增量，前一版阶段矩形/地面日期文字/日均工艺的结论不代表当前视觉。

## 决策与实现

核对首版代码，原 `mean` 已是正贡献成员合计/正贡献日期数，没有把零日摊入。用户选择新的累计口径，因此建设等级使用每栋院落自己的总贡献：1–9朴素、10–49舒适、50–199精工、200+华丽；原日均与每日数保留。该等级是视觉映射，不表示真实收入或资产，也不把累计数称为活动强度。固定阈值不随样本最大值重标定。

活动频率识别模块及λ6保持不变；跨月跨年仍可属于同一活动阶段。视觉院落可在公历年界拆开，每栋最多24个正贡献日期。不同尺寸的矩形院落按时间从前角拼接，替代为每阶段预留的大矩形。冷淡期压缩为园地与零星贡献院落，空间距离不等于天数。未知日期不补零。

年份沿用已有标定木牌素材，文字在竖直牌面内投影，支架与楼宇按深度排序；它不进入出城链接命中。去除原阶段的地面日期/活跃天数长句。没有新增PNG、地图存储字段或权限；道路沿用实景纹理。

City/Town共用悬停改为月份日历：完整年月标题、周一始七列表格、只强调实际成员日，非成员不宣称零贡献。头部显示累计数量和真实活跃日日均。卡片可进入和滚动，保留原按需明细、身份核对、缓存隔离、最多两并发及取消；不会为日历中的非成员补发请求。
