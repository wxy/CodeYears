# 主页生成的城市出口与组织广告牌

## 本机公开主页

在 macOS 的 Chrome 157.0.8103.79 中用独立、未登录的配置，通过 CDP `Extensions.loadUnpacked` 加载项目根目录的 `dist`。使用 1440 × 1000 视窗、减少动态效果和默认三年范围，分别打开下列 GitHub 个人主页，点击贡献区的「城市」，再点击「全景」和「展开」。对照资料卡的 `data-hovercard-type`、会员徽标和地图链接。同时观察进入城市后的网络请求，并用主 Canvas 的 `toDataURL()` 检查导出。

| GitHub 主页 | 此次页面输入 | 城市中的结果 |
| --- | --- | --- |
| [wxy](https://github.com/wxy) | Bio 提及 LCTT、Linux-CN，资料栏再次提及 Linux-CN。Organizations 列出 LCTT、inKerk 两个带头像的组织。 | 7,864 次公开贡献。无个人出口链接。LCTT 和 inKerk 使用真实头像，Linux-CN 使用 LI 缩写，三块牌分别出现在环路的不同侧。 |
| [sonnguyxnn](https://github.com/sonnguyxnn) | Bio 有一个标为个人的 hoangsonww，Organizations 有四个带头像的组织。 | 156 次公开贡献。第一条主路通往 hoangsonww，其余组织各占一块路边广告牌。 |

两页进入城市后均未观察到账号类型、关注关系或头像的额外请求。原有年度贡献加载正常发生，sonnguyxnn 还触发了原有的注册日查询。两张主画布均可导出。用键盘在 wxy 的 LCTT 广告牌按 Enter，可进入该组织主页，标签页里没有新增城市旅程。由 sonnguyxnn 的个人出口按 Enter 后，hoangsonww 城市出现了指回 sonnguyxnn 的返程牌。最终 wxy 展开图中可见四面空白蓝牌和三面组织广告牌。主页实际头像可在地图中显示，无法由浏览器安全导出的跨域头像在保存的主画布中用缩写代替。

## 导航与输入边界

- 在 Chrome 中加载受控 GitHub 主页。提供 2025 年全年日历，仅第二天有一次贡献，使用真实扩展入口依次按 Enter 经过 Amber、BeeCH、CedAr、Drift。大小写混合的 Bio 链接正确复用上一站的绿色返程牌。没有回链时出现独立返程牌。
- 在返程牌按 Shift+F10 选择更早的站点，Esc 焦点回到路牌。浏览器后退与前进后能恢复该历史项的返程菜单，沿菜单回到起点时不出现额外返程。原地更新 Bio 时仍存在的目的地保留键盘焦点。
- 在独立 Chrome 配置以 1440 × 1050 打开受控的本人资料卡。日历为 2023 年，每第 11 天两次贡献，合计 66。Bio 包含十个个人账号，以及本人、大小写重复、组织和未标类型的链接。点「全景」后以鼠标逐一点击八条出城牌并返程，前四个主出口和后四个分岔均到达正确账号。四座目的城市有 Bio 回链，四座使用独立返程牌。
- 该城市输入 90 个去重组织，8 个摆上外环，82 个可以从名录访问。原地把个人账号从 8 个减至 0 个、再增至 2 个，替换整张资料卡并将组织数依次改为 1、0，链接随资料更新。提前给扩展的本地及同步存储写入同名、内容不同的旧路牌数组，所有目的地均由 Bio 决定。行程结束后两个旧值均保持原样，界面中没有手动编辑、删除或同步控件。
- 这组导航共触发 17 次主页导航、36 次已有的身份确认、9 次年度查询及 17 次已有的活动查询。额外社交请求、请求失败和未处理页面异常均为 0。以上身份是受控页面提供的输入，公开主页的验证使用真实未登录会话。

## 组织名录、缩放与构建

在 320 × 300 的城市视口用指针展开组织名录并滚动 450px，列表底部位于 y=246，保留了底部工具区。地图放大 2.5 倍时，样例牌面的投影宽从 18.84px 变到 47.14px。同一跨域头像只由原主页加载一次。主画布在显示头像后仍能导出。

这些是本机测量值。用 3 年（1,096 天）及 20 年（7,305 天）输入重复 10 次更新组织，包括采样已有头像、选址与创建链接。4 个组织的耗时中位数分别为 1.3ms 和 2.7ms，48 个组织分别为 14.6ms 和 18.6ms。缩放和拖动只更新投影位置。

执行 `npm run build`（含 TypeScript 检查），在系统临时目录执行 `python3 scripts/package-city.py --output-dir <临时目录>`，再执行 `python3 scripts/verify-city-package.py <临时目录>/codeyears-0.1.3-city.zip --build-dir dist`。0.1.3 候选包的 120 个文件通过 CRC、清单引用、权限和随包说明检查。登录用户实机视觉、Edge 和商店发布未在本轮验收。
