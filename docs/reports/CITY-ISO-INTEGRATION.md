日期：2026-11-01。继续原 PR #33 / codex/city-connected-landscape，尚未合入main。共享日历a148afc、云端布局fc9e38a与源年范围7035785已组合；云端分支仅作共享提交交付，没有新增重复PR。

## 修复依据与最终行为

用户明确要求把跨元旦的整周移至上一/下一所属年。前版只平移公历季度并补到14列，未落实该要求。现在使用ISO周一至周日、周四所在年规则，每周年52/53周；日历只以UTC作无时区日期计算，不变换来源date。13/26/39周后各插.8格道路，第53周留末段，前三段不补列。混排52/53年时短年末端一列按既有边路铺装，不作为贡献地块。

选择器含义改为ISO周年。边界需要的相邻公历源年经原loader完整获取/校验，缓存仍按公历年、访问者和主页隔离；全部成功后按真实日期窗口筛选，城市、合计、明细共用输入。周年合计可能不同于GitHub公历年度，不以不同范围比较解析正确性。可用入口不足、当前未结束有提示，不补日期或零值；必要相邻源年失败/取消不生成部分城市。

年份附近浅白区域来自独立浅石托盘及其与街区/环路间的透底空隙。删除浅色外框，改为从街区侧缘接至环路内缘的连续不透明绿带；年份仍沿两侧方向作绿篱雕塑，进入既有地面缓存。年度横路不被绿带覆盖。建筑自己的庭院/人行铺装不属于本问题。
