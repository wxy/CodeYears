# 文件夹式页签、双语与画布状态浮层

日期：2026-11-02。基线 main `adb0c6c`，分支 `codex/city-folder-tabs-i18n`。本报告只记录本轮直接范围，未完成门槛继续保留。

## 实现

- 选中页签前置，下沿与贡献区外框相连；未选中页签使用后置浅色表面。原 h2 下距、原日历上边线仅在挂载期间调整，卸载恢复原值。原统计与设置节点继续复用，不重建 GitHub 菜单。
- 英文/简体中文词库统一用于扩展面板、图例、无障碍名称、状态、已知错误和工具栏弹窗；入口只打包六条标题/失败文案。未知底层错误保留原文，不修改解析器/缓存错误合同。
- 默认跟随浏览器；“更多”可手动选择，独立键 `codeyears:ui:language` 保存本机偏好，同浏览器扩展界面响应设置变化。切换语言保留当前画布、年份、数据和取景。GitHub 自有统计/设置不由扩展翻译。
- MV3 增加原生 `default_locale` 及两份 `_locales` 文件，描述/工具栏标题通过清单占位符本地化。没有扩大权限或可公开访问资源范围。
- 读取/取消/重试/警告/错误在 `.scene-wrap` 内绝对定位；移除独立 preparing 文案，顶部合计预留宽度且不显示加载状态。常规完成隐藏浮层，无状态行移除导致的页面位移。

## 验证方法与结果

环境：本机 macOS、用户原 Chrome profile 的独立窗口；真实 MV3 从项目 `dist` 重载。受控页面、合成日期、模拟存储/请求及 ZIP 均放系统任务临时目录，只有本报告长期保留。

2. 在临时根目录放打包脚本，链接本次 dist、清单/词库与通知文件；运行 `python3 scripts/package-city.py` 和 `python3 scripts/verify-city-package.py release/codeyears-0.1.0-city.zip`。76文件；CRC、文件清单、引用、版本、既有权限、两语键/替换参数和清单文案引用检查通过。最终包112,522,585 bytes，SHA-256 `a963b56e810eaebb6579b9de1019ec037923b0044ab5e652f5ebb596c2de92a8`；不提交ZIP。
3. 受控 E2E：Vite 临时入口仅将 GitHub origin 与历史加载/清缓存适配到测试页；真实面板、入口和编译后的 City 渲染器不换。生成所请求公历年内逐日日期至当前日，贡献循环 `[0,1,2,3,5,10,20,50]`，源年间隔150ms，慢模式3s，失败模式HTTP403；模拟UI偏好使用测试源localStorage。该证据不代表真实身份/缓存协议验收。
4. 受控正常/慢/HTTP失败/取消/重试路径通过。加载与完成后画布顶部均171.5px，高度340px，scrollY均0；HTTP错误同坐标，状态定位absolute。无警告时完成隐藏浮层，错误与取消保持重试。
5. 受控语言切换：同一画布DOM标识保留，历史加载调用数保持1，年份不变；标题、合计、帮助、图例、状态/错误和ARIA同步。展开中切换语言后Esc返回通过；刷新后手动偏好保留。336px宽区域的英文控件与菜单未越过页签边界；浅色、暗色表面和原图入口可用。工具栏弹窗在受控非GitHub页显示英文指引、日历未就绪显示中文指引。

打包脚本和核验方法可在任一干净检出中复现：`npm ci && npm run package:city && python3 scripts/verify-city-package.py release/codeyears-0.1.0-city.zip`。发布包输出属于当次验证产物，验收后清理；用户当前加载的项目dist保留。

真实主路径验收后，最终追加入口模块加载失败时保留内容高度的CSS：受控强制缺少content.js，错误浮层absolute、内容高341px（含边线），返回原图成功；同时让小视口预留高度与300px画布一致。最终构建/打包再次通过，这两条高度CSS未再次要求真实扩展重载。
