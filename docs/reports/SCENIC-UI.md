# 融合街区、连续山脉与整体生长

> 前版报告：本报告中“树木仅作景观”和四种年份主色已被后续用户反馈修正；当前地块植被表示贡献强度，公园树木仍仅作景观，见 [城市图样报告](CITY-TYPOLOGIES.md)。

日期：2026-10-31。源码 `2190da5fd8562ad761d5de8597621284ac2cb6b6`，分支 `codex/year-landscapes`，更新原 PR #15，未合入。

## 决策与实现

用户最新反馈优先改善 UI：City 可以年份作街区，但不能像独立年度地块；用道路、树木、绿地和不同建筑风格融合。Terrain 必须连续，不按年份生成山群。画布透明、随 GitHub 明暗；先有完整平地，再整体长出楼宇或山脉，低矮部分先停止；弱化矩形边界。

当前已实现：

- City 共享街路、中央公园/小湖和树木；年份参考四种周期色系、三类立面，增加高度分区、屋顶和退台。没有每年底板或场内年份牌。年份色系不是二十种唯一颜色，宏观组也可能跨年；不将其描述为严格年度统计地块。
- 贡献日均强度与中心城区分区共同影响高度；树木、公园和道路仅作景观，不是贡献单位。原始日期、数量和统计仍保留，未修改请求/缓存/权限。
- Terrain 以真实数量的对数强度经过局部平滑、相对起伏、少量褶皱调制和边缘收敛塑形；不另造独立年度山群。绿色低地、灰绿高地、岩石、雪顶按当前高度混合，未到高处时不提前显示雪。
- renderer 的 alpha 背景完全透明；Shadow DOM 使用 GitHub 的颜色变量，主题变化调整灯光并请求单帧。City 地面边缘渐隐，Terrain 不另铺矩形底板。预览提供系统/浅色/深色页面外观；这不等于 Signature / Natural 主题已完成。
- 全部几何从动画起点参与，不再按日期逐格出现。沿用时间轴作为归一化生长时钟；界面改为“景观生长 · X%”，不能解读为已显示到某个真实日期。City 按共同抬升高度缩放，矮楼先达终态；Terrain 从平地整体隆起。切换视图和缩放保留进度。
- 近/中/远景仍按屏幕尺寸选择 1/2/4 步长，最多聚合 1/4/16 个真实日期。City 使用实例化建筑/树木、一个 1024 阴影；Terrain 单网格、不启用阴影通道。纹理与遮罩均由本地代码生成，无远程素材或后处理框架。

这是当前视觉解释，**用户尚未确认接受画面，也不声称照片级写实**。

## 构建与本地实际画面

环境：本机 macOS 26.6.2、Chrome 真实 WebGL，Node v26.7.0、npm 11.19.0；既有依赖锁文件不变。没有把浏览器自动化调度间隔当作 FPS。

实际观察：

- 起点 level=0，City 已有 5933 个建筑部件/树木实例参与，ground 为完整平地；alpha=true、pending=0，不是随着日期增加实例数。
- 播放至 146/7305 的时钟位置时，实例数仍为 5933，其中 5 个低矮部件已达目标、5928 个仍继续生长，level≈1.352。该数包含屋顶/树木部件，不能称为楼宇数量。
- 暂停切 Terrain 并缩远后，进度保持 5514/7305，pending=0；地形连续，477 组、2385 顶点，无年份切块。
- 放大 7 次到近景、跳过并切明暗后：7305/7305 completed，Terrain 36525 顶点，alpha=true；frames=194/pending=0，间隔后仍为 194。
- 重播并立即暂停、切 City：进度 0，level=0，近景全部 17970 个部件参与，pending=0；已有数据无需重取。
- 关闭后 Canvas=0，frames=202/pending=0，间隔后保持不变。第一次监听放在父容器，Canvas 移除后的异步 contextlost 无法沿原父链观察；改为直接监听实际 Canvas，补充关闭检查取得 Canvas=0、contextlost=1、frames=3/pending=0，后续不变。
- 直接页错误输出为空，捕获的 THREE 错误/告警为空。观察到上下文丢失事件不等于精确显存测量；未宣称显存已归零。

复现顺序：使用临时 Vite 配置加载上述两个正式模块；增加上述只读 DOM 观测和 RAF/context 包装。初始暂停 → 继续/暂停 → Terrain → 缩远 3 次 → 放大 7 次 → 跳过/切明暗 → 重播并暂停 → City → 关闭；核对各次进度、源合计、pending、Canvas 和 contextlost。最后的边缘渐变只影响纹理透明度，生命周期/播放逻辑未变，按影响范围仅追加构建与画面复核。
