# 大型方向牌与整段出城道路访问

日期：2026-11-11。状态：实现、编译与直接端到端路径通过，本机 `dist/` 已重建；继续更新 PR #79，尚未合入或发布。美术尺寸与整体观感仍待用户本地验收。

## 本轮实现

- 现代城市使用金属指示板，小镇使用木制告示板，直接写出“@账号 的城市”；没有目的地时显示“？”。长账号在牌内分行，卡片中仍保留完整名称。
- 牌面、文字、底座、立柱作为 Canvas 世界对象绘制，沿道路切向与竖直高度投影，和建筑共用取景变换及地面深度顺序。移除原先 DOM SVG 的 20–46px 尺寸钳制和仅左右翻转的方向处理；缩放不改变几何或布局。
- 接近视线方向的斜分岔牌在地面轻转 30° 露出正面；额外出口向外伸展，使同侧两块大牌分开。返程牌退到对侧草地，和小镇窄路旁的出口牌保持间距。没有加宽路面或叠加另一套路面文字。
- 点击牌面打开原有目的地/设置卡片；点击已连接的整段出城道路可直接进入目标 Profile，并打开相同地图。点击本人未知道路可添加，他人未知道路只显示只读说明。
- 从路面开始移动超过 4 CSS 像素后进入平移，结束时取消该次点击；禁用链接原生拖动。地图缩放工具置于道路命中层上方。
- 本人编辑、保存前实时身份核对、四至八槽上限及访问者多跳返程规则沿用。返程不占槽位，不修改对方设置；没有新增关系取数、公开共享、Token、权限或后端。

方案选择与候选范围见[任务记录](../tasks/CITY-DIRECTION-BOARDS.md)。牌面尺寸是本轮实现选择，不代表用户已接受为最终美术规范。

## 环境、前置条件与输入

macOS，本机 Google Chrome 157.0.8103.39，Node v26.7.0，Playwright 1.62.1；1280×1000 视口，headless，独立系统临时 Chrome 资料。使用实际 MV3 构建、真实 `chrome.storage.local` 和公开贡献页面；未读取个人浏览器配置或凭证。

两类证据分开：

1. **真实匿名路径**：不替换 GitHub 页面，访问 wxy、torvalds、octocat。实际 wxy 三年摘要为 7,727 contributions。预置本机路线 `wxy=[torvalds,null,null,null]`、`torvalds=[octocat,null,null,null]`、`octocat=[jashkenas,null,null,null]`。这些是测试输入，不是对账号真实关系的断言。
2. **受控本人身份**：只在完整 Profile HTML 的 `meta[name=user-login]` 中设置 wxy，保持年度贡献响应、扩展存储和渲染器真实；保存前单独把身份响应改为 torvalds 验证拒绝写入。这不等于真实登录、SSO 或私有权限验收。

八路首轮输入：`torvalds`、`octocat`、`antirez`、`jashkenas`、`sindresorhus`、`yyx990803`、`tj`、`abcdefghijklmnopqrstuvwxyzabcdefghijklm`。最后定向检查将 octocat 移至第 5 槽，前三个其余名称顺次前移，以便通过真实分岔路访问已有测试城市；torvalds 的第 1 槽设为 wxy。最后一个 39 字符账号仅用于长文字排版，不访问、不声称该账号存在。

## 失败证据与修正

- 初次斜路试排出现小镇某块牌面宽度为 0；近侧视的牌面轻转后两种地图所有八块牌宽度大于 10 CSS 像素（本次视口和 50% 缩放），均能实际点击。此数值是实测结果，不是运行时的屏幕尺寸下限。
- 相邻额外出口大牌部分覆盖城市名；拉开额外道路末端与路肩位置后，实际查看最终两种地图画面，名称分开显示。
- 八路城市初始取景下，一块大牌拦截 Fit view；将缩放工具放到道路命中层之上后，最终点击通过。
- 小镇窄路的返程牌拦截第一个出口牌；返程牌退到对侧草地后，最终九块牌逐个点击通过。
- 测试曾等待中文的画布进度标签，但切换地图后该标签会被既有本地化文案替换。修正测试等待条件为读取结束、画布可见及既有 650ms 填入完成；没有为此改产品行为，也没有通过强制点击绕过遮挡。

## 复现步骤

```sh
TASK_TMP=$(mktemp -d -t codeyears-direction-boards)
npm run build -- --outDir "$TASK_TMP/build"
# 用下述独立 Chrome 和输入复现；用户要求的本机重载目录：
npm run build
```

Playwright 指向 `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`，设置 `ignoreDefaultArgs: ['--disable-extensions']`、`args: ['--enable-unsafe-extension-debugging','--disable-background-networking']`。通过 browser 级 CDP session 调用 `Extensions.loadUnpacked({path: buildPath})`；打开返回 id 的 `options.html`，在其扩展上下文中执行 `chrome.storage.local.clear()` 与上述输入的 `set()`，语言键为 `codeyears:ui:language`。

1. 匿名访问 `https://github.com/wxy#codeyears-city`，等贡献摘要出现、Apply 恢复可用、画布可见并完成短填入。点击 Fit view 到 50%。分别在城市/小镇查看四块牌，点击已知和未知牌，核对匿名没有编辑操作。
2. 记录 `[data-road-slot="0"]` 的 `getBoundingClientRect()`；在场景中心滚轮 `deltaY=-Math.log(2)/.0015`，等取景更新，核对显示 100%，牌面宽高比约 2，取整容差 0.004。回 50% 后拖动已连接路面，检查位移、URL 和 `sessionStorage['codeyears:journey:arrival']` 没有产生旅程。
3. 点击 `.city-road-surface` 中已连接的路面进入 torvalds，再去 octocat。检查 `.city-return-post` 的 B/A 列表，刷新、切小镇，直接回 A，比较三个原道路数组。
4. 按上述受控身份方法打开 wxy，添加一个空槽，用 S、Enter 验证输入和实际保存；下一次保存只改变实时身份响应，确认错误与原数组。填满四槽，检查第五块问号牌出现。
5. 设置最终八槽，从 torvalds 已连接路面到 wxy，分别切两种地图。50% 逐个实际点击八个 `[data-road-slot]` 和独立返程牌，核对标题；缩放到 100% 后点 Fit view，确认没有命中遮挡。切换中文检查长名分行。拖动额外分岔路只平移，随后点击第 5 条分岔路去 octocat，确认小镇与两段返程，回 wxy 后比较八槽数组。

最终本机 `dist/` 与最后端到端临时构建的 SHA-256 相同：`content.js` 为 `6b1ab9dedf0e2e21d87267f61740926cce00224008432d9750acb81082a8af7c`，`landscape.js` 为 `7943bc971cb23864477170321b47e1cb61159d94926bbdfcb688fd5cf95e78cc`。
