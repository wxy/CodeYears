## 投影、落点与美术限制

建筑原生占地为1×1、2×1、1×2和少量2×2，不增加占地矩阵或巨大奇观。图书馆靠锯齿顶与阅读窗，学校靠双山墙和内院，中心靠围合翼楼和玻璃门厅，邮局靠投递口表现用途；诊所没有标识，识别度需审查。公共建筑只描述外观，不解释贡献的项目类型；没有真实机构logo。

`calibration.json`记录各栋的源图crop、可见W/D主边、地面L/F/R与高度参考。`calibrate`将量测轴归一为±0.5，竖边变换后仍竖直；按地面包络居中并等比缩放，楼身不独立拉高。以下为实际计算，不是所有局部线条的几何证明。源图为AI绘制，装饰、栏杆、局部檐口仍可能偏离主边；隐藏背角为推断，支持包络包含入口台阶和花池，选点误差约±5源像素。

## 验证结果

Linux Node v24.19.0 / npm11.9.0 / Chromium154.0.8037.57，headless软件Canvas。本轮不是用户GitHub登录会话，也不是Mac GPU、真实硬件性能预算、内存/显存/功耗或本机最终视觉通过。

- `npm ci`、`npm run check`、`npx tsc --noEmit -p probes/city-models-civic/tsconfig.json`通过。
- `npm run build -- --outDir /tmp/codeyears-civic/dist`通过，正式landscape95.76kB/gzip29.50kB；该构建不包含候选正式映射。
- 独立预览Vite临时构建通过；提交的离线烘焙脚本实际运行通过，得到5张新图和2项旧引用。
- 实际打开1/3/20年，候选隔离与完整混排各覆盖全景/150%/最大倍率；七项每组各3处，所有非空候选实际进入正式Canvas；浏览器pageerror为0。
- 逐款最大倍率聚焦检查；按地面深度排序，前景楼宇正常遮住后景，隔离模式便于查看完整低层。完整混排中候选可能被高层遮住，这是现有深度绘制的实际结果。
- 关闭按钮后持有原Canvas引用，宽高归零、DOM移除；重新打开可绘制。没有加入RAF或定时器，只有交互/尺寸改变触发绘制。
