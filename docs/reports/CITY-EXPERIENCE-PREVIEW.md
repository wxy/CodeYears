本机 macOS / Apple M1；沿用本轮主线环境 Chrome 156.0.8078.76。Node v26.7.0、npm 11.19.0、锁定 Three.js 0.186.1 / TypeScript 7.0.2 / Vite 8.3.5。实际生成城市的扩展从项目 `dist/` 加载，用户已手动重新加载并刷新 GitHub；使用现有登录会话，无 Token、Cookie 导出或额外登录。

manifest 权限仍为 `activeTab`、`scripting`、`storage`。仅新增 GitHub 范围的本地 `city-preview.js` 可访问声明；没有 host / Cookie 权限、后台服务、自动注入或远程代码。实际 Chrome 加载成功不等于完整权限或 Edge 验收通过。

在真实 `https://github.com/wxy/`，通过浏览器工具栏实际扩展弹窗打开面板；主页与已登录访问者均识别为 wxy。选择年份生成，不通过本地替身替代以下结果：

| 路径 | 实际观察 |
| --- | --- |
| 尚未生成 | 面板可见，原生贡献日历保留，Canvas 数为 0 |
| 2024 网络读取 | 366 天、逐日合计与页面年度标题一致；该公开样本为 440；创建 1 个 City Canvas，日期自然到 2024-12-31 |
| 2024 完整缓存重新生成 | 状态明确为本地缓存、抓取时间不变；动画重新从历史起点推进，而非直接结束 |
| 暂停/继续/跳过 | 缓存播放在 2024-02-06（37/366）暂停，间隔超过 1 秒仍为 37；继续后跳过至 366/366，完成时暂停按钮禁用 |
| 重播 | 立即显示历史起点 0/366，并重新生长 |

可复现操作：重新构建并在扩展管理页重载项目 `dist/` → 刷新上述主页 → 扩展图标 → 打开 CodeYears → 选择 2024 → 生成 → 再生成验证来源为缓存 → 暂停/继续/跳过/重播 → 关闭城市。选择当年重复网络/缓存路径。数量与截止日期会随访问者及实际运行时间改变，不把本报告样本作为固定断言。

## 受控 UI 失败与缓存路径

本轮在系统临时目录构建完整内容脚本，只把当前 URL 边界适配为 GitHub 主页；本地页面提供年份/日历标记、访问者 Alice，Chrome 存储由 Map 替代，年度 fetch 返回真实匿名公开 2024 HTML，身份 fetch 返回带 Alice 标记的完整主页 HTML。实际解析、年度加载器、缓存、Shadow DOM 和 City 渲染器均运行；这不是实际 MV3 或真实登录隔离证据。

输入可重新取得：无 Cookie / Token 请求 `https://github.com/wxy?action=show&controller=profiles&from=2024-01-01&tab=contributions&to=2024-12-31&user_id=wxy`，设置 `Accept: text/html` 与 `X-Requested-With: XMLHttpRequest`，和年度请求器一致。替身 transport 记录年度/身份请求及存储项数；分别启用 5 秒年度延迟和 HTTP 503，按下列 UI 路径重现。输入响应、替身页面、构建、日志均不长期保存。

| 路径 | 实际观察 |
| --- | --- |
| 初始未激活 | 年度/身份请求、存储项、Canvas 均为 0 |
| 网络 → 暂停/继续/跳过 | 得到 366 天/440，单个 Canvas；暂停进度不变，跳过到完整 |
| 缓存重播/重复生成 | 观察到 10/366、6/366 的重新生长进度；年度网络请求仍为 1，Canvas 不累积 |
| 延迟中取消 | 显示“请求已取消，本次不显示结果。”；Canvas 和存储项均为 0 |
| HTTP 503 | 明确显示 HTTP 503 失败；Canvas 和存储项均为 0，不把失败当作空年成功 |
| 恢复后强制刷新 | 新增年度网络请求，仍只有对应作用域的 1 项缓存 |
| 清除 | 明确成功反馈，Canvas 归零；之后重新网络获取可用 |
| 仅查看每日数据 | 366 条日期/数量，Canvas 为 0 |
| 再生成/关闭 | 缓存可生成完整城市；关闭城市后 Canvas 为 0 |

使用直接 UI 端到端检查覆盖新增流程，没有在实现后补写单元测试。
