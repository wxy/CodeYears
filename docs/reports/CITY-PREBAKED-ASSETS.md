# 城市素材预烘焙

日期：2026-11-04。基线main `e6416c5`；分支`codex/city-prebaked-assets`。用户授权先做建筑、树林、地表样本，确认体积和画质后全量优化，经验证后提交PR；保留原图，截图等界面定稿。本轮不自动合入、不发布新版。

## 实现与边界

将基线`city-assets.ts`的源图加载与烘焙保留到`city-source-assets.ts`，复用原低alpha处理、768px中间缩图、投影/地表标定和最长384px建筑缓存；外围/自然背景沿用原512px缓存及镜像规则。通过真实Chrome Canvas生成PNG，保存全部空间元数据。正式加载器只解码小图，不重新缩放或再次处理透明度；程序铺装与灯具仍用原实现。

59张`public/assets/city/`大图与全部设计/标定文件未修改。57张正式运行PNG放入`public/assets/city-runtime/`，对应54个目录单元（含两种幼树）及3个外围/背景id；目录表为`city-baked-catalog.json`。未引用的`house.png`、`hall.png`、`stadium.png`和`outskirts-meadow.png`合计8,260,821 bytes，保留在源目录，发行时不复制。

构建关闭Vite整目录public复制，只复制manifest、双语目录、图标和运行PNG；运行图仍放在`dist/assets/city/`。扩展权限、WAR范围、资源URL前缀、默认150%、缩放上限、数据/身份/缓存与建筑选择不变。生成工具与复现步骤见[说明](../../scripts/city-assets/README.md)。没有新增运行依赖或引入WebP/有损编码。
