# 城市轮廓与长期空档分城候选报告

## 2026-11-06 本机修正（当前版本）

用户本机评审指出：路口/拐角有无依据的局部退让，相邻年份原有共用道路被画成两条独立道路。本轮继续更新 PR #63，不合入、不发布；正式扩展入口仍未启用候选。

原因是旧候选按附近两周的活跃星期行裁掉零值格，并逐列外扩包络；每个年度子区又单独描出整圈道路。三年密集输入在原本应共用 z=7.8 的年界，实际描出 z=7.6 和8两条边。

当前修正：

- 取消按局部星期分布的裁切及逐列平滑。长期空档与首尾时间范围仍用于分段，范围按整周取边，每个年度子区保留完整七天深度。周末、短暂稀疏及路口邻接不单独制造凹口。52/53周年混排的既有末端道路余量保留。
- 年度主路沿原布局 z−0.8 / z+7.8 中心线规划；同轴重叠或相接的道路区间先合并，再调用既有车道 painter。三年完整样本只有4条横向年度主路，z=7.8、16.4 各一条；季度轴继续贯通。五年河带保持间隔，桥接仍是原型平桥。
- 修复本地审查的P2：候选只替换底面/路网，保留建筑庭院、步道和所有仍在场景中的 flat 贴图命令；不再为被替换的外围景观要求图片。修正后一年稀疏样本保留136个 flat 地块，实际136次素材绘制；旧候选保留107个却0次绘制的证据属于上一版本。
- 日期/count、全部非零建筑的素材/坐标/占地/成员索引不变。`complete=false` 不收缩、不识别空闲；全零样本没有伪造城市。60/90/120天仍为实验阈值。

本机 Chrome156.0.8078.80、Apple M1、1600×1000、DPR1.5，使用正式 Vite 模块和运行PNG。三年稀疏/密集/中断60天/跨年90天，二十年密集/跨年120天，一年全零，三年未完成→补齐共8组直接路径通过数量守恒、非零映射无遗漏/重复和原建筑映射一致。稀疏完整样本不再按星期剔除零值；中断/跨年样本省略155个零值日期、保留孤立贡献。补齐保留倍率6；静止两次draw计数22/22，关闭DOM画布0，重开成功。截图实际检查了稀疏、中断及跨年轮廓、共用道路和恢复的平地。

`npm run check`、正式临时目录构建、预览独立类型检查和 `git diff --check` 通过。一次性运行/绘制观测脚本、截图、JSON和构建放系统临时目录，报告后清理；用户仍在使用的忽略目录预览服务继续保留，不进Git。没有新增实现后单元测试。完整美术接受、正式MV3候选接入、Edge、GPU耗时/功耗/内存仍未验收。

## 设计假设（未确认）

时间连续性按排序后的真实日历日期判断，不能从二维相邻推断连续活动。提供 60/90/120 天三个零值连续段阈值用于比较；两三个月没有被写成产品决策。日期中断会结束当前已知零值段，缺失/未加载/未来没有生成零值。

每个已知连续时间段保留首尾真实贡献前后七天的已提供日期；年度边缘按附近两周非零贡献的星期行上下留一行退让，再给地面包络一格余量。普通周末不会切断时间段。地面沿相邻列取外包络并用圆角描边柔化，不强迫圆形，也没有任意紧凑重排。上述留量、外扩和边缘处理仍需视觉评审。

本轮优先证明“时间判定 + 原坐标保真 + 一致地面边界”，没有将简化候选道路定为新的正式 2/4/8 车道规范。

## 实际实现

- `src/renderers/city-organic-layout.ts` 从原 `planCityScene` 取得原始 ISO 年度布局与建筑映射，只筛选零值地块和装饰。所有非零地块（包括含零成员的奇观）保留原素材、因子、坐标、尺寸、indices 和 count；`weekly` 仍保留完整输入映射。
- 连续零值段记录起止、实际日数及原始索引。首尾退让与长空档分别处理；预览列出省略的零值日期，原始输入、总量、非零日期不变。省略指取消该零值地块的独立显示，地面包络与道路留量可覆盖附近零值格，不声称每个视觉像素都对应一个贡献日期。
- 每个时间段在每个 ISO 年生成列包络。年度地面与外围道路共用同一条轮廓；季度通道限制在本轮廓内。旧矩形路床、出城路、信号灯、静态车辆和旧边缘装饰不进入候选地面，避免道路跨越剔除区。
- 相邻年度只有属于同一时间段且两岸季度轴都存在时才连通；五年带只在两岸范围交集内绘制河岸，桥接随保留的季度通道调整。桥采用简化平桥，不复用旧完整矩形路网的桥头/车辆。没有协作道路、行人/车辆动画或城市游戏。
- `createCityView` 仅增加 City 局部的可选地面 painter 参数，候选同时复用原远/近缓存和建筑绘制。没有改 `LandscapeView` 等共享接口。默认调用沿用原绘制命令；候选源码由独立预览引用，没有接入正式扩展入口。
- `complete=false` 一律保留原矩形预留场地与已提供贡献，不收缩、不识别空档。补齐按钮演示同一预留范围从不完整到完整的重新规划，保留取景。正式渐进入口尚未接入候选；完整性标志应由本地集成的已校验历史状态提供，不能仅凭“请求停止”推定完整。
- 全零完整样本仅绘制原有自然背景，无候选道路、年度地面或伪造建筑。图片全部复用现有运行 PNG，没有生成素材。

## 合成输入规则

索引 i 从所选 ISO 窗口第一天开始，UTC 日历按天加一天，保留 YYYY-MM-DD，不改变用户数据时区。范围为最后一年2025：1年=2024-12-30至2025-12-28（364天），3年=2023-01-02至2025-12-28（1092天），20年=2006-01-02至2025-12-28（7301天）。不是公历7305天旧样本。

- 稀疏：仅周二至四且 i%3=0，count=1+i%23，其余为0。
- 密集：每日 count=6+(i×17%65)。
- 中断：工作日 count=3+i%31，周末0。自末年ISO起点后70天开始150天置0，并在中点放入真实 count=1。
- 跨年：同样工作日数量，从末年ISO起点前50天起150天置0，不插入中点贡献。邻接周末可能延长实际连续零值日数，以扫描结果为准。
- 全零：全部 count=0。
- 未完成：采用稀疏规则但缺少2025-03-01至03-31，以及2025-09-01之后。模拟快照截止2025-08-31；“未来”是该历史回放快照的未来，不是工作日期2026-11-05的未来。预留年份独立保留，complete=false。补齐后为相同稀疏规则的完整窗口。

所有合成输入均在可复用预览运行时生成，没有把生成数据或一次性验证脚本提交到 Git。

## 候选取舍与本地未验收

原坐标方案让用户仍能追溯ISO周/年份，非零建筑完全可对照，代价是跨年时间中断投影到不同行，多个聚落不一定空间上相距很远；本轮没有为视觉紧凑另行重排。60天对孤立贡献更敏感，90/120天保留更大连续空场地。没有据此选定最终阈值。

本地仍需评审轮廓与留量、孤立贡献的视觉权重、道路宽度/标线/桥头美术、年份标识和边缘零值解释方式。候选桥与路网仅为原型一致性，未完整恢复正式8车道外环细节。候选构建仍会先生成原场景的地面命令再替换 painter，没有宣称CPU/内存优化。

正式扩展渐进加载、取消/失败/身份/缓存路径、真实GitHub会话、真实MV3、后台切换、Edge、用户GPU/高DPI/功耗/20年内存与帧耗时预算尚未验收。未改这些模块，不从独立预览推导通过。完整性判定的正式入口接线如需范围外接口变化，应由本地集成负责。本轮没有合入或发布。
