# 建筑悬停工作片段摘要

日期：2026-11-08，Asia/Shanghai。基线 main `7fe73384ce9bfb391b3c5913aae15b169bc4b6f2`，分支 `codex/building-hover-summary`。用户确认采用简洁浮层，呈现时间规律、相关项目和大致活动内容，不显示来源和状态栏目；完成后接入本机 dist，由用户真实 GitHub 数据验收。本报告区分受控浏览器、真实匿名 HTML 及尚未完成的登录验收。

## 实现

- CityView 逆绘制顺序命中实际显示的建筑，使用相同取景投影；透明像素穿透，前景设施遮挡后面的建筑。首次遇到素材时读取 alpha 并生成一位掩码，通过 WeakMap 让同一解码素材跨实例复用；后续移动只查掩码。没有新增图片或画布副本，也不请求城市重绘。
- 地图返回当前实例的成员 indices，协调器立即映射到该实例同一批次的原始日期；只用非零成员日。正在读取/替换场景时不启动悬停，重建清除卡片和请求，避免旧索引配新数据。
- 停留300ms后出现独立DOM浮层。先呈现本地可计算的周次/星期及活动程度概括，再按需补充项目。最近两周使用本周/上周；历史保留ISO年份和周次。仅相同星期模式且周次连续时写“每周”，其余按周归纳，不展开具体日期清单。
- 按成员日请求同源 `tab=overview&from=日期&to=日期` 活动区域；复用已有 HTML 传输及访问者确认。解析单日标题、仓库链接、提交汇总、打开PR、评审及Issue条目，不访问仓库文件、PR正文、提交说明或其他日期，不跟随活动分页。
- 浮层最多一条重点项目的类型摘要及一行其他项目，仓库名用textContent写入。活动程度为解释性分档：可见提交汇总至少20，或打开PR/被评审PR链接至少3时写“贡献较集中”；否则跨多个成员日有活动写“持续参与”，其余“有一些贡献”。项目先按出现日期数，再按可见提交及条目量排列，只表示取得的活动，不展示数值排名、比例、工时、完整统计或完成度。工作内容采用提交代码、发起PR、参与评审、提出Issue这些可观察类型，没有自动编造工作成果或调用外部AI。
- 新请求前后确认访问者及当前页面作用域；最多两个日期并发，单个工作链失败后停止该链，取消不变成空成功。成功日期的复用有效期五分钟，下一次悬停淘汰过期条目；缓存仅在面板内存，按访问者/主页隔离。重建/刷新/清除/销毁清缓存，原图/后台往返先隐藏卡片并取消在途请求，面板核对身份通过后才可再次使用。身份变化或无法确认会释放旧城市与详情。
- 429、错日期、结构变化等失败只保留本地时间及大致活动概括，不写回贡献数量，不显示来源/状态/加载文字。浮层不进入画布右键保存的图片。中英文跟随既有语言设置，布局/取景/图片和地图分档未变。

## 环境、输入与复现

Apple M1、macOS arm64、Node v26.7.0、Chrome 157.0.8103.38。复用根工作区同一锁文件安装的依赖，未改依赖、锁文件、manifest或权限。正式脚本执行：

```sh
npm run check
task_tmp=$(mktemp -d "${TMPDIR:-/tmp}/codeyears-building-hover.XXXXXX")
npm run build -- --outDir "$task_tmp/package/dist"
git diff --check
```

独立临时Chrome资料目录，通过CDP `connectOverCDP(...,{noDefaults:true})` 接入，保留真实标签可见性。受控页面为 `https://github.com/wxy`，提供2024/2025/2026年度入口、贡献表格和合成viewer-a。正式entry/content/landscape及实际PNG均运行，只有HTTP页面响应及Chrome runtime/storage在此上下文替换；没有读取用户现有浏览器资料、真实缓存或登录凭证。

普通输入：窗口各源年逐日生成，只有2025-05-02/05-09、2025-06-03/06-04、2026-10-30/11-06和2026-11-04的数量为4，其余0；当年截止采用正式请求to。它生成跨周周五、同周周二/三、上周/本周周五和单日四个目标，基于正常合并而非替换renderer。浏览器测试日期固定2026-11-08，定时器/RAF仍运行。合成活动页面单日h3、Created 24 commits in 1 repository的提交链接（since当天、until次日）、一个打开的PR、另一个仓库的评审和第三仓库的Issue，均以正式解析器读取。活动汇总与原始数量故意独立，不从详情改写每日数量。

命中坐标先用临时指针探针在DOM内扫描，仅定位实际pick返回建筑的位置；事件显式composed跨越Shadow DOM，然后用真实鼠标移动到候选点完成悬停。最初坐标探针遗漏composed导致观测到旧按钮坐标，已修正；旧失败不算产品通过。复跑为每次创建新资料目录，避免读取前次DevToolsActivePort。临时包装Canvas的drawImage/clearRect/fillRect，统计主画布操作；不是帧率或GPU测量。

## 真实匿名页面字段补验

使用一次无Cookie/Authorization的正常TLS curl GET，读取 `https://github.com/wxy?tab=overview&from=2026-11-04&to=2026-11-04`，存入本轮系统临时目录。该日期的活动请求在受控浏览器中返回这份原始HTML，由同一生产请求/解析/浮层链消费，取得仓库及提交/PR/评审摘要。未在报告保存仓库列表、响应正文、真实数量或页面附件。

这是“真实匿名响应 + 受控传输/身份壳”的字段证据，不是用户现有已登录浏览器或私有贡献验收。Issue仅由合成响应验证；没有承诺其所有真实页面样式可解析。HTML是观察结构，仍可能因GitHub格式或语言变化而失效；失败不影响城市原始数量。
