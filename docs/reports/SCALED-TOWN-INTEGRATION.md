# 魔法小镇：共同尺度与独立围院接入

日期：2026-11-11。基线：PR [#78](https://github.com/wxy/CodeYears/pull/78) 的 `2103aee`，独立临时工作树。用户在农舍、畜舍、门窗、成人尺度及一栋一院原型之后授权继续接入。本轮更新同一 PR，不合入或发布；没有包含并行的现代城市手动道路与路牌改动。

## 实现与美术边界

- 正式面板继续提供现代城市与魔法小镇。小镇使用七列工作日、周为行的 ISO 周年网格；同强度档、相邻且已知的正贡献日期可合为矩形，最多16日、每边4格。不按固定4周/13周切块，未知日期不补零，注册里程碑独立保留。
- 所有小镇实例保持 `factor=1`。成人参考高0.8、普通门1.0、墙0.32/柱0.4；源图先按已量门或可见成人统一尺度，地面包络随之确定。日期格距改为3.4，选择能容纳真实院落的形态，没有为塞进旧格子而再次缩小建筑或人物。
- 9类建筑、12个方向包括农舍、长屋、独立畜舍、圆形观星台、圆形法师工坊、温室、炼金庄园、行会与学院。低强度合并区可组合长屋/农舍与独立畜舍；高强度较大区域按占地选择行会或学院。地块大小与强度共同约束选型，不把高度当贡献数量。
- 每栋建筑各有独立围院及院门。院落必须完整落在所属贡献区域内，院间留0.35；支路绕行其他院落并接到街道。剩余土地安排菜畦、花树；零贡献公共空间有魔法井、泉台、路灯、传送门与居民。
- 院墙在离线烘焙时生成前后两层PNG。`CitySceneItem.sortY`只覆盖其绘制顺序，其他素材沿用原中心深度；不改变生长/包围盒的groundY。前景墙进入现有Alpha命中和高光遮挡路径，不把整块院子变成可点击贡献建筑。
- 工坊工作窗里的同尺度居民及瓶子/木撑遮挡离线合成；行会与学院开放内院另放同尺度学者、居民，保留门口人物。没有新增模拟人数、定时器或持续动画。项目/活动类型只在悬停按原成员日期取得，不由总量猜测。

预览和生产烘焙共用 `town-scale.mjs`、`scale-sprites.js`、`work-window.js`，避免两套标尺。44张PNG共2,364,185 bytes（12建筑方向、24院墙层、8生活/设施），最大实际边370像素，均不超过384且有透明边。完整资源表及可复现烘焙命令见[资源报告](TOWN-SCALE-ASSETS.md)。原设计源PNG未修改；旧整图农场、旧动物组合、长椅和集市不准入。

上述为美术设计尺。温室半身人体比例、圆形支撑包络及部分基础设施仍含手工推定，不是物理测绘或隐藏角点精确验收，详见[原型记录](../design/ancient-town-concepts/2026-11-11/HUMAN-SCALE-AND-COURTYARDS.md)及各观测JSON。
