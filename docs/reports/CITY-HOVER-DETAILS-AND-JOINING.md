# 悬停详情缓存、数量、注册塔与轮廓内收

日期：2026-11-08，Asia/Shanghai。基线`ecbc455`；用户已在自己的GitHub页面确认此前项目与高光正常。本轮在同一PR #70继续实现以下已授权调整，新版真实登录效果仍待用户重载验收。

## 事实与决策

- 成功活动本来已有五分钟页内缓存，但unknown时每次都会清空并拒绝写入；已登录缓存命中仍先画空概括，容易看起来又在获取。当前公开omit响应也按独立public作用域复用，不能读登录缓存；已登录缓存展示前仍核对实时身份，因此“活动请求0”不等于“所有网络请求0”。未完成/取消/失败响应不写成成功缓存。
- 浮层数量只表示该建筑成员日已经取得的记录，提交量求和、PR/评审/Issue按链接去重；没有完成所有成员日或部分提交数不可读时用≥或保留数量缺失，不补零。最多展示两个项目及一条同页已有PR/Issue标题，其他项目给数量提示，不读取正文或额外打开项目。
- 公共2009年度365日仅`2009-09-18`为1；当天单日活动明确写Joined GitHub，没有项目活动。该事实不等于“注册做了一次代码提交”。源日历数量保留，用专属注册纪念高塔表达该里程碑。
- 用户截图中的额外空城区来自ISO2009首周跨到2008的缺失日期，被当成未加载占位。现仅为完全未提供的周保留加载场地，部分已知的边界周按真实地块规划，不填补缺日。
- 最新所选公历源年到达后，已提供日期上界之外不再继续保留未来周空占位；较早源年仍在加载时保持场地，不把尚未返回的数据误当作零值。该判断使用已到达快照的日期上界，不新增时钟轮询。
- 用户随后确认轮廓方向：年份/周继续决定日期位置与道路骨架，外缘按连续时间段内实际活动地块的包围盒平滑内收，内部空白保留庭院，避免逐日挖洞。年度交通走廊及共用道路轴线保持；季度路在规划时延伸到实际交点。独立注册塔只保留1×1地基、小型两车道接入，不再铺七天长条。

## 注册识别、素材与生命周期

仅当所选范围含主页最早可用年，在该源年首次到达时最多检查其首个非零日；单日标题匹配且TimelineItem明确为Joined GitHub才确认。不能把任意首次提交推断为注册，也不扫描所有历史日期。该查询和悬停共用身份协议及缓存，失败不虚构注册，身份失败/取消仍传播到现有清理流程。加载协调器先取得已确认日期，再把它交给正式地块规划和模型选择，不在完成画面上修补布局。

注册格禁止并入普通矩形/奇观，始终1×1，原始date/count和总量不改。塔运行PNG为123×384 RGBA、75,521 bytes，源图1024×1536仅作正式设计源，不进入发行包；完整提示、透明清理及标定见[素材记录](../design/github-joining-tower/README.md)。运行目录97→98张，普通按需解码、预滤波、透明度命中、高光及释放共用，无新增持续动画。

## 验证环境与输入

独立Chrome157、Apple M1、Node26，本地HTTP页800×500，不访问用户浏览器资料或凭证，不在真实GitHub页注入脚本。生产createCityHover→请求→解析→DOM使用受控pick/身份/传输；生产createLandscape、有机规划器及正式PNG用于城市路径。没有新增单元测试。

实现前准备并运行浏览器驱动；基线由git archive ecbc455导出，相同输入再跑当前版。悬停输入为2025-05-02/05-09两天、每日30；每个单日响应含6次提交、同一PR、同一被评审PR和同一Issue，标题Improve search。身份响应延迟120ms、活动延迟300ms，观察首次及再次悬停、内容增长前后角点、身份变化。公开与登录身份分别验证；synthetic private/project只用于隔离检查，不是真实私有仓库证据。

注册使用正常TLS匿名curl读取的2009年度、2010年度与2009-09-18单日XHR HTML，经正式解析器消费；ISO2009只纳入2010-01-01至01-03，未编造2008缺日。另以2009全年每天30的稠密输入验证特殊格不丢失日期或数量。

轮廓比较输入按ISO周年边界生成：2024–2025每天30；稀疏版仅每年第8–20周的周一至周五为30、其余0；跨河版2019–2024全年周一至周五为30、其余0。基线与当前均通过正式场景创建、素材读取、updateDays、draw、销毁；统计年度共用道路以及季度路实际穿过该轴线的数量。

构建命令：`npm run check`、`npm run build -- --outDir "$task_tmp/package/dist"`、`git diff --check`。本地驱动通过独立Chrome临时user-data-dir启动正常时钟页面，异步结果POST回本地服务；截图仅用于当次目视检查。减少动态效果使用保持连接的独立CDP会话，检查matchMedia确为true，再检查动画调用。
