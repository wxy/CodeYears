# 0.1.3 候选版的城市与路牌验证

本机使用 macOS、Chrome 157.0.8103.79、Node 26.7.0。受控页面用于稳定复现交互及边界；公开 GitHub 主页用于检查实际视图。此报告记录候选构建的验证。

## 窄屏菜单及长账号

用 Playwright 在独立配置中启动 Chrome，通过浏览器 CDP 的 `Extensions.loadUnpacked` 加载构建目录。受控 GitHub 个人页只暴露 2025 年入口，提供完整 365 日，各日贡献为从零起算的序号对 7 取余，使界面出现年份边界提示。视窗设为 375 × 750，分别检查内嵌和展开视图。

- 在内嵌深色与展开浅色界面打开「更多」，点击语言选择框中心。两次均命中语言框，可切换英文与中文，Esc 将焦点交还「更多」。
- 设置一个由 39 个连续小写 w 组成的合法目的地。用实际路牌链接依次进入长账号城市及第三个城市，形成返程入口。分别在内嵌与展开视图用 Shift+F10 打开长目的地面板和独立返程面板。四次面板的可视宽与内容宽均为 320px，横滚偏移均为 0；Tab 可聚焦链接，Esc 回到对应路牌。修复前长名导致面板内容宽达 470px。

## 真实公开城市、车阵与草地

在独立、未登录的 Chrome 配置里打开 `https://github.com/wxy`。分别加载主干基线 `d960942` 和候选版，使用减少动态效果、1440 × 1000 窗口及默认三年范围。两版都显示 2024-01-01 至 2026-11-18 的 7,863 次公开贡献。用键盘选中首栋建筑，两版都显示 9 个活跃日、89 次贡献及相同日期。

- 同一次查看中，按 + 再按 −；另用鼠标将画布向右拖 100px 再拖回。每次中间帧都发生变化，两次恢复原取景后的主 Canvas 像素都与初始图逐像素相同。切回原图再进入城市，同一取景下像素发生变化，贡献总量与日期范围相同。
- 在主 Canvas 的 (5, 5) 取 55 × 50 像素的城外草地，用每个像素的 `0.2126 R + 0.7152 G + 0.0722 B` 计算亮度。745 × 340 内嵌画布中，样本的亮度标准差从 28.08 降到 19.96（下降约 29%）；1398 × 903 展开画布中，从 28.94 降到 22.93（下降约 21%）。调整随像素尺度连续变化，达到近景后恢复基础地纹原始对比。

## 已命名路牌的全景

用正式布局器与 Chrome Canvas 生成三年稠密城市。输入为自 2023-01-02 起的 1,092 天，第 i 天贡献为 `2 + (i × 19) % 61`。在 980 × 340 下，普通初始视距仍为 100%，其中一个出口牌原本越过画布顶沿约 2.4px。

- 点击「全景」，在空牌配置之后送入 8 个已命名出口及 1 个临时返程牌。分别更新年度数据，并将视窗从 980 × 340 改为 375 × 300、1398 × 902。九块牌均在可用画幅内，与顶端 40px 的提示区及底部 48px 的工具区之间至少留出 27.5px。
- 接着放大两倍并用方向键平移 40px，改变路牌名字后取景保持不动。再次点击「全景」可恢复完整画面。约 35% 的全景先放大至 1.1 倍、再反向缩回时，九牌命中框也回到原坐标。
- 在正式扩展中，用 39 字符的目的地与真实导航产生的独立返程牌复核内嵌、展开和调整窗口。375px 窗口内，目的地牌距画布边界至少 95.9px，返程牌至少 106.9px；1100 × 850 窗口内的返程牌也完整可见。上述场景均可看清牌面，实际年份提示与缩放按钮均未覆盖牌面。

## 车辆与资源复用

在合成三年页面上用实际 Chrome MV3 入口进入城市，记录 Canvas 绘制的车辆贴图、位置及其他图元。在往返拖动、缩放后，20 辆车的指纹一致。再从贡献图进入，得到 26 辆车，1,043 个非车辆图元的位置与素材全部一致，仍复用同一个画布。连续三次进入得到三种车阵；缓存有效时，切回城市的年度请求和素材请求增量都是 0。首次动态导入过程中切到后台再返回，只在最初点击时抽一次种子。

补齐另一个年度的输入时，受测路段的 19 辆既有车位置保持一致。以 2005–2024 年逐日 1–5 次、每 120 日仅前 8 日有 1–5 次两种输入，在正式规划器各试 10 个种子，分别得到 95–128 辆、41–61 辆，均满足现有的 180 辆上限、车距和路口、出口避让。全景测试另将窄屏提示区由 28px 增高到 94px，同时显示九块路牌时，距可用区域仍至少留 21.5px。

## 构建与范围

用 `npm run build` 在项目根目录生成 Chrome 可直接加载的 `dist`，包含 TypeScript 检查。在系统临时目录执行 `python3 scripts/package-city.py --output-dir <临时目录>` 和 `python3 scripts/verify-city-package.py <临时目录>/codeyears-0.1.3-city.zip --build-dir dist`，120 个打包条目的 CRC、引用、权限、版本和必要随包说明通过。扩展清单、package 和锁文件均标为 0.1.3。本轮验收聚焦 Chrome 的画面与直接交互，跨设备同步、其他浏览器和商店发布不在此次验收范围。
