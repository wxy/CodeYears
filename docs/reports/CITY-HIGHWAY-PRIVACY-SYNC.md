## 路牌和同步

- 在两个独立 Chrome 配置 A、B 内安装扩展。主页为合成的 sample-owner，2025-04-10 有 5 次贡献。A 本地首个出口为 local-road，B 本地首个出口为 stale-other-device。将 A 的同步区值送入 B 的真实扩展同步存储，模拟浏览器收到同步更新。
- 验证默认路牌仅本机保存、身份复核不符时拒写、主动开启时带上本机已有路牌，B 优先恢复同步配置。同步编辑、外部设置变更、同一出口在编辑期间发生变化、删除最后出口、关闭同步并保留当前设备最新副本均符合预期。未知身份或标签页旅程记录写入失败时，原生目的地链接仍可导航。
- 正式 `planOrganicCity` 和 `createCityView` 使用 2025 全年稠密输入，第 i 天贡献 `2 + (i * 19) % 61`。980×470、DPR 1.5 下配置八个出口和独立返程。对比默认视距及 400% 近景，蓝色出城、绿色返程、无文字空牌各自可辨。主出口默认命中宽度由 49.06 增至 56.49 CSS 像素；600% 近景下 39 字符用户名分两行完整显示。实绘的九个牌面中心均命中各自多边形；18 个脚点均在离城右侧、全部受测路面之外。该场景最小右侧余量为 11.83 CSS 像素。
- 键盘、触屏及 Chrome 存储验证使用真实扩展与受控页面。尚待真实 Google 账号双设备在线同步、真实私有组织/SSO 会话以及 Edge 验收。

## 规划和发行检查

- 取 2025-05-01 的一笔贡献，用正式规划器分别选择 2025 和 2024–2025，得到同一 garden-butterfly 建筑。再取 2005-01-03 至 2024-12-29，按顺序令 `i % 405 < 143` 的天数为 0，其他日为 `1 + (i * 17) % 83`。7,301 天中 4,716 个活跃日恰好各属于一个地块，地块合计 197,971 次，与输入一致。
- `npm run check` 与全新目录中的构建通过。在独立临时目录用 `python3 scripts/package-city.py --output-dir <候选目录>` 两次生成相同候选，保持原文件不变；用 `python3 scripts/verify-city-package.py <候选.zip> --build-dir <全新构建目录>` 核对 CRC、120 个条目、清单、引用、权限与随包说明，通过。分别放入内容不同的同名 ZIP 和摘要，再试仅有冲突 ZIP 的情况，均拒绝覆盖，已有字节保持一致。
- 验证未操作线上发布存档、Chrome 商店或生产隐私页面。
