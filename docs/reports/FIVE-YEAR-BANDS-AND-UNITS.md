# 五年景观带与第二轮单元设计

日期：2026-10-31。布局源码 `a27732c`，分支 `codex/year-landscapes`，更新原 PR #15，不合入。

## 行为与设计范围

原先绿带/湖泊人工放在所选年份列表中间，不按贡献量划分。现从所选历史最早年份起，每五个年份一组；仅在相邻组之间插景观带，组内保留普通年间道路。它是装饰性组间空间，不代表低贡献，也不消耗日期格。不足五年不插带，不在末尾补带或未来年份。三年不再被中间公园分开，二十年为四组、三条景观带。

单元规范增加 3×3 H1/H2 与各 A/B，建筑目录扩为13个组合。八张设计板覆盖26款建筑、10款植被、8款平地；四个子代理分批并行完成22款独立透明候选。加入由明确坐标绘制的统一投影模板，地面两轴±0.5、竖边竖直，所有占地用同一地面格比例。**造型图和透明候选不是已标定运行素材**，新单元/季度支路尚未接入，具体实际投影问题保留在候选说明。
