# 双向车道、车辆与桥头连接组合验收

日期：2026-11-01。基线 main `63327cb`；#25→#26→#27已按授权保留历史合入。新分支 `codex/city-road-network` 整合独立云端 PR [#28](https://github.com/wxy/CodeYears/pull/28)（`7000a01`）和 [#29](https://github.com/wxy/CodeYears/pull/29)（`0d45284`），本轮新PR不合入。

## 原因与实际实现

旧桥先寻找岸树间隙再横向折接季度路，桥头不以路口为起点；两岸季度周列还可能不同。现在道路、桥面、桥上车辆与岸树避让共用世界坐标计划：先按同季度配对两岸真实路口，桥端与路口中心一致；相同列为直桥，不同列以端部沿道路方向的缓和中心线过渡。不移动任何日期地块，只移除桥廊里的装饰岸树。

季度街道双向2车道、年度主路双向4车道、闭合外环双向8车道，单车道0.4逻辑格，中央双黄线、同向白色虚线、路缘和过街带分别绘制，路口内部标线断开。外环中心距地块3.6格、外缘5.2格，与最外年度主路保留0.4格路床间隔。桥与季度路同为0.8格路面，坡道降到路口地面，栏杆在桥头前结束。

轿车、SUV、厢式车和公交车为确定性静态装饰，车道内双向行驶朝向、避开路口，桥车跟随同一桥面高度/切线；总数最多180。镜头和重播不重新随机布车。绘制路径在创建时预备，进入既有远/近景地面缓存；不增加图片、依赖、权限、计时器或交通模拟。贡献合并、奇观和日期映射不变。
