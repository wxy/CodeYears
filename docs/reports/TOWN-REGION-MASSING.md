# 区域建筑体量修正

后续用户反馈否定了长排窗与宫殿式体量：当前实现已转为小屋围合的乡间院落，见[最新报告](TOWN-RUSTIC-COURTYARDS.md)。本报告保留当时技术证据，不能视为当前造型或用户验收。

2026-11-11。基线为PR [#78](https://github.com/wxy/CodeYears/pull/78) 的 `aa4f5bb`，在独立临时工作树完成，未包含并行的现代道路/路牌PR #79。用户要求少量较大建筑代表较大区域的平均贡献，指出小屋、大片院子及稀疏分布仍不合适。本轮更新原PR和已有本地测试构建，不合入或发布。

## 原因与实现

同一真实输入的96个多日区域，原主体建筑包络总面积只占区域面积13.66%；175区域放219栋小主体，并有3,271块装饰菜畦。增加合并范围后沿用小模型、以院子/田地填空，不能实现用户要求的建筑体量。

现在每个正贡献区域一座完整主体、一座独立围院。新增商馆、连体庄园、工匠会所、四方院、学院、长厅与广翼学宫，通过实际新增开间/连接翼楼增加体量；没有把门、窗和居民随地块整体放大。普通门设计高1.0、成人0.8，所有运行实例factor=1。

选型先取可完整容纳的最大建筑包络，再在面积至少为最大90%的同量级候选中按日均偏好朴素/工坊/学院形态；体量不会被旧band硬限制阻断，也不声称每种占地已有每个强度的专属外观。已有区域均值、原成员与数量直接沿用。每院居中、门路接原街道，侧退让0.30（普通路肩半幅0.29）；移除多院排布/绕院分支、全部填充菜畦和成排果树，保留门口/可见内院人物、公共空间及低档单日畜舍动物。新小内院只放一名居民，广翼内院两名，不据此表示真实人数。

合并规则、已知零值/未知日/注册日边界、最多32成员、周/星期/年份方向、世界场景尺寸及材质背景道路沿用。改动前后同一场景均为201.4×85.8，年份方向与现代城市相同。

主代理复看共同倍率绿色底板：原农舍、学院与七个新主体、围院及标准居民；没有按卡片fit。新源外围无橙色底块；小内院脚点取自可见铺地，不把屋顶或被遮挡位置当落脚处。
