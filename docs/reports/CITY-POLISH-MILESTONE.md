# 个人经历里程碑探索报告

日期：2026-11-08。基线 `5c6d2e60b3becdbb5900d98cb7478a1fbf9b6bba`。仅工程预览，正式行为不变，不合入/发布。

## 假设

相比继续增加地标，用注册塔关联明确首库日期与少量活动量化摘要，能够提高经历识别度且不挤占日期格。首库必须同时满足地图内有明确注册塔和从注册日起完整创建事件证据；相机看不看得见塔无关。真实历史HTML未证明能满足完整性，不以最早可见仓库推断首个。

## 实现

入口 `probes/city-polish/milestone/`，命令 `npx vite --config probes/city-polish/milestone/vite.config.ts`，浏览器4185。默认基线，按钮开启候选。共用同一个生产城市规划、地面、排序、预烘焙PNG和画布，仅替换工程摘要。同日复用注册塔；异日只关联日期，不新增仓库楼。无塔/范围排除塔/不完整证据不认定。既有路网、桥、ISO周年/周列/星期与成员indices均由原函数生成；摘要开关不重规划、不触碰date/count。

量化摘要为范围活跃天数和最高单日贡献，没有具体PR标题、工时或绩效。组织事件不实施。新增PNG为0，没有新的素材预算、定时器、RAF、请求、权限或持久化。

## 可复作输入

全部是合成证据与确定性日数据，非真实登录数据。ISO 2020（371天）与2020—2025（2191天），范围排除塔时改为2021或2021—2025。UTC逐日生成，日序i从范围起点0开始：稀疏/多年 `i%17===0 ? 12 : 0`；稠密每天30；所有输入的2020-01-06固定1，保证正式选择器产生注册塔。事件：Joined=2020-01-06，异日创建=2020-02-03，同日创建=2020-01-06；弱证据只关闭完整覆盖标志，无注册场景不提供Joined。不得拿这些合成事件当作真实取数结果。

切换摘要保持相同镜头，整体按钮为50%，近景先命中注册塔再放大居中，允许拖动、按钮缩放。上限取正式素材上限与2000%较小者。整体与近景可分别开关候选比较。

## 实际验证

云端Linux，Node24.19.0，Chromium154.0.8037.57独立无登录headless，1200×920、DPR1。`npm ci`、`npm run check`、`npm run build -- --outDir /tmp/codeyears-milestone-build`通过。正式landscape114.07kB/gzip35.14，与固定基线相同。规则断言先于实现编写，`node probes/city-polish/milestone/rules.test.mjs` 7项通过：异日、缺塔、不完整、同日、首库不在范围、注册前冲突、无创建记录。

浏览器三输入×五证据场景15组：异日/同日识别，弱证据/无塔/排除塔不识别；每组连续开关候选不增加draw计数。完成近景后静止观察1.2秒draw计数不变；隐藏再恢复canvas对象身份相同。页面无脚本错误。最终近景与整体截图在临时目录查看后清理。原型不使用帧循环，单次静态绘制由交互触发。没有把云端软件渲染作为本机GPU、功耗或真实MV3验收。

## 视觉取舍与性能

候选增加了明确日期、同日共塔关系和“不认定”解释；城市轮廓完全不变，远景中首库不会比基线更醒目。它适合作为摘要方向比较，尚不是独立视觉地标方案。保守表达避免为每仓库制造重复地标，也保持每日贡献映射。

规则排序成本O(E log E)、日期集合O(D)，摘要统计O(D)，仅输入/按钮变化运行；新增解码/PNG/持续帧为0。正式包不引入本原型。未测内存、硬件帧率、20年预算与真实身份复用。

## 未验收与建议

真实首库取数未实现；完整覆盖、删除/私有历史、身份可见性与HTML稳定性未证明。注册日count=0时正式选择器可能只显示平地，本轮样本明确使用1，不修改共享渲染器；未来接入必须检查真实塔存在。独立组织事件与异日专用楼体未实现。年度特征当前仅做范围统计，尚未逐年形成独立视觉特征。

建议继续：采用保守证据门槛与同日共塔原则，先评估用户是否认可摘要增益；不要直接启用真实“首库”标签。若需要地图远景可辨性，再做获得接受的专用标识规划；当前没有视觉证据支持增加每仓库楼体。
