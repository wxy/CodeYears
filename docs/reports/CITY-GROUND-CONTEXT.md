## 环境选择规则

`createGroundSelector(weekly)(parcel, seed)` 只用于已经规划的零贡献地块。创建选择器时对 `weekly.cells` 建一次位置索引，查询本年度地块向四周各扩两格的邻域；单格约 5×5，2×2 约 6×6，仅统计实际存在的日期格，不补缺失/未来日期。季度道路不阻断环境观察，因为道路两侧仍可能属于同一城市环境；不跨年份统计。

- **自然环境**：邻域中非建筑（每日 0–5）占比至少 80%，且建筑不超过两格。单格选 1×1 草地；2×2 选 2×2 草地，邻域至少 12 个有效格且无符号 seed `%24` 为 0/1 时分别选 pond-a/b。水塘因而必须处于整体空旷且自身 2×2 连续零值的区域。
- **城市广场**：不符合自然环境，邻域建筑至少四格且占比至少 1/3，自身为 2×2 零值地块，seed `%6===0` 才出现；按 `floor(seed/6)%2` 选择 A/B，避免筛选条件让一种变体永远选不到。
- **其余零值地块**：`urban-paving` 铺装；单格 factor1，2×2 factor2，地面和尺寸同步等比。城市中的零贡献不再随机成为草地/水塘。

这些阈值是本轮可复核的绘制选择，不是贡献数量口径变化。低贡献的幼树、树木继续沿既有数据表达，由场景调用方保持。函数不读取缩放、时间或随机源，不改传入 weekly，选择在城市创建时固定。

## 程序素材与资源责任

`createCityDecoration(id)` 仅识别 `urban-paving`、`traffic-signal-w`、`traffic-signal-d`、`traffic-signal-d-reverse`；其他 id 返回 undefined，继续由原 PNG 目录处理。它们以 Canvas 原生几何生成，不修改已有位图，不增加下载资源、依赖或动态灯光。

| id | 原生占地 | baselineHeight | 画布尺寸 | 落地位置 |
| --- | --- | ---: | --- | --- |
| urban-paving | 1×1 | 0 | 292×148 | 标准 1×1 平行四边形，暖灰石材与细拼缝 |
| traffic-signal-w / d / d-reverse | 0.25×0.25 | 0.6H | 100×124 | 杆中心 `project(.125,.125)=(0,6)`，归一后 `(0,.0625)` |

共同 W=(48,24)、D=(-48,24)、H=(0,-48)，随后按既有 `/96` 规范返回 Sprite 的 left/top/width/height；烘焙比例3、透明边距2像素。灯具的杆保持竖直，支臂沿 W/D 两个方向延伸，灯箱面沿另一条地面轴；W 向点亮静态绿灯、D 向点亮静态红灯，不模拟交通或添加动画。主代理按 native 占地、factor1 将灯放路缘，沿用现有深度排序。

北侧东角专用 `traffic-signal-d-reverse` 保持同一落地锚点、灯箱投影和静态红灯，只把支臂端点由本地 `(.125,.315,.6)` 改为 `(.125,-.065,.6)`，即沿 -D 伸出0.19格。按场景位置 `x=roadX+ROAD+.05、z=yearZ-.3` 放置时，杆中心为 `z=yearZ-.175`，支臂端点为 `z=yearZ-.365`，回到年度主路内；南侧仍使用原 +D。没有增加图片或常驻动画。

装载时只对去重后的实际请求 id 生成程序画布；PNG 仍按文件共享解码。外层资源恢复职责覆盖目录缺失、程序创建失败、PNG 失败与取消：先收集已创建程序 Sprite，失败统一调用 `closeCityImages` 后原样抛出，不吞错或用默认图片伪装成功。PNG 失败沿用原来的用户可见错误转换；源位图仍在原 finally 关闭。成功后的普通关闭同样把四个 id 对应的程序画布尺寸归零。不在逐帧绘制时重新生成。
