# P1-B 访问者隔离与年度缓存验证

日期：2026-10-30。状态：主线原型已实现，通过 [PR #5](https://github.com/wxy/CodeYears/pull/5) 交付；18 项受控浏览器检查证据绑定 `e818cb6`，真实 Chrome 已登录缓存主流程及本轮构建证据绑定修复提交 `adb5eab`。A/B/未登录实际账户、跨标签页身份变化和 Edge 待验收，不能据此宣布完整真实身份隔离或 P1-G 完成。

## 范围与实现

- 分支 `codex/p1-viewer-cache`，基线为合入 PR #3/#2 后的 `main` `12b00e2`。不修改时间轴或渲染源码；云端另在 `codex/time-travel-probe` 推进独立时间轴前置原型。
- 环境：本机 macOS、Chrome 156、Node.js 26.7.0、npm 11.19.0；沿用锁文件，无新增依赖。
- `chrome.storage.local` 键按 schema 1、访问者登录名/未登录、主页和年份隔离，名称转小写。只存连续日期/数量、抓取时间和版本，不保存原始 HTML。
- 缓存读取入口校验作用域、schema、解析器版本 2、连续日期、非负整数和有效期。当年 1 小时且跨日失效，历史年 30 天；损坏/过期/旧版本视为未命中。
- 已知身份在读取缓存前、使用缓存/写入网络结果前，各请求一次禁用浏览器缓存的同源完整主页，检查当前访问者。命中缓存会省去年份请求，仍需要身份请求。变化或无法确认时停止；身份不明只联网获取，不读写缓存。
- 界面提供读取、强制刷新、清除此访问者在当前主页的全部年度缓存、取消与关闭。明确显示网络/缓存来源及抓取时间；缓存命中不声称重新核对年度标题。标签隐藏清空可见数量并取消请求。
- 缓存读失败改为联网并提示，写失败仍显示有效网络数据并提示；网络/解析失败不覆盖有效缓存。不新增后台服务、Token、Cookie 或持久网站权限。

## 验证方法与输入

在实现前创建主线失败方式清单与受控检查。真实页面无法可靠、低干扰地制造另一登录账户、损坏存储、配额错误或请求中切换，因此这些状态只在 Fetch/Chrome 存储边界模拟；真实解析器、缓存、请求编排和界面源码直接运行在 Chrome。没有退出用户账户、复制凭证或把真实用户缓存写入测试。

输入生成：遍历 UTC 2024-01-01 至 2025-01-01（不含），生成 366 个日期格及 `tool-tip[for]` 英文数量。默认仅 01-01 为 7，其余为零；切换场景改为 9/11/12/13，并同步年度标题。完整主页输入使用 meta user-login 为 Alice/Bob、body logged-out 或两者都缺失。存储适配用按键复制的 Map 表达 Chrome 的异步 get/set/remove，只在读取/写入失败场景拒绝 Promise。

缓存主线共 13 项通过：

1. 首次联网写入，再次命中不重复获取年度。
2. Alice/Bob/未登录查看同一主页分别建记录，数量不混用。
3. 身份不明零次缓存读取/写入，仍可联网取得数据。
4. 同一访问者的不同主页隔离。
5. 强制刷新重新请求并更新当前作用域。
6. 超过 30 天及旧解析器版本重新获取。
7. 日期缺失的损坏缓存重新获取，不填零。
8. 年度请求前后身份改变，拒绝结果且没有缓存写入。
9. 年度请求中取消，没有缓存写入。
10. 缓存读取失败仍返回有效网络数量及提示。
11. 缓存写入失败仍返回有效网络数量及提示。
12. 强制刷新网络失败，原有有效记录字节不变。
13. 清除只影响当前访问者/主页，其他访问者与主页记录保留。

另有 5 项真实 Shadow DOM 界面流程通过：初次打开不自动读取；联网→命中→强制刷新→清除→再次联网；其他标签身份变化的受控响应不会展示旧缓存；后台隐藏取消并清空行数；写失败仍显示 366 天和明确提示。界面测试只把本地测试 URL 映射为已知 GitHub 主页路径，其余真实界面与加载编排不替换。
