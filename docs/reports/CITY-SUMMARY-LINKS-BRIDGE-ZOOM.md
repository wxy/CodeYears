## 环境与方法

macOS本机，Node26.7、Vite8.3.5、TypeScript7.0.2、独立Chrome157 headless；1000×650 CSS画布，DPR1。`git archive 76f6316 src`导出基线，分别用Vite将相同临时入口打包，127.0.0.1临时HTTP提供生产模块与正式运行PNG；Chrome使用本次专属临时资料。没有访问已有Chrome资料、改Codex/浏览器设置、在GitHub页面注入脚本或读取用户凭证。首次驱动因相对素材base导致失败，改成绝对本地URL；ResizeObserver首次回调清除悬停由驱动等待后触发；输入边界按ISO周年筛选后完成矩阵。这些是驱动修正，不作为产品失败或通过的证据。

必要命令：在本PR源码目录执行 `npm run build -- --outDir <本轮临时目录>/package/dist`（包含`npm run check`）；素材执行 `node scripts/bake-city-transport.mjs --outDir <本轮临时目录>/baked --canvasModule <临时安装的@napi-rs/canvas@0.1.80>/index.js`。未增加项目依赖或事后补单元测试。包装使用该临时package内的 `python3 scripts/package-city.py`，核对manifest、许可、版本、资源、ZIP完整性与SHA256。

浏览器入口直接调用 `planOrganicCity(days,90,years,true,years[0],joinedOn)`、`loadCityImages`、`createCityView(...,0,createOrganicGround(plan))` 并绘制；贡献输入以UTC逐日生成、公历窗口内再筛选`isoWeekDate(date).year`属于years。每组核对总量、所有非零成员的数量与唯一覆盖；将实际roads的线段相交关系组成连通图。连接线与同轴季度街道可能被原有line map合并，不能仅按`organic-link`名称计数，所以长度统一包含`organic-link/exit`，减去不变的四向12格出口（48格）。三片区用实际非零地块矩形核对穿越，避免把原季度街道穿过街区包围盒误当成穿楼。

- 庭院：2020—2022，除2021外均16；2021中03-10前、10-01后及06-16为16，其余0；06-16用作受控单日里程碑，检验庭院中的独立小片区，不是实际注册记录。

- 稠密：2006—2025所有日期30。
- 跨河：2010—2015所有日期30。
