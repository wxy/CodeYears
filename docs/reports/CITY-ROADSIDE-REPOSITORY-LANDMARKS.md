# 0.1.5 道路绿化与环外仓库地标

2026-11-21。基线是合入 0.1.4 的主干提交 `085aa52`。本轮试验使用现有树木和住宅素材。

## 复现

1. 运行 `npm ci` 和 `npm run build`。在 macOS Chrome 158.0.8127.36 的全新未登录配置加载 `dist/`。
2. 打开 `https://github.com/wxy#codeyears-city?from=2017&to=2026`。等待日期范围和贡献合计出现。用同一日期范围打开保存的 0.1.4 构建做对照。
3. 展开地图，点「全景」。检查左上角方向标、环外的住宅和装饰小村。直接悬停环外住宅，将鼠标移动到卡片上并滚动列表。检查键盘聚焦与 Esc。放大到河带，检查两岸的英文路名和道路两侧树列。
4. 在新配置用 DevTools 阻断 `*://api.github.com/users/wxy/repos*`，检查贡献图仍可用以及「更多」中的提示。用 DevTools Fetch 分别提供 100 条与 5 条同一五年城区的公开仓库样本，首页带 `Link: ...; rel="next"`，复现分页。
5. 运行 `python3 scripts/package-city.py --output-dir <临时目录>` 与 `python3 scripts/verify-city-package.py <临时目录>/codeyears-0.1.5-city.zip`。

## 实际结果

- 公开主页的 2017–2026 选区显示 55,943 次贡献，覆盖 2017-01-02 至 2026-11-21。0.1.4 的对照合计与覆盖日期相同。0.1.5 的三个地标分别列出 7、10 和 17 个公开仓库。抽查卡片名称和日期与 Chrome 收到的 GitHub 公开 REST 响应一致。观察到一页 HTTP 200 请求，未发送 Cookie 或 Authorization。
- 三个住宅组各有五栋房屋。鼠标直接悬停房屋打开日期列表，静止图面没有年份牌。移入卡片仍可阅读，滚轮滚动列表时地图倍率保持原值。键盘聚焦同样打开卡片，Esc 先收起卡片并留在展开的地图中。阻断接口时只有仓库提示，贡献城市仍可用。两页受控数据共 105 条，在一个对应住宅组的卡片中完整出现。
- 在 1440 × 1024 的全景中检查方向标、环外的三个住宅组和田野聚落。拉近到 295% 后，能同时读出 `10TH AVE N BANK` 和 `10TH AVE S BANK`，河岸和楼旁有连续植树，桥头和交叉口留空。
- 通过 TypeScript、Vite 和发行包核验。ZIP 137 项，33,442,701 字节，SHA-256 为 `ce244d2e94b0e2bfad3712e8836600c5a08243ec387daaf62647d69aa797d4c5`。

本轮覆盖匿名公开主页的 Chrome 路径。Edge 与完整硬件性能预算另行验收。

## 11 月 21 日后续修订

### 引桥与布置

种植带加入后，原引桥每端离岸路实际车行边缘差 0.64 个世界单位，坡脚还沿用包含种植带的 2.48 格宽度。现从实际岸路边缘起坡，用 1.2 格两车道车幅接回路面。种植带内的宽冠树在直路沿轴密植，并让出实际引桥。仓库住宅沿外环直段按创建日期的公历年排列，密度高时缩小同年院落。没有同年可建直段时使用相邻可用路段，卡片继续标出实际年份。

### 复现与结果

1. 运行 `npm run build -- --outDir <系统临时目录>/dist` 和 `git diff --check`。通过独立 macOS Chrome 158 的 `Extensions.loadUnpacked` 加载这一构建，再在另一个未登录配置加载上一版 `fe6ceda`。
2. 两个配置均访问 `https://github.com/wxy#codeyears-city?from=2017&to=2026`。等到贡献总数出现，再展开并全景复位。两版均显示 55,944 次贡献，区间为 2017-01-02–2026-11-21。新版 34 个公开仓库分为 34 组住宅，每组三栋。直接悬停住宅打开对应名称和日期，鼠标移开后收起。按钮聚焦也能打开，Esc 收起卡片并留在展开地图。浏览器未报告页面脚本异常。
3. 核对浅色、深色罗盘。星形与字母在同一个 SVG 中旋转，背景透明，边框为 0。N 在右上，S 在左下，连接两字母中心的屏幕斜率约为 -0.5。把指针移到全景的河带桥面，滚轮放大至 299%，对照两版引桥边缘、树冠间距及桥口留空。
4. 同一路径仅替换仓库接口响应，提供同一公历年 105 条仓库记录，首页 100 条并给出下一页链接，末页 5 条。其中一条日期为 2023-01-01，用来区分公历年与 ISO 周年。两页均读取，105 组住宅都能找到各自的卡片，全部标为 2023 年。

这轮浏览器验收使用已退出的 Chrome 配置。分页压力检查使用受控响应，画面检查覆盖公开主页与上述取景。Edge、登录态和完整硬件性能预算另行验收。
