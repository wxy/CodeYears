## 固定接口与实际实现

接口逐项遵照任务：RoadPoint=[number,number]；CityRoadRoute含id、readonly points、lanes:2|4|8、可选closed；CityRoadJunction含x/z/radius；CITY_LANE_WIDTH=.4；createCityRoadPainter返回(context:CanvasRenderingContext2D)=>void。路线为世界XZ中心线，普通道路轴向两点、闭环四角不重复。创建时预计算Path2D与所有样式/虚线相位；调用paint只save、附加投影transform、提交描边、restore，无新画布、图片请求、逐帧几何或动画。

地面统一W=(.5,.25)、D=(-.5,.25)，路面用真实世界宽度stroke后整体投影，2/4/8车道宽度分别.8/1.6/3.2。路缘先于所有路面，所有路面先于所有标线，避免道路交叉处路缘穿过路面。中央两条黄实线偏移±.05、线宽.035；同向车道每.4格一条白虚线（.24实/.22空），4车道左右各一条、8车道左右各三条，2车道无同向分割线。两侧内退.055格的细边线、外侧路缘形成层级，无斑马纹。

偏移标线在闭环各转角计算相邻段交点。所有标线（含边线）在传入的圆形junction半径内裁断，扩半线宽防残留，重叠裁段合并；虚线相位按原路径距离累计，路口裁断后不会重新起步。路面本身保持连接。路口坐标/半径和真实路网、桥端点由主代理提供，本模块不推断路网。调用者需给足路口半径以覆盖应断开的标线区域。

## 实际浏览器样板

云端Linux6.18.57，Node v24.19.0，Chromium154.0.8037.57 headless，Playwright控制，窗口1600×850、DPR1。通过现有preview:city Vite服务导入新模块，在临时页面画两块浅/深背景样板，不修改预览源码；先pagehide停止原时间轴。使用三条水平路：从(0,0)/(0,5)/(0,10)至(18,0)/(18,5)/(18,10)，分别2/4/8车道；纵路(10,-4)至(10,15)为2车道；四角(-3,-4)/(21,-4)/(21,15)/(-3,15)的closed环路为4车道。junction位于纵路交点，z=0/5/10半径=.8/1.2/2，环路两交点z=-4/15半径1.2。

- 查看临时样板：中央为双黄实线，同向白虚线数量随2/4/8车道变化，路口中心无贯穿标线；闭环转角标线沿偏移路径连接，路缘不穿交叉路面。浅深均可辨；以34和12 CSS px/世界投影单位两档观看，同一几何随缩放，没有改变车道宽度或密度。
- 拦截实际Canvas stroke，按三位小数记录提交的世界路面宽度为[.8,1.6,3.2]。Canvas内部浮点表示不作严格二进制相等判断。宽度比例由同一worldXZ描边/transform保证，未用屏幕坐标线宽伪造双向路。
- 同一painter在两种背景两档缩放共paint四次，Path2D构造计数创建后97、绘制后仍97；共408次stroke。该计数证明此样板paint未重建路径，不是耗时、GPU内存或FPS验收。
- `npm run check`、`npm run build -- --outDir /tmp/codeyears-lanes-build`、`git diff --check`通过。模块尚未集成，因此主构建不会把它作为可达模块打入城市入口；TS检查与Vite样板已直接加载该模块。没有事后新增单元测试。
