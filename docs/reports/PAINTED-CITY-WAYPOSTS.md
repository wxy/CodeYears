# 精绘公路牌、宽路名称与双向返程复用

日期：2026-11-11。状态：实现、编译与下述直接路径完成，本机 `dist/` 已重建；继续更新 PR #79，未合入或发布。当前造型与尺寸仍待用户本地验收。

## 最终行为与边界

- 现代款为薄反光铝板、白色边线和细镀锌立柱；双向款为蓝底双白边。小镇款为带支架、石基、灯笼和藤蔓的精绘木牌，双向款另有蓝色木面、雕花及嵌边。全部由内置 imagegen 制作，保留四张正式源图和提示词，未继续使用早稿厚重装饰框。
- 牌面控制点离线校准，四个出口使用两种方向；牌面和路杆作为世界对象绘制，文字保持正向。牌面仅写 GitHub ID 或“？”，不再追加“的城市”。长 ID 分行，ID 与方向箭头不烘焙进素材。
- 出城段统一为 3.2 世界单位宽，并沿原方向延长 14 单位；牌面放在远端路肩。额外分岔继续在城区外伸展，给精绘牌面留出间距。现代路面沿用车道绘制，小镇使用宽石路；路面写目的 ID 与方向。
- 已指定的路牌改为原生链接，主点击或 Enter 直接进入目标 Profile 的同类地图；整段已连接道路也可直达。拖动路面只平移。本人空牌添加，已有牌右键或 Shift+F10 打开修改/移除卡片。权限仍要求已登录访问者与 Profile 相同，保存前实时核对。
- 双向关系仅来自当前浏览器已保存的双方数组，最多只读八个已配置目标；双方各自包含对方时，两端使用独立双向款。没有关系推断、公开配置服务、后台或自动发现请求。
- 如果已有双向牌指回旅程上一站，复用该牌，不额外绘制独立返程牌；其右键/Shift+F10 仍能选此前城市。否则独立返程牌主点击回上一站，右键选择更早城市。返程依旧按标签页和访问者隔离，不修改对方数组，不占八个出口槽位。

素材、源图与制作命令见[设计目录](../design/city-wayposts/v1/README.md)，完整提示词与外部视觉参考见 [PROMPTS.md](../design/city-wayposts/v1/PROMPTS.md)。交通牌外观参考不等于交通工程标准认证。

3. **八路间距**：输入 `torvalds`、`octocat`、`antirez`、`jashkenas`、`sindresorhus`、`yyx990803`、`tj`、`abcdefghijklmnopqrstuvwxyzabcdefghijklm`；最终分岔检查对调第 2 与第 5 槽，使额外分岔可实际进入 octocat。末尾 39 字符字符串仅验证排版，不声称账号存在。

## 实际发现与修正

- 原路牌的 `onclick` 只打开卡片，路面才有旅行链接。现已将已指定牌接入同一个原生链接与旅程处理，右键保留设置和多跳选择，不添加中间确认页面。
- 小镇切回现代城市时，聚落规划器重建 `keys`，漏掉新增的两张牌图，导致牌面隐藏。修正该实际资源清单后，切换及后续直接点击通过；没有用程序图形兜底掩盖缺图。
- 八路组合中精绘蓝牌与相邻绿牌发生遮挡；拉开额外路段末端后，两种地图八牌命中通过。
- 缺图测试最初误期望原始 HTTP 码，实际产品按既有合同显示素材加载失败。随后一次请求拦截没有可靠制造失败，改为在临时构建实际移走 PNG，并在全新配置中验证实际缺失及恢复；不据此改产品错误合同。
- 离线制作时的内嵌源图占满 Chrome dump 输出，改为只输出制作结果；实测退出时的临时配置晚写用有界清理重试处理。临时页面与 Chrome 资料不长期留存。

## 复现命令与步骤

```sh
TASK_TMP=$(mktemp -d -t codeyears-painted-wayposts)
node scripts/bake-direction-boards.mjs
npm run build -- --outDir "$TASK_TMP/build"
# 用户本机用于重载的目录：
npm run build
```

按前轮报告的 Chrome MV3 方法启动：Playwright 指向本机 Chrome，排除默认 `--disable-extensions`，临时配置增加 `--enable-unsafe-extension-debugging`，在 browser 级 CDP 调用 `Extensions.loadUnpacked({path: buildPath})`。打开扩展 `options.html` 写入上述明确的本机数组及 `codeyears:ui:language=en`。

1. 匿名进入 `https://github.com/wxy#codeyears-city`；贡献摘要出现、Apply 可用、短填入完成后点 Fit view。核对两种牌和未知牌、切小镇再切回来、缩放宽度比例、四方向外移位置和路面 ID。
2. 主点击 torvalds 牌，确认自动打开现代城市、没有独立返程；右键已有 wxy 牌核对返程列表，Enter 返回。再依次到 torvalds/octocat，刷新并切小镇，主点击独立返程回 torvalds，再由其双向牌回 wxy；比较三个原数组。
3. 改变 torvalds 的本机反向槽并恢复，核对双向状态；拖动已连接路面，检查位移与 URL，再实际点击验证访问。
4. 受控 wxy 身份测试 Shift+F10、添加 S/Enter、实时身份改变拒绝。预置八槽，逐个真实右键命中；两种地图截图查看，实际点击第 5 条分岔去 octocat 并返回。
5. 仅在临时构建把 `assets/town/direction-board-mutual.png` 改为 `.held`，启动全新临时 Chrome，先进入现代城市再切小镇；应提示失败且保留现代城市。恢复文件后重试应显示小镇及双向牌。
