# 预绘 City、年度工作周街区与固定缩放

日期：2026-10-31。实现提交 `955e55f`；用户反馈的投影/缩放修复提交 `5c70347`。分支 `codex/year-landscapes`，更新原 PR #15，**不合入**。本报告只保留文字、命令和结果，测试过程文件清理。

## 结果与范围

用户选择的六款建筑分别生成透明 PNG 并接入 Canvas 2D City。每年一条横向街区，周列、周一至周日七行；同年同强度档相邻建筑格可矩形融合。取消 City / Terrain 旋转，保留缩放、平移、重置与共享播放头。Terrain 仍为跨年份连续 Three.js 高度场，选择时才导入分包。数据获取、身份缓存和每日解析模块未改动。

源 PNG 各 1254×1254 RGBA，alpha 范围 0–255，合计 11,817,334 字节；运行时解码为每张 640×640 ImageBitmap。素材、标定和生成来源见 [素材说明](../design/city-buildings/v1/README.md)。建筑主色来自素材；大小/类型是视觉表达，不是精确贡献数量标尺。公园植物/湖泊/道路仅装饰。生长为整体向上揭示，不是真实三维拉伸。

用户指出两个实际问题：原生成素材的底边方向不一；缩放触发 1/2/4 重采样使跨格融合和类型变化。前者按每款主地面边做绘制时仿射校准，对齐地图 ±atan(1/2)；后者移除 City 缩放重采样，生成时固定地块与模型，缩放仅调整显示。Terrain 自身降低远景网格细节不改变 City 建筑。

## 直接路径与缩放不变量

临时 Vite 页面导入正式 `createLandscape` 和正式 `generateDays`，使用真实图片和 Canvas，未替换规划、绘制或时间轴。临时编译观测将规划结果、模型分布与共享视口写到 DOM；浏览器实际点击/拖动，观测只读 DOM。不是新增隔离单元测试，也不是仅用纯函数结果冒充页面行为。

常规数据使用 `src/renderers/probe/data.ts`：种子 20060101，逐日 `seed=(imul(seed,1664525)+1013904223)>>>0`，`seed%5===0 ? 0 : 1+seed%30`。三年为 2023–2025，二十年为 2006–2025，含闰日。其他输入见表。

所有上述输入的日期到周列/星期行/年份不匹配计数为 0。年度网格不强裁为 52 列，通常 53 列，2012 年在周一起始的布局下需要 54 列以保留首尾日期。这是边界日历位置，不是多出贡献日期。当前合并上限 8 周列×4 个星期行是实现选择，不是月度分区或已冻结产品规则。

二十年在 **0.35、1、2.5、5 倍**及重置后始终为 5642 个地块/3229 座建筑：住宅1280、公寓79、办公347、塔楼1495、会展26、体育场2。按源日期索引、占地宽深、模型、绘制尺寸及落点高度串联的 FNV 风格指纹始终 `929891803`。三年平移后同样保持指纹 `1004337843`，实际视口 zoom=1、panX=110、panY=45；重置恢复。此前可变采样结果是已修复问题，不作为通过证据。

实际查看浅/深色的透明画布、全景与放大后的道路/建筑主轴。仿射量测为近似校准，不宣称每个装饰边都符合单一物理相机，也不宣称用户已经接受整体观感。正式本地预览：`npm run preview:city`，打开 <http://127.0.0.1:4175/>，选一年/三年/二十年、页面明暗，跳过或重播，再缩放、平移、重置。

## 播放、失败与释放

`955e55f` 实装检查：真实 Chrome City 读取三年缓存后显示 1035 天；完整缓存仍可重播，暂停在约 7% 后切 Terrain 保留暂停位置，继续/跳过后回 City 为 100%，无额外数据请求；关闭风景画布归零，关闭面板后原生日历仍在。未在本报告记录真实贡献总数、缓存内容或页面响应。

同轮临时直接页：二十年暂停在 402/7305 后切 Terrain 保持进度；回 City 复用六张已解码图片，无额外 PNG 请求，Terrain 上下文释放。完成后的 render 计数两次观察保持 32，无连续提交。部分图片 404 时失败明确、5 张已成功位图均关闭；六个素材请求挂起时先关闭，再释放请求，晚到的6张位图全部关闭，画布为0。失败明细不会同时显示“准备中”。这些播放/资源控制未被后续 City 投影/固定规划修复改变。

`5c70347` 最终复核：刷新真实 GitHub 页面重新生成，修复后的“缩放不改变合并和建筑”说明、1 个 City 画布、100% 状态均出现，无素材加载失败，原生贡献日历为1。临时页最终关闭为画布0、累计创建/关闭位图36/36、City 的 WebGL 创建数0、捕获页面错误为空。深浅预览与真实扩展均使用最终资源，不以早期旧图代替。
