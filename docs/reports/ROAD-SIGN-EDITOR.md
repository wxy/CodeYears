# 出口路牌编辑、八条道路与输入快捷键修复

本报告记录第一版浮动路牌编辑。最新城主权限、道路尽头实体牌与多跳返程见[后续报告](OWNER-ROADS-AND-RETURN-TRAIL.md)；下方保留对应构建的历史范围。

日期：2026-11-11。状态：实现完成，类型检查、构建与直接受影响的真实匿名 Chrome MV3 路径通过；继续更新 PR #79，未合入或发布。首版菜单路径的历史记录见 [原报告](MANUAL-CITY-ROADS.md)。

## 最终行为

- 默认四条出城道路均有“+ 添加道路”路牌，直接点击即可在路牌旁输入目的用户名。工具栏不再提供道路菜单；收紧年份控件的横向间距，使 1280 像素窗口下的“更多”与其他控件保持同一行。
- 已指定路牌的主体链接直达目标 Profile；旁边的修改按钮用于更换或移除。原生路面链接与同类地图深链继续可用。
- 当前出口全部指定后提供下一条可添加的分岔出口，最多八条。额外道路从已有出城路段向外分岔，不占贡献日期地块；只增加道路与设置，不重新请求贡献历史或规划建筑。
- 原四槽设置直接沿用。新增后保存四至八槽数组，移除不挪动其他目的账号，也不替换地图切换前后的道路位置。全景下的路牌就近错开，细杆连接实际出口，避免修改按钮被其他路牌遮挡。
- 输入框隔离 `keydown`、`keypress`、`keyup` 的传播，保留默认输入、编辑和 Enter 提交。Escape 取消且恢复路牌按钮焦点；展开地图中只关闭编辑框，不误关整个地图。
- 本机存储、身份隔离、真实贡献数量、目标地图选择及普通访问默认贡献图沿用原规则。无新增权限、图片、后端、自动关系发现或后台轮询。

## S 键原因与最小验证

在此前已构建的 `dist/`、真实匿名 GitHub 页面和实际 MV3 扩展中复现：点击旧用户名输入框并实际按 S，输入内容仍为空，GitHub 的 “Search or jump to...” 搜索输入出现。document 处的键盘记录显示 `event.target.tagName === 'DIV'`，而 `event.composedPath()[0].tagName === 'INPUT'`；Shadow DOM 的事件重定向使页面快捷键没有识别内部输入状态。

重新加载同一真实页面，只在该输入框上停止键盘事件传播，实际按 S 后得到文本 `s`，搜索输入不再出现。实现采用相同的局部处理，不修改 document/window 的全局热键规则，不调用 `preventDefault()` 屏蔽正常文字输入。最终路牌编辑器再次验证 S、斜杠、退格、全选替换和 Enter 保存；编辑器以外的 GitHub S 搜索仍可正常触发。

## 环境、输入与复现

- macOS、Google Chrome 157.0.8103.39、Node v26.7.0、Playwright 1.62.1，1280×1000 视口，独立临时浏览器资料。
- 使用 browser 级 CDP `Extensions.loadUnpacked` 加载实际构建；启动时 `ignoreDefaultArgs: ['--disable-extensions']`，仅临时浏览器启用 `--enable-unsafe-extension-debugging`。具体加载方法沿用原报告。
- 真实匿名 `wxy`、`torvalds`、`octocat` 页面，没有贡献、身份、存储或响应替身，也没有读取个人 Chrome 配置、Cookie 或 Token。最终画面中 wxy 默认三年为 7,726，torvalds 为 9,364，octocat 为 0 次；公开快照会变化，不把这些数值写成固定预期。
- 通过这份临时扩展的 `options.html` 和真实 `chrome.storage.local` 写入旧四槽输入 `['octocat', null, null, null]`，验证兼容及槽位保持。随后依次添加 `antirez`、`jashkenas`、`sindresorhus`、`torvalds`、`yyx990803`、`tj`、`gaearon`，合计八条；没有对这些账号进行写操作。
- 输入失败使用 `bad/name`、`WXY`、重复 `OCTOCAT`；取消使用尚未保存的 `will-cancel`。按键与点击均由真实浏览器事件执行，没有调用产品内部方法替代交互。

可重复的操作顺序：

1. 打开 `https://github.com/wxy#codeyears-city`，等待真实合计、一个主画布及可用控件，点击全景。确认四个空路牌、没有工具栏道路菜单，“更多”在第一行。
2. 点击空路牌，按 S、斜杠、退格、全选替换；确认输入正确且 GitHub 搜索未弹出。按 Escape，确认没有新增存储。
3. 尝试非法用户名、自连接、重复账号。加载上述旧四槽设置并填满四条，确认自动出现第五条可添加的分岔路；继续添加至八条，确认不出现第九条，年度请求数量没有增加。
4. 对八块路牌分别点击修改按钮，再取消；确认均可实际命中。移除第二条后确认第五条仍是 torvalds，重新添加第二条。
5. 展开地图，编辑路牌并输入 S；按 Escape 只关闭编辑框。对现有 torvalds 不作更改，按 Enter 保存，确认表单正常提交且不触发年份重载。
6. 点击第五条 torvalds 路牌，确认目标 URL 为 `https://github.com/torvalds#codeyears-city`，自动打开目标现代城市并显示其实际贡献合计。后退及刷新后仍保留八条。
7. 切换魔法小镇，八个修改按钮均能实际点击；在第五条新增路面的命中多边形内、路牌以外的位置执行真实鼠标点击。确认目标 URL 为 `#codeyears-town`，同样自动显示对方小镇与合计。
8. 后退并切中文，确认编辑标题、道路数量文案。关闭编辑器后聚焦页面，按 S 验证 GitHub 原搜索功能仍可用。
9. 打开 `https://github.com/octocat#codeyears-city`，取得零贡献日历后从空路牌添加 wxy，确认路牌可保存并出现目标链接。

跨页等待以 `domcontentloaded`、实际目标 URL、地图控件与贡献合计就绪判断；GitHub 背景资源的完整 `load` 事件不是地图成功条件。
