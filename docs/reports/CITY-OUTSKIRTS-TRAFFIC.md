# 城郊水系、公路和车流验证

2026-11-19 初版 `ab5872b` 在 macOS 上使用 Chrome 157.0.8103.79 加载开发者模式扩展。测试窗口为 1380 × 980，DPR 为 1，开启减少动态效果。此次验证覆盖真实公开主页、受控资料栏变化以及包内容。五年城区出口和山路的后续结果在文末。

## 公开主页

打开公开的 `github.com/wxy`，进入城市，将起始年从 2024 改为 2018。构建显示 2018-01-01 至 2026-11-19，共 53,972 次贡献。默认三年范围已经有城外水系。较长范围的全景中，两条主要水道都穿过视野，主河经过城区并在城外分出两条支流。支流沿途形成两处明显拓宽的水面，草场边还可见一处完整的独立小湖。近城林丘、远山和雪山均已绘制。

点击全景，再向外滚动到 50%。两条主要水道和四条主出口都延伸至视野外。复位后先将地图拖至一段城外公路，再点击最大缩放。1,145% 下公路从画面边缘连续穿过。用同样方法移到城外水道并放到最大，河道仍从一侧进入、另一侧流出。打开开发者工具的 Network 面板可以复核贡献读取期间的请求。记录中 followers 和 following 页请求均为零。

## 受控样本

用 Playwright 在隔离的 Chrome 会话中加载同一 MV3 构建，拦截 GitHub 响应。资料卡含 8 个带 user 类型的 Bio 链接和两个可调整的计数。2018 至 2024 的七个日历按日期索引生成，索引从 0 开始，`i % 7` 为 0 或 6 时贡献为 0，其余日期为 `12 + (i * 19) % 43`。固定 `Math.random()` 返回 0.23751，以同一车阵比较，浏览器通过 Canvas 绘制参数记录车辆和水路坐标。共显示 60,511 次贡献，实际覆盖 2018-01-01 至 2024-12-29。

- 两个计数为 0 时全景绘制 112 辆车。只把关注数改成 `1.2k` 后为 142 辆，再把粉丝数改成 `5,000` 后为 153 辆。缩放后复位，车辆素材与世界坐标相同，贡献合计相同。关注列表请求为零。
- 全景和最小倍率下，四条主出口和四条分岔均穿出画面。两条主要水道、两处分流拓宽及独立小湖可见。分别将公路、水道放到该样本的最大倍率 1,071%，跨过视野的部分仍连续。

## 五年城区与山地公路复核

在相同 Chrome 环境加载新构建。进入公开的 `github.com/wxy` 城市，默认三年见到四个出口。起始年改为 2018 后，2018–2026 范围有两个五年城区和六个出口，本次合计 53,973 次。全景及 50% 下六条山路均越过画面边界。将一段弯道拖至中心后点最大缩放，1,145% 下路面、两侧边线与车道线连续。全景可见主河、两个不同走向的支流、独立小湖、林木山脊与雪山。用 Canvas 路径记录到各主路相对首尾连线的最大偏移为 13.2–15.6 世界格。

受控资料卡含 11 个个人账号，另外加入本人、组织和大小写重复账号。沿用上文逐年日历的生成方法，将输入增加为 2008–2024。默认三年显示前四位；选择 2012–2024 后三个城区显示前八位，共 112,405 次贡献；再向前扩展到 2008 后四个城区显示前十位。路牌避让最初把相邻城区的独立公路算作同一处路肩，部分牌面重叠。收窄至真正接近牌脚的路面后，八块命名路牌的浏览器指针命中逐一通过。实际点击第一块牌进入目标页，目标页的四个出口都已使用且来路排在 Bio 第五位，独立返程牌仍可点击并回到原城市。八条公路在 50% 时均延伸至视野外，1,330% 近景的弯道连续。

`npm run build` 和逐文件比对通过，本地 `dist/` 与浏览器验收构建一致。按上文命令在任务临时目录打包和校验，0.1.3 ZIP 共 125 个文件、29,501,573 字节，SHA-256 为 `c9b3b806c2997f5db341cd85e583bf3ba980ddda539761d643bf9c54314ab4b5`。本轮证据覆盖公开页面、受控跨城导航和包内容，长年限性能预算及商店仍待验收。
