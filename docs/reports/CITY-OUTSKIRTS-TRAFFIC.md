## 受控样本

用 Playwright 在隔离的 Chrome 会话中加载同一 MV3 构建，拦截 GitHub 响应。资料卡含 8 个带 user 类型的 Bio 链接和两个可调整的计数。2018 至 2024 的七个日历按日期索引生成，索引从 0 开始，`i % 7` 为 0 或 6 时贡献为 0，其余日期为 `12 + (i * 19) % 43`。固定 `Math.random()` 返回 0.23751，以同一车阵比较，浏览器通过 Canvas 绘制参数记录车辆和水路坐标。共显示 60,511 次贡献，实际覆盖 2018-01-01 至 2024-12-29。

- 两个计数为 0 时全景绘制 112 辆车。只把关注数改成 `1.2k` 后为 142 辆，再把粉丝数改成 `5,000` 后为 153 辆。缩放后复位，车辆素材与世界坐标相同，贡献合计相同。关注列表请求为零。
- 全景和最小倍率下，四条主出口和四条分岔均穿出画面。两条主要水道、两处分流拓宽及独立小湖可见。分别将公路、水道放到该样本的最大倍率 1,071%，跨过视野的部分仍连续。

## 从山体和水面规划公路

在 Chrome 157.0.8103.79 的隔离会话重新加载最终构建。默认三年与单年范围各显示四个出口。公开主页选 2018–2026 后显示 53,973 次贡献、六条公路。全景可见 12 处山地，其中 11 处的投影宽度至少 20 世界格，五处使用新增的宽幅林木山体，城市与河谷一带留出低地。以 Canvas 实际提交的路面中心线与贴图四角记录为输入，复核六条公路均避开可见山体轮廓，中心线互不交叉。50% 下六条路延伸出画面，移到弯道后放大至 1,145% 路面与标线仍连续。

按上文方法用 2008–2024 的 17 年受控日历和 11 个 Bio 个人提及复核。共显示 146,993 次贡献，十条路的中心线互不交叉，十块牌逐一通过浏览器指针命中。可见路段中有九条明显绕行，一条基本沿直线。50% 下十条路延伸出画面，所查弯道在 1,515% 下仍连续。

迭代中以矩形投影估算山体时，连续公路会挤进同一个谷口。改用运行 PNG 的轮廓，把同向出口分配在各自的谷带，先留出可通行的山口，再据最终绘制的地貌生成道路。规划在创建城市画面时完成，平移和缩放根据视口裁剪现有路线。

`npm run build` 通过，测试构建与本地 `dist/` 逐文件一致。任务临时目录的 0.1.3 验证包含 126 项，共 30,565,325 字节，SHA-256 为 `29785af624f895d25baa59d5172e87bbdfa6dfd830def56ea4bc5a7e343cb844`。本轮验证范围为公开主页、受控 17 年地图及包内容。
