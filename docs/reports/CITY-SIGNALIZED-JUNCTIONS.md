# 宽窄道路接入改为平交路口

日期：2026-11-07。对应 [PR #63](https://github.com/wxy/CodeYears/pull/63)，修改前为 `809bb17`。本轮桥梁暂时保持，尚未合入 main 或发布。

## 原因与实现

旧版将年度大道的端点投影到圆角前的闭环折线，在那里增加小环岛；环路本身的路缘和外侧标线仍然绕原弯角走。因此环岛不能消除截图中的多余外弯，部分入口还有年度轴线与投影接点的偏差。

- 年度四车道大道沿原轴线接到环路，接点规划为有信号灯的平交路口，移除中央绿岛及中央灯柱。
- 接入圆角时，规划器先记录闭环上的对应弯角；道路绘制命令创建时将该处外侧路面、路缘和外侧标线拉直，内侧继续沿原圆弧。只影响有大道接入的弯角，其余圆角保持。外侧填充与原路面重叠 0.02 格，避免抗锯齿留下旧弧线细缝。
- 直路入口按交点留白，弯道入口按实际切点定位；同一份入口几何供停止线和路缘灯具使用。灯具使用现有精绘 PNG；去掉距新灯过近的旧灯，Q3 样本共去掉六个重复位置。
- 年份/季度共用道路、路名留白和片区连接逻辑沿用；接点不再追加独立细支路。所有命令在地面缓存创建前预备，没有绘制结束后修改布局。
- 两张桥 PNG、桥位、桥跨、引桥、河道和贡献地块不改；没有新增素材、依赖、数据请求、定时器或连续绘制。
