# 微缩贡献图与工具栏设置验收

日期 2026-11-20。PR #87 的反馈修订，基线 `d8fee4d`。

## 复现

1. 在功能工作树运行 `npm ci` 和 `npm run build`。构建包含 `npm run check`。
2. 在 Chrome 的扩展管理中以「加载已解压的扩展程序」加载 `dist/`。使用新建、未登录的 Chrome 配置，打开公开 GitHub 个人主页 `https://github.com/torvalds`。
3. 初次打开应看到原生贡献图和「城市」页签。点击工具栏图标，依次选择「关闭」和「微缩城市」，对照 `table.ContributionCalendar-grid` 和 `thead` 的尺寸，以及覆盖层尺寸。
4. 检查微缩图例的空地和四栋示意建筑。在弹窗关开道路，对照同一组房型。切 GitHub 深色主题，检查微缩图底色。
5. 在微缩图点选一个原生日格，检查 GitHub 点选状态及日期提示。选择「关闭」并刷新。重新选微缩城市，通过原生年份列表切到 2024 年，最后选回大规模城市。
6. 将打包输出放到独立临时目录，运行 `python3 scripts/package-city.py --output-dir <临时目录>` 和 `python3 scripts/verify-city-package.py <临时目录>/codeyears-0.1.3-city.zip`。

## 实际结果

- macOS Chrome 158.0.8127.36 以全新未登录配置加载实际 MV3 构建。通过 DevTools Protocol 在实际标签上触发工具栏动作，三个模式与道路开关均即时生效。
- 同一原生日历的 370 个日期。关闭与微缩模式下，表格同为 723 × 113 CSS 像素，标题行高 13 像素，整个图表高 143 像素。微缩覆盖层与原生日格范围同为 686 × 88 像素。
- 五档图例保持自身无障碍描述。0 档用灰色空地，1–4 档使用对应档位的建筑。设置 GitHub 深色主题后，底色从浅灰随页面换成深灰。关闭再开启道路后画布输出相同。
- 实际鼠标点选触发 GitHub 原生日期选中，原生日期提示仍可用。关闭模式恢复日格颜色、图例和原布局，刷新后仍然关闭。重新选微缩城市、切到 2024 年及切回大规模城市均通过。
- TypeScript、Vite 构建和发行包核验通过。测试 ZIP 138 项，33,441,920 字节。SHA-256 为 `1e1b58c9d6f7d15f1cda154f7fb3abd05393f8aa7ce4d2173f3adb813b90e686`。
