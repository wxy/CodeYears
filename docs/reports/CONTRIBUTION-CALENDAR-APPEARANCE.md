# 微缩贡献图与工具栏设置验收

日期 2026-11-20。PR #87 的反馈修订，基线 `e248a6b`。

## 复现

1. 安装锁定依赖后运行 `npm run build`。构建包含 `npm run check`。
2. 使用新建、未登录的 Chrome 配置加载 `dist/`，打开公开 GitHub 个人主页 `https://github.com/torvalds`。
3. 确认「城市」和「贡献图」均可见。用工具栏弹窗切换原图和微缩城市，对照 `table.ContributionCalendar-grid`、`thead` 和微缩覆盖层的尺寸。
4. 在 GitHub 明暗主题下检查微缩城市的虚线圆格、建筑与五档图例。点选有贡献的日格，检查 GitHub 原生选中状态和日期提示。
5. 在微缩模式中通过弹窗快捷按钮打开大规模城市。在城市内把贡献图样式改为原图，确认城市仍打开，返回「贡献图」后显示原图。测试页内按空格切换、刷新恢复已选样式、原生年份链接切换到 2024 年和再切回原图。旧偏好可用 `chrome.storage.local` 将 `codeyears:ui:appearance` 分别设为 `off` 和 `city` 验证。
6. 将打包输出放到独立临时目录，运行 `python3 scripts/package-city.py --output-dir <临时目录>` 和 `python3 scripts/verify-city-package.py <临时目录>/codeyears-0.1.3-city.zip`。

## 实际结果

- macOS Chrome 158.0.8127.36 以全新未登录的无头配置加载实际 MV3 构建。通过 DevTools Protocol 触发工具栏动作，并输入原生鼠标与键盘事件。
- 原图与微缩模式均显示 370 个日期，表格同为 723 × 113 CSS 像素，月份标题行高 13 像素，图表高 143 像素。微缩覆盖层与原生日格范围同为 686 × 88 像素。
- 明暗主题实看通过。空日格用淡灰虚线圆格表示，底板为两端全圆角，底色随主题变化。五档图例的原生无障碍描述保留，0 档为灰圆点，1–4 档为对应建筑。原生日格可点选，日期提示仍可用。
- 「城市」页签在两种贡献图样式下都可用。微缩状态可用弹窗快捷按钮打开大规模城市并绘制画布，随后切换样式时可继续浏览城市。页内按钮可用空格切换。刷新、切换年份和还原原图均通过，旧值 `off` 与 `city` 都显示原图并保留城市页签。
- TypeScript、Vite 构建和发行包核验通过，微缩道路纹理已从包中移除。测试 ZIP 137 项，33,435,134 字节。SHA-256 为 `e42c07921789f0f24b07dbfa6dacac32a71a72ad0a18ab70bfe8337e9d19855e`。
