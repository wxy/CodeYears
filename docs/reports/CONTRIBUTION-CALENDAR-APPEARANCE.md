# 微缩贡献图与工具栏设置验收

日期 2026-11-20。PR #87 的反馈修订，基线 `6604565`。

## 复现

1. 安装锁定依赖后运行 `npm run build`。构建包含 `npm run check`。
2. 使用新建、未登录的 Chrome 配置加载 `dist/`，打开公开 GitHub 个人主页 `https://github.com/torvalds`。
3. 分别在站外页面、GitHub 仓库、GitHub 组织主页和有贡献图的个人主页打开弹窗。确认前三处有说明且所有设置控件禁用。个人主页的弹窗顶部应有独立「城市」分组，包含页签开关和打开按钮。用复选框隐藏城市，再切换贡献图样式。对照 `table.ContributionCalendar-grid`、`thead` 和微缩覆盖层的尺寸。
4. 在 GitHub 明暗主题下检查微缩图、建筑与五档图例。对照两种样式下 `.ContributionCalendar-day` 和 `.ContributionCalendar-day[data-level="0"]` 的圆角与边框，确认微缩覆盖层的子元素只有建筑画布。悬停及点选有贡献的日格，观察 GitHub 原生日期提示和选中状态。
5. 刷新验证设置保留。城市隐藏时打开城市直达链接，确认仍显示所选的贡献图。重新勾选复选框，从工具栏快捷按钮进入大规模城市，再取消勾选。用原生年份链接切换到 2024 年后切回原图。
6. 将打包输出放到独立临时目录，运行 `python3 scripts/package-city.py --output-dir <临时目录>` 和 `python3 scripts/verify-city-package.py <临时目录>/codeyears-0.1.3-city.zip`。

## 实际结果

- macOS Chrome 158.0.8127.36 以全新未登录的无头配置加载实际 MV3 构建。通过 DevTools Protocol 触发工具栏动作、标签点击和原生鼠标事件。
- 在 `https://example.com/`、`https://github.com/wxy/CodeYears` 和 `https://github.com/github` 打开弹窗，均显示个人主页提示。城市页签开关、打开城市按钮、两种贡献图样式及语言菜单均禁用。尝试点按未改变本机偏好，页脚帮助可见。返回 `https://github.com/torvalds` 后，控件启用并可保存设置。
- 350 像素宽弹窗实看通过。顶部「城市」分组的标题字号大于下方「贡献图样式」，开关点击区约 50 像素高，快捷按钮位于同组。点击开关标签可以切换页签。
- 原图与微缩模式均显示 370 个日期，表格同为 723 × 113 CSS 像素，月份标题行高 13 像素，图表高 143 像素。微缩覆盖层与原生日格范围同为 686 × 88 像素。
- 明暗主题实看通过。370 个原生日期格在微缩模式为等宽等高的 50% 圆角，测试中的原图为 2 像素圆角。GitHub 源样式声明为 `.5px solid`，该 Chrome 会话在两个模式中都以 1 CSS 像素报告计算后的边框。建筑画布叠在日格上方，矩形底板圆角为 0，原生外框的上角在两种样式下都为 6 像素。GitHub 日期悬停提示和实际鼠标点选通过。
- 城市显示和隐藏均可配合 GitHub 原图或微缩样式。隐藏后刷新或访问城市直达链接继续显示贡献图。开启时快捷按钮可打开大规模城市并绘制画布，关闭当前城市页签会释放大规模场景并恢复微缩图。切换年份和还原原图通过。
- TypeScript、Vite 构建和发行包核验通过。测试 ZIP 137 项，33,436,091 字节。SHA-256 为 `f23e75816fda6c46ffd8b3e577ae5599030bc4044c16e0d6434820b4ffdd561e`。
