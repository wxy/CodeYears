# 微缩贡献图与工具栏设置验收

日期 2026-11-20。基线 `99b0e4c`。

## 复现

1. 在功能工作树运行 `npm ci` 和 `npm run build`。构建包含 `npm run check`。
2. 在 Chrome 的扩展管理中以「加载已解压的扩展程序」加载 `dist/`。使用新建、未登录的 Chrome 配置，打开公开 GitHub 个人主页 `https://github.com/torvalds`。
3. 初次打开应看到原生贡献图和「城市」页签。点击工具栏图标，在弹窗切换简体中文、微缩城市。检查语言联动、版本号、帮助、隐私和反馈。
4. 在微缩图点选一个原生日格，对照 GitHub 日期提示。将滑块从 100% 调到 250% 再回到 100%，检查选中日期记录与房型。通过 GitHub 年份列表切到 2024 年，刷新该页。
5. 再用弹窗切回大规模城市，并点击「打开当前主页的城市」。检查原生日历恢复、城市画布打开。
6. 在 `about:blank` 标签点击工具栏图标，检查设置是否直接可用。显式点击打开城市时检查缺少 GitHub 主页的提示。
7. 将打包输出放到独立临时目录，运行 `python3 scripts/package-city.py --output-dir <临时目录>` 和 `python3 scripts/verify-city-package.py <临时目录>/codeyears-0.1.3-city.zip`。

## 实际结果

- macOS Chrome 158.0.8127.36 以全新未登录配置加载实际 MV3 构建。通过 DevTools Protocol 在实际标签上触发工具栏动作。保存简体中文与展示方式后，当前 GitHub 个人页立即更新。
- 公开当前日历的 370 个原生日格及日期提示仍在。实际鼠标点击的日期由 GitHub 标记为选中，扩展显示对应的原生提示文字。回到 100% 时画布输出相同，选中记录经过缩放仍然可见。
- GitHub 2024 年入口及浏览器刷新通过。切回大规模城市时微缩布局和日格位移已移除，工具栏快捷按钮打开大规模城市画布。
- 清单已移除独立选项页。实际工具栏弹窗包含原有语言、版本与三个帮助入口。在 `about:blank` 可以保存展示方式，显式点击打开城市时才提示缺少 GitHub 主页。
- TypeScript、Vite 构建和发行包核验通过。测试 ZIP 136 项，33,436,185 字节。SHA-256 为 `6d546c6ea0030c65ac1aa5a861da1eca1a2e8d1da56bfc06a7be03dca898e922`。
