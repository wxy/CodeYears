# 紧凑缩放工具条

日期：2026-11-04。起点：main `663c49e`；分支：`codex/compact-zoom-toolbar`。本轮仅交付工具条，通过PR提交，不自动合入或发布。正式商店截图等待下一版界面定稿后制作。

## 实现

- 正式City右下角改为“全景图标｜当前比例｜最大倍率图标”，移除加减按钮。图标使用内联SVG，继承现有颜色；提供中英文可访问名称和悬停说明。
- 100%仍为完整城市适配当前画布，比例取实际缩放值并四舍五入显示。渲染器在滚轮、键盘、复位、最大倍率及尺寸变化时通知面板，不轮询，不逐帧更新DOM。
- 最大倍率复用现有`layer.maxZoom(viewport)`，不新增另一套上限。尺寸变化时按新上限约束；全景按钮恢复100%并居中，最大倍率从当前取景中心放大。
- 保留滚轮缩放、拖动与方向键平移；移除按钮后，聚焦画布可按`+`（也接受`=`）放大、`-`缩小。只有焦点在场景本身且没有Alt/Ctrl/Meta时处理，原方向键的Shift限制保留。原生按钮支持Tab和Enter。
- 比例是只读文本，不作为输入框，也不逐次向屏幕阅读器播报滚轮事件。语言切换更新比例说明与图标提示，不重新加载数据。
- 贡献获取、解析、身份缓存、地块规划、资源格式与权限不改；开发预览既有加减控件保留。没有加入素材、依赖、计时器或持续绘制。
