## 后台边界的证据限制

本轮接管页面时，已看到城市画布为零和“页面进入后台，结果已清除；返回后重新读取时会核对当前身份。”提示。但这不是本轮操作形成的独立触发样本，不据此认定后台路径已通过。

之后在 DOM 控制附着的 GitHub 标签上，用原生标签控件切到本地预览，再切回，画布仍存在，未得到清理提示。控制期间曾观察到 Chrome 原生前台是另一标签，而受控 GitHub 的 `document.hidden` 为 false；焦点模拟或控制附着可能影响可见性，因此上述现象无法区分工具干扰与产品行为。尝试准备另一未受本轮 DOM 控制的原生样本时，原生 AX 读取超时并重置工具，未形成完整独立证据。

本轮将后台清理标为 **INCONCLUSIVE**，没有改动或绕过产品代码，也不把它写成通过或已证实产品缺陷。正式验收仍需在未启用工具焦点模拟的普通浏览器中实际切走/返回，确认画布、数量和明细清除，再重新生成；该项不因本报告的其他通过项而关闭。

本轮新增的有效边界证据是正常年度页内导航后的面板/画布清理。未重新开启扩展以测试所有历史导航组合，也未将页面中的账户名字等同于完整身份隔离验收。
