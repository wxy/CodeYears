## 规则与原因

- 普通出城路牌统一蓝色，未配置时仍是纯空牌。当前访问的返程路牌绿色；已有指回上一站的出口时复用并显示绿色，没有额外的“双向状态”。只读当前城的本机配置和当前标签来路，不读取对方发布数据。
- 原 `paintRoad` 直接跳过了返程，而且地面阶段只调用普通路牌的文字绘制，这是有返程牌却没有路面名称的直接原因。现在临时返程在原留白半幅写来源 GitHub ID，并有对应的半幅链接；普通出城半幅的名称和链接保持各自目的地。没有临时返程时仍留白。复用已有出口时，该出口照常显示返回名称。
- 原牌面横轴使用道路纵向向量，斜路还人为偏转了 30°。现在统一投影道路法线，立杆保持竖直，文字与点击多边形使用同一平面。四个基本方向和四个额外分岔不再有单独的角度补偿。
- 保留正式 PNG 和牌面比例。整体尺寸为前版的 80%，在竖直牌面坐标分开绘制牌面与支架，仅将牌面以下现代立杆高度乘 0.35、小镇支架乘 0.65；不会把牌面和文字压扁。现代款复用原蓝/绿图，小镇保留木框、灯笼和石基，在原木纹上绘绿色漆面。无新增图像资源。
- 点击已指定牌面或公路仍直达。本人已指定牌旁增加独立“修改”按钮，悬停或焦点显示，触屏直接显示；按钮在牌面外侧，不遮住缩小后的牌面。点击直接打开预填目的地的表单，可以修改或移除。空牌仍点击添加，右键/Shift+F10 仍保留。其他人的城市和临时返程牌没有修改按钮，原保存前身份核对不变。

## 环境与输入

macOS，Chrome 157.0.8103.39，Node v26.7.0，Playwright 1.62.1，1280×1000 headless；实际安装当前 `dist/` 的 MV3 扩展。浏览器配置与过程文件仅在独立系统临时目录。

1. 匿名真实公开 Profile：`wxy=[octocat,null,null,null]`，`octocat=[torvalds,null,null,null]`，从 wxy 点击牌面抵达 octocat。两种地图分别检查蓝色 torvalds 出城和绿色 wxy 返程，然后从返程半幅回去。将 octocat 改为 `[wxy,null,null,null]` 后再访问，检查复用既有返回出口及 Enter 返回。配置是明确测试输入，不断言账号真实关系。
2. 本人编辑只在真实 wxy HTML 注入受控 `meta[name=user-login]=wxy`，贡献仍走实际 GitHub 读取和解析，保存使用真实扩展存储及现有联网身份核对。这不构成真实登录或私有权限验收。
3. 八槽输入：torvalds、sindresorhus、antirez、jashkenas、octocat、yyx990803、tj、abcdefghijklmnopqrstuvwxyzabcdefghijklm。末尾 39 字符只用于排版，不访问或声称账号存在。修改第一个为已有 octocat 检查重复拒绝，再改为 defunkt，Enter 保存。

## 验证方法

```sh
npm run build
shasum -a 256 dist/content.js dist/landscape.js
```

Playwright 指向本机 Chrome，排除默认 `--disable-extensions`，开启 `--enable-unsafe-extension-debugging`；browser CDP `Extensions.loadUnpacked({path: distPath})`。在扩展 options 页用 `chrome.storage.local.set` 写入上述输入，语言设 en。进入 Profile，等待真实读取和短填入结束，Fit view。

- 在扩展 isolated world 记录主 Canvas 实际 `fillText`、`measureText` 字形包络和变换，触发一次缩放重绘。返程名称的四个包络角点应全部落在 `.city-return-surface` 多边形内；同时存在出城目的名与来源名，没有问号。
- 取路牌实际点击多边形上沿及对应公路宽度方向，核对平行；DOM 分数像素取整的允许垂距为 0.05 CSS px。使用可见像素误差，避免在很窄的斜路上用不必要的角度小数作为产品标准。
- 从正常可见的返程半幅鼠标点击回去，比较目标城原槽位不变；已有返回出口时不应有独立返程牌或返程半幅覆盖层。
- 两种地图八块牌分别 Tab 到修改按钮、Enter 打开表单，核对预填 ID 并关闭；悬停时显示修改按钮，用实际可见位置的鼠标点击进入。全程没有 force click 或绕过命中。
- 四个方向分别围绕路牌放大，核对牌面、竖杆、脚点及道路关系；原美术文件不变，不把浏览器截图当作正式素材保存。
