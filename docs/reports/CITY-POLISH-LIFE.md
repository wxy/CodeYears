# 轻量城市生命感：原型与比较

日期：2026-11-08。分支 `codex/city-polish-life-probe`；固定起点 `5c6d2e60b3becdbb5900d98cb7478a1fbf9b6bba`。云端初始检出 `7fe7338`，fetch 后从指定起点建立独立分支。未合入、发布或直接推送 main。

**建议：保留可运行实验，暂缓正式接入。** 1/2辆精绘车辆在近景有轻微生命感；整体视角很难辨认。主城Canvas和地面缓存可以保持静止，但独立层仍带来持续调度、样式计算和合成成本；当前收益不足以建议默认启用。用户视觉接受与目标设备验证之后再决定，不扩大为交通系统。

## 假设

少量移动精绘车辆是否能在不重绘城市、不改变道路与数据的情况下提高生命感？本轮只比较关闭/1辆/2辆，不验证交通规则系统、人口或经济，也不假定CSS、GIF或精灵图天然省电。

## 实现

全部源码在 `probes/city-polish/life/`。直接使用正式 `planOrganicCity`、`createOrganicGround`、`loadCityImages`、`createCityView(...,0,ground)`。正式入口与共享src、配置、锁文件、素材目录均未修改。

- 正式规划结果保持原样；在创建车辆层前筛选已有外围环路直道，4格短段，避开圆角/路口/路名，沿正式右行车道和方向选轿车图片。
- 整段车辆投影矩形与全部非平面静态素材投影矩形比较，存在重叠就拒绝；包括楼体、树木、静态车辆及桥。保守矩形也可能拒绝透明区域。本轮四个输入均取得两条安全段，未改、移、删道路或楼体补救。
- 复用正式四方向预烘焙PNG，249×180、257×170、248×181、249×178，源文件合计319442 bytes，均小于384长边。没有新增PNG、imagegen调用或素材库转换；原图/提示/标定沿用正式既有档案。桥及1152预算未变。
- 两个小Canvas各复制一次图片，随后只更新独立DOM层的transform、opacity与地面深度顺序。0.7格/秒、约5.7秒周期、首尾12%淡入淡出，始终单向；不把短段消失误称完整交通。独立层不持有主画布或重绘回调。
- 默认关闭；暂停、原图替身、`document.hidden`、`prefers-reduced-motion`与销毁取消RAF并隐藏候选。恢复重置上一帧时间戳，保留相位，不追赶停留时间。单帧时间增量最高100ms。
- 镜头变化才重绘主城并通知动态层。初始100%，整体比较固定50%居中；近景对准第一短段、目标90 CSS px/投影单位。范围保持50%—最高2000%，沿用正式素材细节上限，因此有时更早到顶。

工程原图按钮只隐藏/恢复同一个City实例，另一面是明确标注的贡献图替身。没有GitHub请求、身份核对替代品、会话复制、后端、Token、登录或持久化。静态装饰车辆全部保留。

```sh

# 浏览器打开 http://localhost:4184
```

先选输入，再选“整体50%”或“路段近景”，在关闭/1辆/2辆间切换。切档不重新规划、不改变镜头或数据。可拖动、滚轮、暂停、切换替身、销毁与重建；“刷新测量”显示计数，面板没有持续刷新定时器。

## 输入与实际验证

Linux云端，Node24.19.0、npm11.9.0、TypeScript7.0.2、Vite8.3.5，Chromium154.0.0.0 headless；窗口1280×1000、舞台1218×648 CSS、DPR1。WebGL诊断显示ANGLE/Vulkan SwiftShader软件设备，不是本机GPU。本原型使用Canvas2D，WebGL仅在测试末尾读取后端信息。

输入复用正式 `generateDays`：从2006-01-01至2025-12-31，seed=20060101，逐日 `seed=(imul(seed,1664525)+1013904223)>>>0`；稀疏为 `seed%20===0 ? 1+seed%40 : 0`，常规为 `seed%5===0 ? 0 : 1+seed%30`，稠密为 `50+seed%151`。按ISO周年筛选三年2023—2025或二十年2006—2025，不补输入外跨年日期，所以不是7305天。

| 输入 | 日期 / 合计 / 非零日期 | 正式显示成员数 |
| --- | --- | --- |
| 三年稀疏 | 1092 / 509 / 49 | 1002 |
| 三年常规 | 1092 / 13684 / 876 | 1092 |
| 三年稠密 | 1092 / 139213 / 1092 | 1092 |
| 二十年稠密 | 7301 / 912895 / 7301 | 7301 |

稀疏有90个零值日期被既有organic长空档策略省略；本候选没有新增省略。原date/count、成员indices、ISO周列/星期定位完全由原规划产生并保留；动态层只读取独立track和图片，未修改scene或其道路/桥/河对象。切档复核相同输入统计和viewport，年度共用路、季度路、片区连接与桥高/水位没有候选分支。

最终四输入×两镜头×三档=24组，每组稳定后观测1.8秒并截图。同一输入只创建一个实例，切档复用，截图的车辆相位自然不同。所有窗口的主Canvas调用增量=0、其余Canvas绘制调用增量=0，主城有效重绘计数增量=0；检测覆盖 `drawImage/clearRect/fillRect/fill/stroke`，包括脱离DOM的地面缓存。关闭8组均新增动画帧0、pending=false；开启16组约新增108—109帧，帧间隔P50约16.7ms、P95约16.7—16.8ms，回调自身CPU P95约0.1ms。这不包括浏览器后续样式/合成工作，不能作为总帧成本或硬件FPS承诺。

## 停止、恢复与交互

每个停止窗口800ms：暂停548→548帧；原图替身562→562；减少动态577→577；受控隐藏598→598；销毁639→639。各窗口pending=false，Canvas调用不变。原图返回同一实例新增素材请求0、主城重绘0；没有用销毁重建冒充复用。销毁后DOM Canvas数0，重建后3个（主城+两辆），图片复制2次且可继续运动。诊断字段spriteUploads计数小Canvas的一次drawImage复制，不代表GPU上传测量。

无头Chromium中实际打开并激活另一页后 `document.hidden=false`，因此**真实后台隐藏/恢复未验收**。驱动如实保留该结果，再在独立测试页临时覆盖hidden、派发visibilitychange验证停止路径，恢复删除覆盖：恢复100ms后相位只推进约0.100s，没有追赶约1.8秒的停留。暂停1.2秒后恢复约100ms，相位推进0.0833秒。这是受控事件路径，不冒充真实浏览器后台行为。

拖动平移、滚轮与按钮缩放、近景/整体切换通过。最终二十年舞台实测最小50%，最大约1479.0%（受到正式素材细节上限约束，未人为提升至2000%）；代码最高限制2000%。动画层镜头随主城同次更新，近景人工检查道路落点与车辆朝向，未见穿楼、水面或逆向；已生成四类输入整体/近景截图；人工复核常规与多年近景、稀疏整体、稠密近景和多年整体。稠密三年近景的第二条安全段可能出屏，末次屏内只有1辆，不强行移动场景把它拉入取景。

## 视觉取舍

近景车辆与正式PNG风格一致，细微移动可感知；静止基线已含精绘静态车辆，开启并不会让整城呈现明显不同的节奏。整体50%下仅是小点。选外围能稳妥避遮挡，但缺乏城中心生活感；扩大到内街就需要更多深度遮挡/信号灯/路径规则，超出本方向。短段淡入淡出可以看到，不是连续路线；不值得为了掩饰它升级交通模拟。
